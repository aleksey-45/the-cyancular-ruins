# 渲染

项目使用 Godot Mobile 渲染后端和 1920×1440 的逻辑视口。对局世界画在 `WorldViewport`，根视口转发未处理输入，并在画布层合成后处理与界面。`PostProcess` 处理鱼眼、倒地去色、受击红闪、低血暗角和单人时间效果。低血强度按当前生命值与最大生命值的比例计算。 [项目设置](../project.godot) · [后处理](../core/present/post_process.gd)

摄像机以当前基准位置为锚点跟随目标最近的环面副本，叠加震动作为显示位置。瞄准使用未加震动的基准位置。远端角色、敌人、掉落物与弹丸视图对齐到观察者附近的副本。本地预测的平滑校正在 `Visuals` 上衰减，物理体和枪口使用逻辑位置。 [摄像机](../core/present/camera_2d.gd) · [玩家表现](../scenes/player/player.gd)

## 地形与水面

`TerrainAtlas` 从实际使用的描述符生成染色纹理。32 像素源砖分成 4×4 个切片，每片用最近邻放大到 16 像素。墙体和水体铺主图与接缝带，宽度取相机缩放下的半视野。镜头中心越界时，显示层平移相应的地图周期。

水体按辅码及 2×2 形状掩码生成瓦片。上方没有水的水格生成水面，水面按辅码合批，着色器驱动起伏。主菜单鱼眼背景使用 `newfactory.cyrm` 的地图纹理。 [图集](../core/sim/terrain_atlas.gd) · [关卡渲染](../scenes/level_0.gd) · [菜单背景](../scenes/main_menu.gd)

## 动作与反馈

挤压拉伸将滞空形变与起跳、落地、冲刺及受击的衰减脉冲叠加到精灵缩放。走路时，持枪摆动取当前动画帧与帧内进度，叠加到后坐和装填的贴图偏移。枪口与碰撞仍使用模拟坐标。 [形变](../scenes/effects/squash_stretch.gd) · [武器表现](../scenes/weapons/weapon_base.gd)

单人命中飘字按同批命中的目标合并伤害。玩家受到的伤害为红色，敌人受到的伤害为金黄色。文字从受击点附近上浮淡出，并随本地观察位置选择环面副本。 [伤害飘字](../scenes/effects/damage_numbers.gd)
