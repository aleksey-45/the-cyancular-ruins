# 界面与交互

菜单、对局 HUD、联机大厅、对局准备界面和地图编辑器使用 UI v2 公共主题。主题生成器和各界面共用字号、颜色与间距。`UiKit` 提供页面容器、工具栏、状态栏和卡片。[主题参数](../ui/theme/menu_style.gd) · [主题生成器](../tools/gen_menu_theme_v2.gd)

## 菜单与大厅

主菜单设有单人、多人和 Beta 入口。单人开局可选地图和可用武器。联机大厅列出在局域网内发现的公开房间，可按 1v1、团队对抗和大乱斗筛选。玩家可点击房间卡片加入，也可在工具栏输入 8 位房间号后按 Enter 或点「加入房间」。房号为空时，点击「加入房间」会聚焦输入框。Esc 结束输入或关闭建房表单。房主可在建房时关闭「对局域网展示房间卡片」。点击等待室标题可复制房间号，团队房提供换队按钮。等待室在满足开局条件后向房主显示「开始游戏」按钮。断线后返回大厅时，游戏会凭有效的重连凭据尝试恢复对局连接。[联机大厅](../scenes/mp_lobby.gd) · [对战模式](modes.md)

单人开局和多人建房共用地图选择控件。1v1 与大乱斗的建房表单也复用单人模式的武器选择控件。勾选的武器在本局禁用。建房表单通过信号将选择交给大厅控制器。大厅控制器按房号加入，使用房间管理提供的摘要更新列表，使用服务器确认的名单更新等待室。对局控制器根据服务器的回合状态更新中央提示、比分和结算列表。[地图选择](../ui/map_picker.gd) · [武器选择](../ui/weapon_picker.gd) · [大厅视图](../ui/screens/lobby_view.gd) · [回合界面数据](../scenes/round_projection.gd)

## 对局加载

进入单人关卡或联机对局时，加载界面会提示场景创建、进入场景等阶段。切换期间的联机消息由 `NetSession` 暂存。加载失败时可点击「返回」或按 Esc 关闭提示。返回主菜单或大厅时会短暂显示过场遮罩。[加载流程](../core/present/scene_transition.gd) · [联机会话](../core/net/net_session.gd)

## 对局 HUD

单人和多人共用玩家状态面板。生命条按实际生命值上限绘制，近期损失的生命值闪白后淡出。氧气回满时氧气条淡出。武器栏按背包容量和各武器占用的格数绘制，并高亮当前装备的武器。弹药单独显示。单人面板显示当前关卡的累计击杀数。靠近地面武器时，拾取键显示在武器上方。换弹环在角色脚下显示剩余秒数。[玩家 HUD](../ui/hud/hud.gd)

多人模式共用延迟读数和中央提示，比分、断线提示及排行榜随对局状态更新。结算面板显示胜负和排名。玩家可点「返回房间」，按钮会显示等待状态。所有在线玩家确认后，一起回到原房间。圆形小地图以本地角色为中心，显示半径为 200 个子格。玩家标记颜色按队伍或模式确定。设置分别控制小地图、其他玩家的小地图标记、头顶生命条和弹丸尾迹。[联机 HUD](../ui/hud/pvp_hud.gd) · [小地图](../ui/hud/minimap.gd)

单人和 Beta 对战中，怀表用白色短针显示时间颗粒余额比例，用红色长针显示短期消耗和透支。表盘中央显示剩余额度，透支时显示红色负数。[怀表 HUD](../ui/hud/watch_hud.gd)

## 地图编辑器

顶栏提供文件、编辑、视图和试玩操作。左侧选工具与材质，右侧选图层并编辑当前工具的参数，底部显示操作提示和光标坐标。图层和材质按钮用相同的选中样式。新建、尺寸、注记和放弃修改窗口继承公共主题，打开和另存为使用系统文件窗口。操作和快捷键见[地图编辑器](tools.md#地图编辑器)。

## 主题与设置

公共主题定义按钮、面板、输入框和开关的外观。主题类型变体继承基础类型的主题项，可覆盖需要调整的样式。控件通过 `theme_type_variation` 属性选择变体。`UiDesign` 使用 `menu_theme_v2.tres`。界面文字和世界中直接绘制的文字共用字体资源，首选 Less Perfect DOS VGA，缺字时依次尝试 GNU Unifont 和系统字体。[v2 主题](../ui/theme/menu_theme_v2.tres) · [控件工厂](../ui/design_v2/ui_design.gd) · [字体资源](../assets/fonts/menu_font.tres)

显示设置提供全屏和四种 4:3 窗口尺寸，分别为 1280×960、1600×1200、1920×1440 和 2560×1920。空间不足时，游戏会等比缩小窗口以适应屏幕工作区。窗口居中显示，逻辑视口始终为 1920×1440。显示设置、音量和键位保存在 `user://settings.cfg`。[设置](../core/config/settings.gd) · [默认操作](player.md#默认操作)
