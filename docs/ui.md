# 界面与交互

主菜单、对局 HUD、联机大厅和对局准备使用 UI v2 的公共主题。字号、颜色与间距由 `UiDesign` 定义，公共控件由 `UiKit` 创建。 [迁移与验收计划](construction/2026-11-23-ui-full-replacement-plan.md)

## 菜单与大厅

主菜单设有单人、多人和 Beta 入口。单人开局可选地图和可用武器。联机大厅列出同网段的公开房间，可按 1v1、团队对抗和大乱斗筛选。玩家可点击房间卡片加入，也可手动输入 8 位房间号。房主可在建房时关闭「对局域网展示房间卡片」。等待室标题可复制房间号，团队房提供换队按钮。达到开局条件时，等待室会向房主显示「开始游戏」按钮。持有效凭据的玩家可从房间卡片重连。[联机大厅](../scenes/mp_lobby.gd) · [对战模式](modes.md)

单人开局和多人建房共用地图选择器。1v1 与大乱斗的建房表单也复用单人模式的武器选择控件。建房表单通过信号传递选择结果，控制器处理连接请求，并将房间状态交给卡片和等待室。对局控制器将服务器的回合状态转换为中央提示、比分和结算列表。[地图选择](../ui/map_picker.gd) · [武器选择](../ui/weapon_picker.gd) · [大厅视图](../ui/screens/lobby_view.gd) · [回合界面数据](../scenes/round_projection.gd)

## 对局加载

单人和联机进场共用加载界面，依次显示准备、构建、挂载和就绪。场景构建与挂载在主线程分阶段执行，切换期间的联机消息由 `NetSession` 暂存。构建失败时，加载界面会显示错误和返回按钮。返回主菜单或大厅时会短暂显示过场遮罩。[加载流程](../core/present/scene_transition.gd) · [联机会话](../core/net/net_session.gd)

## 对局 HUD

单人和多人共用玩家状态面板。生命条按实际生命值上限绘制，近期损失的生命值闪白后淡出。氧气回满时氧气条淡出。武器栏按背包容量和各武器占用的格数绘制，并高亮当前装备的武器。弹药单独显示。单人面板显示当前关卡的累计击杀数。[玩家 HUD](../ui/hud/hud.gd)

多人模式共用延迟显示和中央提示，比分、断线提示及排行榜随对战状态更新。圆形小地图以本地角色为中心，覆盖半径为 50 格。角色标记颜色按队伍或模式确定。设置分别控制小地图、其他玩家的地图标记、头顶生命条和弹丸轨迹。[联机 HUD](../ui/hud/pvp_hud.gd) · [小地图](../ui/hud/minimap.gd)

单人和 Beta 对战中，怀表用白色短针显示时间颗粒余额比例，用红色长针显示短期消耗和透支。表盘中央显示剩余额度，透支时显示红色负数。[怀表 HUD](../ui/hud/watch_hud.gd)

## 主题与设置

共享主题定义按钮、面板、输入框和开关的外观。按钮变体继承通用样式并设置各自的状态。`UiFactory` 使用同一主题创建动态控件。界面和世界中直接绘制的文字均使用同一个字体资源，以 Less Perfect DOS VGA 为主字体，中文使用 GNU Unifont 或系统字体回退。[主题](../ui/theme/menu_theme.tres) · [控件工厂](../ui/factory/ui_factory.gd) · [字体资源](../assets/fonts/menu_font.tres)

显示设置提供全屏以及 1280×960、1600×1200、1920×1440、2560×1920 四种 4:3 窗口尺寸。窗口按屏幕工作区缩放并居中，逻辑视口仍为 1920×1440。窗口、音量和重新绑定的按键保存在 `user://settings.cfg`。[设置](../core/config/settings.gd) · [默认操作](player.md#默认操作)
