# 界面与交互

主菜单提供单人开局、多人模式与 Beta。单人开局可以选地图和禁用武器。联机大厅按 1v1、团队和大乱斗筛选房间，加入使用 8 位房间号。等待室标题可复制房间号，团队房提供选边按钮。开始按钮根据服务端返回的开局资格显示给房主，持有效凭据的玩家可从房间卡片重连。 [大厅](../scenes/mp_lobby.gd) · [对战模式](modes.md)

对局界面随玩法显示生命值、氧气、装备与弹药，满氧时单人氧气条淡出。1v1、团队和大乱斗共用联机 HUD 的延迟显示和中央广播，比分、断线提示和排行榜随玩法显示。多人小地图以本地角色为中心，半径为 50 格，标记颜色按玩法和队伍区分。小地图、其他玩家标记、头顶生命条及弹丸轨迹可在设置中调整。 [单人 HUD](../ui/hud/hud.gd) · [联机 HUD](../ui/hud/pvp_hud.gd) · [小地图](../ui/hud/minimap.gd)

显示设置支持全屏和四档 4:3 窗口，分别为 1280×960、1600×1200、1920×1440 和 2560×1920。窗口按屏幕工作区缩放并居中，逻辑视口尺寸保持固定。显示、音量与可重绑按键保存于 `user://settings.cfg`。 [设置](../core/config/settings.gd) · [默认按键](player.md)

`UiFactory` 提供面板、标题、按钮与界面配色。`PixelFont` 使用 Less Perfect DOS VGA，中文回退至 GNU Unifont 和系统字体，字体关闭抗锯齿、微调与子像素定位。 [控件工厂](../ui/factory/ui_factory.gd) · [字体](../core/present/pixel_font.gd)
