# 界面与交互

主菜单提供单人开局、多人模式与 Beta。单人开局可以选地图和禁用武器。联机大厅按 1v1、团队和大乱斗筛选房间，加入使用 8 位房间号。等待室标题可复制房间号，团队房提供选边按钮。开始按钮根据服务端返回的开局资格显示给房主，持有效凭据的玩家可从房间卡片重连。 [大厅](../scenes/mp_lobby.gd) · [对战模式](modes.md)

单人开局和建房共用禁用武器列表。表单发出用户选择。大厅控制器处理建房、加入和重连，并把已整理的房间信息交给房间卡片与等待室。对战控制器把服务端的回合状态转换为广播文案、记分和结算行。 [武器列表](../ui/weapon_picker.gd) · [大厅视图](../ui/screens/lobby_view.gd) · [回合显示数据](../scenes/round_projection.gd)

单人和多人共用角色面板。生命条按实际最大生命值绘制，保留受击闪白和淡出。氧气条在满氧时淡出。装备格和武器列表根据当前背包容量、武器种类和选中位一起刷新，弹药量单独更新。单人关卡累计击杀数，角色面板显示计数。1v1、团队和大乱斗共用联机 HUD 的延迟显示和中央广播，比分、断线提示和排行榜随玩法显示。多人小地图以本地角色为中心，半径为 50 格，标记颜色按玩法和队伍区分。小地图、其他玩家标记、头顶生命条及弹丸轨迹可在设置中调整。 [角色面板](../ui/hud/hud.gd) · [联机 HUD](../ui/hud/pvp_hud.gd) · [小地图](../ui/hud/minimap.gd)

显示设置支持全屏和四档 4:3 窗口，分别为 1280×960、1600×1200、1920×1440 和 2560×1920。窗口按屏幕工作区缩放并居中，逻辑视口尺寸保持固定。显示、音量与可重绑按键保存于 `user://settings.cfg`。 [设置](../core/config/settings.gd) · [默认按键](player.md)

菜单和大厅的按钮、面板、输入框与开关样式集中在共享主题中。按钮变体继承通用按钮样式并覆盖各自的状态差异，`UiFactory` 用同一主题创建动态控件和读取界面配色。场景、动态控件和直接绘制的文字都使用同一个字体资源。它以 Less Perfect DOS VGA 为主字体，中文回退至 GNU Unifont 和系统字体。 [主题](../ui/theme/menu_theme.tres) · [控件工厂](../ui/factory/ui_factory.gd) · [字体资源](../assets/fonts/menu_font.tres)
