# 界面视觉验收

适用于 UI v2 迁移、界面返修和地图编辑器改版。验收要看实际渲染画面，并按 [界面视觉检查方法](ui-visual-review-method.md) 定位问题。

## 截图与复现

1. 分别在 1920×1440 和 1280×960 的窗口中截取实际场景画面，记录入口和操作。至少覆盖空列表和有内容两种状态，按页面补充加载、错误、禁用等状态。
2. 分别加载联机大厅和实际对局场景，或用临时测试数据复现待验收的界面状态。等待布局完成及 `RenderingServer.frame_post_draw` 信号，再从根视口导出 PNG。
3. 截图保存在工作区 `.tmp/`。验收记录给出路径、分辨率、界面状态和发现的问题。补拍修正前后的同状态画面，便于复查。

## 检查项

| 范围 | 检查 |
| --- | --- |
| 布局 | 内容居中且合理限宽，容器间距一致，弹层完整显示。缩小窗口后无裁切、叠字、布局溢出或交互遮挡。 |
| 字体 | 中文、英文和数字均可识别，次级信息与背景有足够对比度。28/40 等档位按 1:1 截图确认笔画。 |
| 控件 | 主操作、次要操作、危险操作和图标按钮的样式可区分。列表和卡片的悬停、按下及禁用状态清楚，缩略图保持比例。 |
| 大厅 | 房间列表为空、按模式筛选、连接失败、满员、对局中、等待开局及断线重连。另检查房主能否开局，以及关闭局域网广播后能否通过房间号加入。 |
| 对局 | 低生命值和弹药不足时的提示，以及换弹、拾取、倒地、比分和结算。检查 HUD 与场景内提示的遮挡关系。 |
| 编辑器 | 工具栏、图层、点位类型、文件选择、保存状态，以及结束试玩后返回编辑器。 |
