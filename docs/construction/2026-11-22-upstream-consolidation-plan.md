# 上游玩法与联机迁移

2026-11-22 立项，2026-11-24 更新。配置、武器、移动、输入和局域网发现已合入迁移分支，验收进度见下文。

## 分支基线

在上游 `siri` 的玩法和网络实现上迁入 `main` 的数值配置与操作手感。本地早期迁移保存在 `archive/siri-migration-2026-11-22`。本次整理以联机输入时序提交 `0a5946b5` 为起点。

关卡继续使用七层 CYRM 地图、16 像素子格、`CyrmMap` 读写和现有编辑器数据接口。角色移动从 `Terrain` 查询子格，联机客户端用 `CyrmMap.from_bytes()` 读取服务器的开局地图。编辑器的界面迁移另见 [UI v2 迁移计划](2026-11-23-ui-full-replacement-plan.md)。

## 迁移范围

| 模块 | 交付 | 验收重点 |
| --- | --- | --- |
| 数值配置 | 玩家、世界、敌人和时间参数迁入 Godot 自定义资源。玩家和世界脚本直接引用资源，`EnemyParams` 和 `TimeParams` 保留既有访问接口。 | 修改 `.tres` 后重启生效，清点旧常量引用，运行模拟、预测与编辑器测试。 |
| 武器 | 8 种武器各用一份 `WeaponDef`，由 `WeaponCatalog` 引用。注册表提供只读武器定义。 | 逐项核对 `main` 数值及上游保留项，重点检查 M82A1 瞄准线、复合弓搭箭拉弦和 M249 开火反馈。 |
| 移动与碰撞 | 玩家与敌人可穿过彼此，接触伤害覆盖两队。低台阶直接迈上，48/64 像素台阶自动跳跃，空中卡在浅台沿时向上修正。 | 对照单人和联机预测，确认触碰伤害、双方队伍碰撞选项及台阶回放。 |
| 输入 | 默认用空格跳跃、上攀和上浮。双击同一方向键触发横冲，继续支持重绑和单独绑定修饰键。 | 检查默认键位、重绑、梯子和水中移动、双击横冲及下冲。 |
| 局域网 | 房主每秒广播，客户端按房间号更新列表，3 秒未收到广播则移除。点击卡片优先直连，失败后走 EasyTier。 | 验证发现、刷新、关房消失、直连进场、关闭广播后手输房间号和断线重连。 |

配置迁移先于移动和碰撞调整，方便复用重力、台阶高度等参数。局域网发现沿用现有房间协议、等待室和重连流程。录像、倒带和渲染管线有各自的实施计划。

## 验收记录

- 上游基线要求重新构建原生扩展，确保包含 `CyrmStorage`，并通过 CYRM 地图往返与编辑器测试。
- 原迁移记录已勾选资源化、移动和台阶、默认键位、LAN 自动化测试，以及双实例发现、加入和关闭广播后手输房间号。
- 武器资源逐字段比对，以及独立设备间的 LAN 测试仍由集成验收清单跟踪。自动化 `lan` 组检查广播包与列表状态，实际网络收发由双实例或双机测试覆盖。
- 集成验收运行默认八组 `run_checks.py` 和 `check_naming.py`，再检查主菜单、地图编辑与试玩、昼夜过渡和联机断线重连。
