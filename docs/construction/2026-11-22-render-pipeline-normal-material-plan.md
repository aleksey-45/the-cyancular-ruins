# 初版渲染管线方案

2026-11-22，历史方案。适用于当时的本地 `siri` 迁移分支。当前实施范围见 [B-1 实施计划](2026-11-24-render-b1-plan.md)。

初版希望以法线、材质和自发光贴图取代 FormLight 及旧玩家着色路径，同时保留精灵合批和屏幕后期。对象提供基色和材质信息，多张辅助视口纹理送入后期着色器，由全屏通道计算光照并合成画面。

| 视口 | 初版拟收集的数据 |
| --- | --- |
| 世界视口 | 天空、背景、地形、角色和特效颜色。 |
| 法线与材质视口 | 像素法线和材质遮罩，后期据此区分受光表面。 |
| 自发光视口 | 自发光及可单独合成的效果。 |
| 输出视口 | 合成世界颜色、光照、自发光和已有屏幕特效。 |

初版计划先建立视口和调试输出，再分阶段迁移角色、地形、水体、敌人和武器。图集需要统一帧区域和边缘留白，检查相机同步、像素采样、角色翻转与武器挂点。最终要比较半分辨率和全分辨率的效果，检查移动端帧时间并保留旧着色路径供切换。

上游之后加入了昼夜光照、视差、地形与水体的独立绘制。重复绘制与全屏材质光照的成本需要重新评估，详见 [基线复盘](2026-11-24-render-plan-review.md)。
