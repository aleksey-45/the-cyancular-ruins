# B-1 二维光照实施计划

让木料、石材、羽毛和金属在日光下呈现不同的高光，让路灯照亮附近的地面、角色和水体。现有昼夜光照和玩家眼灯见[渲染文档](../render.md)。

| 阶段 | 待实现内容 |
| --- | --- |
| R0 图集与着色 | 用 `AtlasStyle` 关联基色、法线和材质图。地形、水体和精灵的着色器按各自图集的分辨率采样，计算环境光与方向光。同一图集内可逐像素连续调整镜面高光强度与粗糙度。调试视图分别显示法线、高光强度和粗糙度。 |
| R1 玩家与武器 | 为玩家补充材质图，用遮罩控制眼睛像素的自发光。为武器补充与基色对齐的法线图和材质图，分别表现枪身和握把。 |
| R2 地形与水体 | 为地形图块、梯子、铁链和水体补充法线与材质数据。水面沿用流动水纹，叠加随日照方向变化的高光。 |
| R3 路灯与合成 | 用 `WorldLight` 定义路灯的位置、颜色、半径、强度和衰减。在随世界摄像机移动的低分辨率 `LightViewport` 中绘制有色光斑。后期合成限定在受光的世界表面，天空、视差背景和 HUD 各自绘制。提供光照纹理调试视图。 |
| R4 敌人与精灵合批 | 为跳鸟、飞鸟和乌鸫接入法线图和材质图。将玩家身体并入按图集材质组织的精灵批次，移除 `PLAYER_BODY` 专用绘制通道。 |

首批地形图块按 R2 的实际画面选定。R3 以 60 帧/秒为目标，根据光斑边缘和帧耗时确定视口分辨率、合成遮罩和同屏可见灯数上限。

动态阴影、光照遮挡、全屏法线缓冲和全局自发光通道留作后续候选。
