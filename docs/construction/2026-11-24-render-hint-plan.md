# 像素材质与局部灯方案记录

2026-11-24。记录从轻量材质着色到 B-1 的选型过程。实施与验收见 [B-1 实施计划](2026-11-24-render-b1-plan.md)和[技术规格](2026-11-24-render-b1-spec.md)。

## 素材选择

地形、角色、敌人和武器使用与基色图集对齐的法线贴图、材质数据贴图。法线以手绘为主，可以用 Laigter 辅助起稿。绘制时保留原像素网格、帧区域和轮廓，检查水平翻转与旋转后的受光方向。高光强度和粗糙度采用逐像素连续值，同一张图集可同时表示金属、木料和石材。

环境色目前会经过 `CanvasModulate` 或各对象的着色路径。接入对象着色器时要确认最终由哪一层应用环境色，避免同一表面被压暗两次。测试应在同一场景对照地形、角色、敌人和掉落武器。

## 局部灯选型

| 方案 | 玩家看到的效果 | 取舍 |
| --- | --- | --- |
| 灯具自发光和光晕 | 能看出灯开着，周围物体亮度基本不变。 | 资源成本低，适合纯装饰灯。 |
| B-1 低分辨率光照纹理 | 路灯为附近地面、角色和水体叠加有色光斑。太阳光继续使对象产生方向高光。 | 局部灯只需维护一张光照纹理，能保留地形与精灵各自的像素颗粒。 |
| B-2 局部灯计算法线光照 | 光源移动时，金属和起伏表面随方向变化产生高光。 | 要增加对象逐灯计算或全屏法线读取，同时维护边缘、遮挡、相机同步和性能预算。已结束评估。 |

B-1 的静态灯来自地图或场景，动态灯可由表现层实体提供。局部灯表示颜色、位置、半径、强度和衰减，使用夜间系数调整亮度。自发光范围收敛到玩家眼睛。天空和视差背景保持原有昼夜配色。

术语参考 [Godot 2D 灯光和阴影](https://docs.godotengine.org/zh-cn/4.x/tutorials/2d/2d_lights_and_shadows.html)和[Unity 精灵图集](https://docs.unity3d.com/cn/2021.2/Manual/class-SpriteAtlas.html)。
