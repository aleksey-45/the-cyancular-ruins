## 实现约定

- 菜单、复杂 HUD 和弹窗可用 `.tscn` 组织。简单控件通过 `UiKit` 构建，通用样式放在主题中。
- 页面优先使用容器布局，HUD 用锚点和设计规范里的间距。画布和自绘区域可使用局部坐标。迁移期旧页面继续使用兼容接口，新页面直接用 v2 控件。
- HUD 和结算从 `MatchFrame`、`RoundProjection` 读取展示数据，大厅使用 `LobbyProjection`。图层、点位与保存状态由编辑会话提供。界面负责展示状态和发出操作信号。
- 编辑器先迁外围界面，再迁工具与对话框。验收覆盖地图读写、撤销重做、画布操作、出生点放置和从选中点位试玩。

## 发布前验收

- 按 [界面视觉验收](ui-visual-qa.md) 检查主菜单、设置、单人启动、联机、HUD、暂停、结算和编辑器。记录实际截图、测试窗口尺寸和问题单。
- 双实例分别验证公开房间、关闭广播的房间、等待室、开局和断线重连。
- 运行八组自动化测试并检查场景能否正常加载。确认新界面无旧绝对定位 API 依赖，清理迁移期兼容层。
