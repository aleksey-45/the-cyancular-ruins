# 本地预测与交互代理

客户端完整预测本地角色及其武器、账户和已知攻击对自身的影响；服务端完整裁决所有角色。远端角色在客户端提供只读运动代理，显示使用独立插值状态。

## 状态归属

| 数据 | 处理方式 |
|---|---|
| 本地角色 | 保存完整模拟状态、输入游标、武器和背包，按固定 tick 预测 |
| 远端角色 | 从权威状态构造原生运动轨迹，按明确 tick 和阶段读取位置、碰撞姿态；不执行其完整武器、伤害和账户玩法 |
| 已知攻击 | 推进弹丸、引信、光束和爆炸，记录本地命中与地形影响，按身份和 tick 确认 |
| 地形 | 原生权威基线、预测差分与历史；碰撞改变在后续查询前提交 |
| 表现 | 精灵、插值、视觉偏移、音效、HUD；不回写模拟状态 |

远端代理会计算地形约束运动，但未知的远端输入和击退仍可能使估计失效。代理不等于另一份完整权威角色。移动依赖角色执行顺序：本地阶段前已经步进的角色读取当前 tick，尚未步进的角色读取前一 tick。远端回溯路径也按对应阶段采样。

## 接纳与重放

每个 process frame 只接纳一批网络结果，在首个物理回调开始处理；没有物理回调时由普通回调处理。之后到达的请求进入下一批。STATE 与可靠战斗结果共用最早失效 tick，不为每条消息单独恢复。

接纳依次检查 epoch、权威覆盖、快照序号、地形版本、同 tick 锚点、ACK 后有效命令及实际查询结果。查询包含轴向阻挡、起身重叠、弹丸接触、射手回溯状态，也包含原先没有命中的查询。只有已发生的接触记录不足以证明复用安全：新代理可能进入原本为空的路径。

锚点与后续依赖都相同时保留预测；发生变化时保留有效前缀，从最近有效检查点重算后缀。缺少历史、epoch 改变、模式改变、锚点不一致或检查点不可恢复时采用权威锚点。具体比较契约见[历史复用](prediction_reuse.md)。

## 窗口与表现

本地预测领先窗口与代理运动历史最多 32 tick。远端显示缓冲为 6 tick，外推最多 6 tick；显示窗口不代表碰撞预测能精确猜中 6 tick 的未知操作。

恢复和重放执行模拟规则，不能重复播放枪声、命中特效、爆炸或更新整套 HUD。表现读取最终模拟状态；物理根节点保持逻辑坐标，本地 Visuals 的平滑偏移独立衰减，枪口计算剔除该偏移。
