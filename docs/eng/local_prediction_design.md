# 客户端预测世界

客户端用一个 PredictionWorld、一个整数 tick 和一份世界历史推进预测。服务端仍完整裁决所有角色；客户端完整预测本地角色、武器、账户和已知攻击，只估计远端运动。远端显示使用独立的 SnapshotBuffer。

## 所有权

| 模块 | 职责 |
|---|---|
| PredictionRollback | 本地输入、目标时钟、ACK/epoch、纯数据比较和重放起点；外层循环追赶目标 tick |
| PredictionWorld | 稳定角色槽、排序角色表、唯一模拟 tick、阶段调度、整世界捕获和恢复；持有最新回溯路径指令 |
| PredictionActorState | 远端运动与控制的固定槽定义、权威投影、比较及恢复 |
| PredictionHistory / PredictionFrame | 64 tick 世界检查点；发布后只读 |
| PlayerReplica | 插值位置、动画、武器外观及特效；没有物理体和模拟游标 |

本地 Player 和远端 ActorBody 共用 ActorBody 的运动配置与 actor_hulls.tscn 形状。物理 RID 由 ServerBody 创建和释放；远端槽归预测世界，对局内保持稳定，角色离场时撤下碰撞层。显示副本的创建、隐藏和释放不改变角色碰撞。

## 唯一 tick 顺序

正常推进、时钟追赶、STATE 校正和事件重放都调用 PredictionWorld.step_tick：

1. 按 role 升序推进角色一次。本地执行 ActorStep 与武器，远端延续已知持续输入与移动倍率，只执行运动；正在 Beta 回溯的角色跳过普通运动。
2. 每个角色之后同步其 RID，再结算该 role 的已知光束和时间奖励。较小 role 自然处于当前 tick，较大 role 仍处于前一 tick。
3. 全部角色阶段结束后，在 Beta 阶段应用已知回溯结点与弹丸回溯事件，再推进本地账户。
4. 全部弹丸按 ID 推进及结算直接命中，随后按到期时刻与 ID 结算爆炸。结算对应阶段奖励。
5. 在已知复活 tick 的规则阶段撤下旧角色碰撞，等待权威提供新生位置；提交地形碰撞，更新世界 tick 并保存检查点。

本地回溯不停止世界时间，其他角色和攻击继续推进。远端不执行未知的武器边沿、伤害和账户玩法；这些未知量仍会导致正常的权威校正。

## 接纳与恢复

每个 process frame 接纳一批网络结果，STATE 和可靠事件合并最早失效 tick，同一批只恢复、重放一次。比较期间整个物理世界保持在预测末端，不因收到远端快照而改动位置。

复用要求同 tick 本地完整状态、输入游标、远端运动及控制、角色集合与碰撞层、弹丸、地形和本地账户全部一致。即使远端离得很远，其变化也会使世界后缀失效。没有按角色补算、动态依赖图或查询时延伸轨迹。

服务端回溯路径只含相对当前位姿的变化结点。客户端只比较权威 tick 到预测末端之间的结点；未模拟的未来尾部更新直接接纳。路径是已知指令，不属于检查点的历史状态，恢复检查点继续使用最新接收的路径。

STATE 不一致时恢复该 tick 的完整世界并重放后缀；只有事件变化时恢复事件前一 tick，再经同一个循环推进。首次同步、epoch 变化和历史窗口过期由权威入口重建。恢复内部直接读取该检查点的完整状态，不选择最近锚点、清零速度或冻结角色来掩盖缺失历史。

## 窗口与表现

预测领先上限 32 tick，世界历史保留 64 tick。远端显示延迟和最大外推各 6 tick，与物理时间线独立。重放抑制重复音画，表现读取最终模拟结果；本地 Visuals 平滑偏移不写回根节点，枪口计算剔除视觉偏移。
