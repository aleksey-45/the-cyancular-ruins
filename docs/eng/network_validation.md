环境为 Godot 4.7.1、Windows x64、官方 EasyTier 2.7.0。线上协议为固定二进制布局、ACK 快照差量与 ENet Zstd；设计见 [联机系统](netplay.md)。

## 传输计量

种子 123456，使用固定真实对战消息轨迹回放二进制差量和 Zstd。回放 ACK 基线年龄固定为三个快照间隔（100 ms），生产使用实际解码 ACK。

统计所有 peer 的 HOST_TOTAL_SENT_DATA/PACKETS，包含 ENet 头、ACK 和重传。IP/UDP 与 EasyTier 外层封装单独于此统计。接收端逐份比较解码后的完整 STATE，缺失基线次数为零。

CPU 表示单个回放进程中全部 peer 的编解码与发送开销；帧耗时包括 poll、编码、发送和 flush。Windows CPU 计时粒度约 15.625 ms，短基线的零读数受此限制。包数和可靠重传受本机调度影响，数据为每个人数的一次传输样本。
