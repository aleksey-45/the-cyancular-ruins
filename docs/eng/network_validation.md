# 联机网络测试与性能验证记录

测试环境基于 Godot 4.7.1、Windows 10 64位操作系统以及官方 EasyTier v2.7.0。网络通信采用二进制数据编码、基于 ACK 确认的增量快照差量压缩及 ENet Zstd 包级压缩。具体架构设计请参阅 [联机系统说明](netplay.md)。

## 二、 本地移动与预测平滑表现

客户端收到 STATE 快照后暂存最新权威状态，在下一物理帧恢复并重放未确认输入。本地视觉表现根据实际预测时钟采样最近一帧位移，50ms 内平滑衰减网络修正偏差。镜头跟随 `Visuals` 表现节点；物理位置、碰撞与弹道完全基于逻辑模拟状态。

在真实 ENet 网络环境下执行持续移动测试（包含 0.96 倍与 1.02 倍预测时钟调速），连续两轮测试指标如下：

## 五、 角色物理与公网中继验收（2026-10-15）

服务端角色由权威世界每 tick 调度一次，真人与 AI 的角色物理回调均关闭。持续输入、关闭重力与碰撞的场景测试中，水平速度为 700 px/s，60 tick 的实际位移为 699.9977 px。远端阻挡体的五种姿态与角色场景逐顶点比较，世界空间轮廓一致。

本轮 2 人对局、6 人团队（80 ± 15 ms RTT、5% 丢包）与 8 人大乱斗（150 ± 25 ms RTT、5% 丢包）均完成换回合、Beta、断线重连和返回原房间；8 人局额外注入 750 ms 积压突发释放及 250 ms 断流。停止输入后的收敛误差均为 0。网络专项 7/7、视觉 8/8、波动链路单测 5/5、网络统计单测 4/4 通过；EasyTier 直连、中继文件日志和 Windows 六种进程退出场景通过。

公网测试使用正式源码副本、真实地图 `newfactory.cyrm`、8 个独立客户端和 120 秒自然结束的大乱斗。测试关闭 P2P 与 STUN，客户端分别指定以下 UDP 中继，服务端保留完整候选列表；路径采样确认三个中继同时承载对局流量。此处为测试指定路径的分组结果。

| 客户端数 | 公网中继 | 各客户端平均 ENet RTT | 停止后静止位置误差最大值 |
|---:|---|---:|---:|
| 3 | `udp://et.basd1.de:11010` | 75.9–83.9 ms | 0 px |
| 3 | `udp://183.230.36.171:11010` | 88.6–93.7 ms | 0 px |
| 2 | `udp://us01.225284.xyz:11010` | 429.8–436.5 ms | 0 px |

8 名客户端均完成结算并返回原房间，9 个游戏进程正常退出，测试进程全部回收。服务端实测 60.0008 Hz，输入队列峰值 8，地形版本由 0 推进至 132。ENet 实际发送流量平均 839.0 kbit/s、1 秒采样峰值 1029.8 kbit/s，包含 ENet 头、ACK 与重传，不含 EasyTier 和外层 IP/UDP 头。

有效计量窗口内各客户端播放断供占比为 0%–0.427%；该指标统计播放达到外推上限、连续停止至少 50 ms 的时段，剔除客户端或服务端 50 ms 长帧附近各 200 ms，加载与停止输入阶段不计入。它只衡量播放缓冲断供。静止位置误差在停止输入 4 秒后、同一控制阶段且权威速度为零时取样。

原始日志与源码校验值保存在本机 `.test_logs/net_compare/relay_brawl/20261015_094242/`。所有客户端、服务端和 EasyTier 位于同一台 Windows 电脑、共用公网出口，流量实际经过公网中继；该测试覆盖此路径与负载下的表现。
