## 九、 统一真实对局夹具与公网中继验证（2026-10-21）

`run_matches.py` 统一运行普通对局、帧率检查、分档矩阵及 EasyTier 直连/中继。所有场次使用正式房间、权威世界和客户端，固定输入驱动移动、跳跃、攀爬、交火与 Beta 技能。游戏负责伤害、地形、死亡、复活和自然结算；隧道子进程使用正式会话生命周期。

八客户端公网 UDP 中继、Beta 大乱斗 120 秒复测通过，总墙钟 128.53 秒。客户端均自然结算并返回原房间；一次主动断线使用 token 重连，收到第二份基线和 3,291 份后续 STATE。停止输入后的最终误差均为 0 px，各有 85–90 个有效预测采样。武器节点/背包一致性、重复开火和渲染期间物理移动断言通过；九个 EasyTier 子进程已退出。
