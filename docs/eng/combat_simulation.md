# 武器、战斗与历史

## 模块边界

| 模块 | 职责 |
|---|---|
| `ActorBody` | 一次调用推进角色计时器、武器和运动 |
| `WeaponBody` | 弹药、冷却、换弹、瞄准、开火缓冲、后坐力和稳定弹丸初态 |
| `BulletBody` | 弹道运动、引擎命中分类、引信与反弹 |
| `ProjectileEntry` | 弹丸生存期、tick 与确认字段；节点只按需弱引用 |
| `CombatSimulator` | 逐攻击身份的推进、命中归属、爆炸、光束与确认结果 |
| `PredictionWorld` / `PredictionHistory` | 全部角色、弹丸、控制、游标与地形版本的世界捕获、保存和恢复 |
| `PredictionFrame` | tick 结束时的全部角色、控制、弹丸、地形及本地账户检查点 |
| `ProjectileSnapshot` | 每帧独占的 id 到连续弹丸数值槽的表，直接比较权威状态并恢复弹丸 |

武器参数来自 WeaponRegistry 和武器场景，不在代码里维护第二张数值表。脚本管理背包、场景装配、输入时钟、账户、网络接纳、重放外层循环和表现。

## 命中几何

弹丸用 `PhysicsServer2D.body_test_motion()` 连续扫掠，位置始终是规范坐标，因此高速弹丸不会只采样终点。单 tick 位移超过 `CollisionWorld.SEAM_REACH` 时按接缝拆成有限段：每段都在镜像覆盖带内求解，越过边界后立即回绕，避免一次走完时跳过对侧空档、漏掉规范世界里的中部形状。所有出口（移动、反弹、地形命中、角色命中、射程结束）都回绕到规范区间，视觉偏移只平移渲染子节点。

命中后先按碰撞节点判定归属：角色体写入 `impact_role`，再决定反弹、短引信或终止；地形命中保持 `impact_role = 0`。榴弹撞角色同样带着归属进入权威端的直击分支。`finished`、`exploded`、`direct_hit`、`impact_role` 各自独立，射程、俯仰、反弹和水中阻力仍由玩法层决定。

穿透由层与显式排除给出：弹丸只在对手队伍对应的层上取 mask，射手真实体（含镜像槽）加入碰撞例外；倒地与回溯免疫由结算规则跳过，不再靠第二套几何判定。

角色与弹丸共用 `CollisionWorld.move_body()` 的 RID 运动求解，命中归属通过物理体的 object instance ID 读取。

## 爆炸与光束

瞬时爆炸有两条目标枚举路径，规则完全相同：

- **联机权威**：`AuthorityWorld` 把玩家表交给 `apply_aoe()`，按 role 升序直接对每个角色做中心距离判定，不做形状查询。目标集合本来就已知，物理候选查询只会增加分配、RID 反查和 32 结果上限带来的漏检。
- **单人**：用可复用圆形的 `intersect_shape()` 取候选 RID，爆心贴接缝时同时查询镜像位置并按 RID 去重。

两条路径之后都只做一次瓦片扫描；遮挡用 `intersect_ray()` 并按环面最短位移分段。内圈免疫遮挡、衰减、击退、水域与瓦片扣血仍是原业务规则。同一角色的接缝镜像会重复出现，按角色去重，不会多次扣血。

光束几何由 `Terrain.trace_beam()` 的引擎射线给出，目标接触由 `CollisionWorld.beam_contacts()` 唯一给出：每条线段用一个沿段旋转、宽度等于走廊的矩形一次取完所有相交形状，起点补圆帽覆盖已经重叠的目标，跨接缝的线段先拆段映射回规范区间，接触点在每个规范子段内先投影、再加上该子段相对原始连续光束的偏移，因此跨接缝命中仍落在连续光束上。`cast_motion()` 只给首个安全比例且不报告起点重叠，因此不再用它枚举目标。单人、权威服务器和预测端消费同一份结果，并按角色去重。

预测端每束激光每 tick 只做一次全角色接触采集（`beam_role_contacts()`），得到角色到接触点的映射，本地结算只取自己的那一条。

## 顺序与副作用

攻击按两个阶段推进：先按攻击身份升序推进全部弹丸并结算直接命中，再按 (due_tick, entity_id) 结算全部到期爆炸。爆炸在触发 tick 直接广播视觉，伤害、击退与地形破坏延迟到 t+3；同一结算 tick 已有权威 HIT 时只应用权威绝对 HP，未来 tick 的 HIT 不会取消本 tick 的预测。单个爆炸内部不刷新地形碰撞；PredictionWorld 在 tick 末尾统一提交。模拟输出带攻击身份和 tick 的结果，外层根据首次预测、权威确认与静默重放决定音画。



物理查询依赖记录已随碰撞代理删除；复用只比较数据，见[预测历史](prediction_reuse.md)。

服务端与预测端同阶段：所有弹丸按 ID 升序推进并结算直接命中，然后按 (due_tick, entity_id) 结算到期爆炸；爆炸产生的地形碰撞只在 tick 末尾提交一次。因射程、地形或爆炸而结束的弹丸不再推测直击；已有权威命中仍优先应用。权威 ACK 裁剪已覆盖的命中、爆炸和光束，未来确认保留。
