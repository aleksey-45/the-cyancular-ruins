# 测试经济学

> 一条守卫要被**保留**,必须**同时**过 K 组;命中 D 组任意一条,就是**删除候选**。
> 总判据:能回答「去掉什么它才会红」;答不出 ⇒ 删。怎么跑见 [`tests.md`](tests.md);已知红见 [`registered-debt.md`](registered-debt.md)。

## 1. 桶选择

桶由「要什么资源」决定,不由「测多少代码」决定。

| 桶 | 资源边界 | 形态 |
|---|---|---|
| **冒烟** | 单进程;被测代码与测试同进程;不碰网络 / 磁盘 / 真场景实例;autoload 未实例化 | `tests/smoke/*.gd`,`-s` |
| **场景探针** | 单机、真场景树:真实例化 `.tscn`,走 `_ready` / 信号 / 资源加载 / 渲染 | `tests/probe/*.tscn` |
| **真链路** | 跨进程 + 真端口 + 真协议 | `tests/{smoke,probe}/*.sh` |

| 你要证明的东西 | 写在哪 |
|---|---|
| 纯逻辑:解析 / 编码解码 / 数值与公式 / 几何计算 / 状态机迁移 / 规则判定 | 冒烟(`-s`) |
| 真实例化场景、节点生命周期、信号、资源加载、UI 树 | 场景探针(`.tscn`) |
| 真端口 / 真子进程 / 真协议握手 / 真对局 | 真链路(`.sh`) |
| 配色 / 版式 / 手感 / 观感 / "好不好玩" | **都不写** —— 这类没有自动化判据,只能人眼与试玩 |

## 2. D 组(删)

| # | 判据 |
|---|---|
| **D1** | 答不出"去掉什么它才会红"(恒真 / 空转) |
| **D2** | 断言数为 0,判词靠 `print` 的字面量、由入口 grep 它 |
| **D3** | 钉死"会被反复调整"的数值 / 时序 / 手感 |
| **D4** | 与别处同源重复(同一个事实两份断言) |
| **D5** | 只证明引擎 / 框架 / 第三方库的行为,不证明本仓契约 |
| **D6** | 靠"读源码文本"判形态(测的是"有没有写那段字",不是行为) |
| **D6a** | D6 里判的是**风格 / 东西住在哪** ⇒ 删;先问同区域有没有行为替代 |
| **D6b** | D6 里判的是**顺序 / 推导**、承重又无廉价行为观测 ⇒ **不许删**;但文件头必须写明「代理判据:读源码文本,不是行为;行为证据见 `<真链路脚本>`」,且判词不可读成"功能没问题" |
| **D7** | 真机不可达的防御分支的守卫 |
| **D8** | 单文件 > 600 行且断言密度低 |
| **D9** | 一条判定类别拆成 N 条"一个数值一条断言" |

## 3. K 组(留)

| # | 判据 |
|---|---|
| **K1** | 能红,且红起来指向一个具体缺陷(不是"某行字变了") |
| **K2** | 测的是本仓契约(协议字段 / 存档格式 / 回滚等价 / 环面几何 / 命中判定) |
| **K3** | 覆盖"改坏了很久才发现"的面:协议 / 输入包 / 回滚与快照 / 存档与地图格式 / 导出与裁剪 / 命中与碰撞 / 联机权威 |
| **K4** | 一条守卫覆盖一个判定类别,不是一个数值 |
| **K5** | 失败信息能让人直接知道去哪修 |

★ **保留上限**:每条守卫都要能算清"它挡住的是哪一种真实发生过或极可能发生的缺陷"。**算不出就不留** —— 这条优先于 D 组任何一条。

## 4. 数量纪律

- **一条判定类别 = 一条守卫**。
- **越高层越少**:端到端减到最低限度。
- **新守卫必须自带条数闸**(`EXPECTED_CHECKS` / `_checks >= N`),否则它的 `ALL-OK` 只等于"没有失败输出"(见 [`tests.md`](tests.md) 的「条数闸」)。
- **存量不追补**;但**新写的没有闸 = 不许进**。
- 加守卫必须能说出它挡的缺陷;"顺手加一条守卫"按违规处理。
- **能生成就别再加守卫**:同一个值要抄两处时,用单一来源 + 生成器 + `--check`,不要补一条盯着复本的守卫。
