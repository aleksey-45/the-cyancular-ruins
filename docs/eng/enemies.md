# 敌人系统

> 本文档属于 [`CLAUDE.md`](../../CLAUDE.md) 架构分域文档。
> 涵盖范围：敌人层次结构 · 基础实体物理与状态机 · 各类敌人行为特征 · 死亡物理与时间回溯状态保留 · 数据驱动注册机制。

---

## 一、 继承层次结构

敌人系统的继承关系如下：
```text
CharacterBody2D
 └─ EnemyBase (通用基础属性、状态机、物理模拟、受击与闪白)
     ├─ EnemyJumpBird (跳跃近战敌人)
     ├─ EnemyBlackBird (瞬移刺客型敌人，具备精英实体属性)
     └─ EnemyFlyBase (飞行与 A* 寻路基类)
         └─ EnemyFlyBird (巡逻飞行与抛物线投弹敌人)
```

---

## 二、 核心机制与基础行为 (`EnemyBase`)

1. **基础属性与状态管理**：
   - 导出基础战斗参数：生命值（`hp`）、接触伤害（`contact_damage`）、击退强度（`knockback_strength`）与击退衰减率（`knock_decay_rate`）。
   - 统一采用整型状态机 `state` 管理当前行为，各派生子类分别定义内部 `enum State`，并在每物理帧覆写 `_ai(delta)` 与 `_anim_update()`。
2. **受击与死亡表现**：
   - **受击闪白与死亡消解**：基类统一提供受击白闪（`_hit_flash_time = 0.1s`）与死亡白闪（`death_flash_time = 0.5s`）计时。渲染通过 `_flash_update()` 调节；对于黑鸟等挂载 Shader 的特殊实体，通过覆写着色器参数实现等效视觉反馈。
   - **转向防抖**：通过 `_set_facing()` 限制朝向翻转频率（两次翻转间隔必须不小于 0.5s），杜绝在玩家临界距离处的频繁视觉抖动。
3. **死亡物理与实体保留机制**：
   - 敌人生命值归零后保留其物理实体与重力碰撞计算，仅禁用其 AI 决策逻辑。阵亡实体继续受重力与击退衰减影响；后续受到攻击时仅结算击退冲击力，不再二次扣除生命值。
   - **时间回溯窗口期状态保留**：在单人模式启用回溯时（`WorldRewind.hold_corpses` 为真），窗口期内被击杀的敌人在死亡白闪结束后暂时隐藏视觉并将其碰撞层置为 0（`collision_layer = 0`），避免形成无视觉碰撞阻挡。当玩家触发时空回溯至其击杀前的时间点时，平滑还原其可见性与物理碰撞体。

## 三、 各类敌人行为特征

### 1. 飞行敌人 (`EnemyFlyBird`)
- **状态机流转**：包含沉睡（`SLEEP`）、起飞（`TAKE_OFF`）、巡逻飞行（`FLY`）、抛物线射击（`SHOOT`）、冲撞自毁（`CHARGE`）以及返航（`RETURN`）等状态。
- **弹道预测与攻击**：飞行过程中根据玩家当前移动速度与预测位移发射平抛抛物线子弹；当生命值低于 25% 时切换为单向冲撞状态，穿透无敌帧并在命中碰撞后自毁。
- **寻路与避障 (`EnemyFlyBase`)**：基于自身飞行碰撞箱及环境实体分布执行 A* 寻路；当陷入悬挑地形死区时执行水平脱困；支持站立与飞行碰撞箱的动态平滑切换。

### 2. 跳跃近战怪 (`EnemyJumpBird`)
- **行为模式**：地面巡逻、蓄力前跳、后撤步调整间距以及空中扑击。死亡后保留物理实体与常规地形碰撞。

### 3. 刺客精英怪 (`EnemyBlackBird` - 乌鸫)
- **精英属性标识**：在 `_ready` 中设置元数据 `set_meta("elite", true)`。精英实体免疫常规时空回溯（不被回溯倒放，保持自主行动），在时间加速状态下与玩家享有相同的加速倍率；被击杀后掉落 300 点时间颗粒结晶。
- **行为模式**：沉睡待机 → 随机巡逻游走 → 周期性评估玩家反方向 2~4 格的地板落点（结合视线检测）→ 蓄力瞬移起跳 → 隐匿并传送至预定坐标 → 空中显现落地 → 快速前冲攻击（造成无视普通无敌帧的高额伤害）→ 战术大后跳拉开距离。

## 四、 数据驱动配置与扩展规范

1. **敌人注册表单一来源 (`data/enemies.json`)**：
   - 新增敌人需在 `data/enemies.json` 的 `enemies` 数组中添加配置条目，声明 `id`、`name`、`scene`（场景路径）与 `color` 属性。
   - 关卡编辑器内嵌的敌人数据表由 `node level_editor/sync-enemies.js` 自动从该文件同步生成；执行 `--check` 参数可在不写入磁盘的情况下校验数据一致性。
2. **场景生成规范**：
   - 敌人生成器 `EnemySpawner` 动态读取已加载配置，随机检索开阔地板单元格（当前格为空气且下方为实体障碍）进行刷新布点。
