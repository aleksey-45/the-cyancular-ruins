# 关键行为检查

测试围绕输入时效、状态往返、历史隔离、地形恢复和共享模拟等关键契约。采用实际组件与小场景；完整对局只用于小场景无法验证的会话、传输或负载问题。

## 运行

先编译原生扩展并导入项目。一次 Godot 启动执行所选分组，30 秒超时，不自动重试。

```bash
python tools/run_checks.py --godot /path/to/godot
python tools/run_checks.py --godot /path/to/godot --groups net,terrain
node tests/editor_case.js
```

可通过 `GODOT` / `GODOT_EDITOR` 指定引擎路径。入口为 [run_checks.py](../../tools/run_checks.py) 和 [run.tscn](../../tests/run.tscn)。启动失败、脚本错误、断言失败或缺少完成标记均判失败。

| 分组 | 保护的行为 |
|---|---|
| net | 输入与动作去重、epoch、过期 ACK；INPUT/START 与房间信令协议；真实角色全量/差分等价、不同 peer 基线与历史隔离、弹丸增删；STATE 合并及事件屏障；环面插值与缓冲隔离 |
| terrain | 材料残血、碰撞失效范围、单人回溯、预测检查点和权威确认；v4 地图与有正确 CRC 的非法块 |
| simulation | 实际角色、武器和 Godot 物理下的移动、落地、弹药、带弹丸的恢复与复用等价、历史隔离及表现隔离；接触历史、空路径与射手回溯依赖失效、后缀裁剪及槽位复用；榴弹二进制场景往返、Beta 引信与爆炸结算；已结束弹丸的确认排序、光束 ACK 裁剪；单人和 Beta 回溯的完整恢复与归属 |
| monitor | 单位、样本分母、最大值、阈值、直方图、同帧累计、窗口轮换、停用和容量 |
| editor_case.js | v4 压缩/裸格式往返、CRC、内置地图、非法文本与备份路径；编辑器或地图契约变化时运行 |

每组释放场景并恢复共享配置，夹具使用小地形。测试和开发工具从导出包排除。CI 在 Windows/macOS 构建后各运行一次四组 Godot 检查。

## 选择与停止

- 按行为风险选择关联组，不按源文件数量补用例。
- 文档和注释改动检查准确性、链接及差异即可。
- 会话生命周期、传输接入或实际负载有明确风险时，选择一次代表性对局；公网不可用单独报告。
- 必要检查通过且没有未解释失败后停止，新修改或新失败才重跑关联项。
- 资源加载证明解析及引用可用，小场景证明其覆盖契约；两者都不能代替完整玩法验收。
