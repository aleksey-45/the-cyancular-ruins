# 出生事件与重放优化

2026-10-27。承接[物理回调检查](physics_callback_audit.md)，处理远端普通弹丸出生引起的无效本地重放，并降低必须重放时的重复地形工作。

## 出生事件先检查影响

[出生入口](../../scenes/pvp_match_client.gd)区分新身份、重复出生与 STATE 已覆盖的出生。[PredictionRollback](../../core/net/prediction_rollback.gd)只有在以下条件成立时尝试独立追赶：

- 新的远端普通弹丸，跨度在现有 32 tick 恢复窗口内，全部历史可用。
- 不含待应用的 HIT，射手在这段历史中未回溯。
- 根据初始速度、重力上界和碰撞外形扩大的整个可能路径，与期间的地形变化区域不相交；地形历史、权威 tick 和几何变化历史均有效。

[CombatPrediction](../../core/net/combat_prediction.gd)只推进新弹丸，使用各 tick 保存的角色位置检查连续接触，处理远端接触及已知结束。可能接触本地角色时立即撤销这次尝试，保留正常后缀重放。判断不依赖本地最终位置，也不会拿当前已破坏的地形代替路径中改变过的历史地形。

成功后将弹丸的每个存活状态补入已有检查点，并记录接触查询（包括空结果）与射手模式依赖。其他角色、输入游标、账户和已有爆炸保持原来的历史结果。重复出生保留已追赶的进度。榴弹、旧身份改写、历史不足或路径内地形变化仍保守恢复。

## 必须重放时的成本

- [原生地形（替代旧模块）](../../native/simulation/terrain.cpp)为爆炸保留有界的静态伤害核，只缓存位置、类型和各子格伤害；每次仍读取实际 HP。核包含当前已破坏的候选子格，因此早期爆炸被撤销、子格复活后仍能正确受损。确认、历史裁剪和完整场景重置释放对应缓存。
- [Level0](../../scenes/level_0.gd)对客户端预测批量写入 HP，实际存亡变化才更新碰撞和待绘制集合，每个宏观格只检查一次剩余子格。存在自定义伤害/破坏回调时使用原路径；服务端和单人结算沿用原来的回调。
- [CollisionBuilder](../../core/sim/collision_builder.gd)每块最多保留四种完整占用位图对应的矩形布局。完全相同的位图复用贪心合并结果，几何提交仍按实际布局更新。缓存随分块节点释放，未缓存完整物理查询结果。
- [PlayerReplica](../../scenes/player/player_replica.gd)同一运动样本和快照重复采样时复用已恢复的节点状态，生成轨迹后不再立刻重复恢复该终点。复活层、查询 tick 与本地锚点仍更新；回溯路径和过期代理保留各自的恢复规则。
- [BulletBase](../../scenes/weapons/bullet_base.gd)接触查询先排除线段包围范围外的候选，再计算连续接触；距离阈值使用平方比较。

## 验证口径

固定数据来自八人中继场 client1 / frame 623：tick 546 权威锚点、原待确认输入、tick 547 七条霰弹出生、tick 548 榴弹爆炸与 tick 550 正常输入。离线组件案例包含全部八个角色代理，并且确实产生同一爆点的 172 个子格变化。

独立追赶与强制重放 547～549 后再推进 550 的结果逐项比较：本地完整预测状态、全部存活弹丸运动、HP 表、宏观网格、碰撞子格、账户、输入游标，以及各 tick 的角色/弹丸/账户检查点全部相同。比较和结果序列化位于计时区间之外。

最终对照在相同脚本与引擎下顺序运行修改前、修改后代码；生产文件在对照结束后逐项恢复并核对哈希。每组预热三次、记录十五次，不启用额外细分探针、FrameTrace 或外部采样器。stdout 由 PIPE 持续排空。

| 工作，中位墙钟耗时 | 修改前 | 修改后 |
|---|---:|---:|
| 强制恢复并重放同样的 3 tick，含检查点恢复 | 11.123 ms | 7.111 ms |
| 正常出生事件入口：七条消息处理至本地预测就绪，含创建弹丸与必要恢复 | 12.411 ms | 2.148 ms |
| 这批出生消息触发的本地重放 | 3 tick | 0 tick |
| 出生事件处理后的下一次正常推进 | 1.149 ms | 1.128 ms |

两组事件处理的样本 P95 分别为 13.466 ms、2.552 ms。原调查的 10.545 ms 与本轮复测的 11.123 ms 是相同数据的不同运行；修改后两次先行组件测量为 6.214 ms、7.109 ms，因此不把任一小数当成稳定性能保证。最终表格采用同轮顺序对照的原始样本。修改前后完整逻辑结果也已跨实现逐项核对一致。

全脚本加载 244/244。逻辑/场景回归 67/70，失败仍是原有的精英掉落退出崩溃、预瞄探针空节点和设置页旧文案断言。六项基础网络检查通过，弹丸迟到专项 23 个场景通过。新增出生专项检查独立追赶、重复消息、历史检查点补齐、迟到本地命中、路径内地形变化、缺失历史和榴弹保守恢复；地形专项比较批量与自定义回调路径的完整 HP/网格/碰撞结果，并检查原先死亡的子格复活后仍能被缓存伤害核破坏。

初轮回归另外发现低层碰撞构建器引用 FrameTrace 使 `-s` 纯逻辑入口拉入 Autoload 依赖，已移除该统计引用并复核通过。两个沙箱内连接超时的 UDP 检查在沙箱外重跑通过。初轮失败与最终复核分别保存，没有把初轮误记为全通过。

这是离线组件性能对照，不含八个进程并行负载，也没有重跑整个八人场。结果不等于原在线物理回调或最大帧间隔；原区间未覆盖的 7.036 ms 也没有因此完成归因。
