# 世界历史比较与复用

复用比较同一 tick 的完整预测域，浮点字段精确比较。位置相近不能证明后缀有效；服务端仍决定玩法结果。

## STATE 接纳

1. 在对局入口拒绝过期 STATE，等待对应地形版本并合并可靠事件。
2. PredictionRollback.reusable_tick 只读检查点，比较本地角色、输入游标、远端运动与下一步控制、角色集合和层、弹丸、历史地形、本地账户。动画姿态与姿态停留计时仍保存恢复，但不参与玩法一致性比较。
3. 全部一致且没有新事件影响后缀时，接收新的回溯路径并确认 ACK 和账本边界；角色、弹丸和输入游标都保留在预测末端。
4. 不一致时，PredictionWorld.restore_authority 一次恢复全部角色及其控制、碰撞、弹丸、地形和账户，从 T+1 经 step_tick 重放到目标时钟。

远端使用 PredictionActorState 定义的固定槽。运动前缀来自 PlayerStateSchema，后缀保存控制锁、倒地、回溯、持续输入、移动倍率和复活边界。协议序号、到包时间与显示信息不参与远端模拟比较。

回溯路径是服务端提供的后续模拟指令。服务端以当前位姿为起点，只输出位置或碰撞姿态实际变化的结点。客户端比较最新已接收路径与新 STATE 在 `(T, P]` 内的结点，T 为快照 tick，P 为预测末端；P 之后的尾部更新不使已模拟后缀失效。路径接纳与物理恢复分开，恢复检查点保留最新路径；合法事件重放不会早于最新权威锚点，因此该路径覆盖全部待重放 tick。

## 可靠事件

收包只更新按身份和 tick 保存的确认账本，既不摆放历史角色，也不单独追赶某颗弹丸。晚到出生、引信、命中、光束、爆炸、结束、回溯和账户奖励影响已经模拟的 tick 时，批次取最早失效时刻 E。检查点可用时恢复 E−1 的整个世界并重放；超出合法窗口时重建最新权威锚点。较新 STATE 已覆盖的事件不再施加。

爆炸和命中等已有结果按纯数据比较去重；新弹丸结束确认只写结束账本，在其真实 tick 生效。奖励由世界循环在原 role、弹丸或爆炸阶段入账，不原地修补历史账户。BULLET_REWIND 在 Beta 阶段改变归属角色的模式和弹丸状态，不提前到角色阶段。

重放不会再次播放枪声、受击或爆炸；表现以稳定身份去重。单个确认一致不能取消其他事件的失效。

## 检查点与物理空间

PredictionFrame 位于 tick 结束，保存本地完整状态与输入游标、所有远端运动及控制、角色层、弹丸、地形代号与本地账户。回溯路径由 PredictionWorld 单独持有，不随检查点回滚。容器和记录发布后只读，重放替换整个后缀。历史访问只读取已保存的帧，不执行模拟。

恢复先还原地形，再恢复全部角色、姿态和碰撞层，以及账户与弹丸。RID 仍使用原槽；恢复后才能进行运动查询。内部历史缺失会直接暴露，入口的窗口检查不改变恢复语义。

[Terrain](../../core/sim/terrain.gd) 保存权威 HP、窗口基线和按 tick 分组的稀疏改前/改后值，世界帧保存其历史代号。只有子格存亡变化才重建碰撞，预测历史保留 64 tick。

入口：[PredictionWorld](../../core/net/prediction_world.gd)、[PredictionRollback](../../core/net/prediction_rollback.gd)、[PredictionHistory](../../core/net/prediction_history.gd)、[CombatPrediction](../../core/net/combat_prediction.gd)。
