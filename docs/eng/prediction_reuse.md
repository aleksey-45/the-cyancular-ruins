# 历史比较与预测复用

复用以同 tick 的状态和依赖一致为前提，最终位置相近不能代替比较。权威状态仍决定玩法结果。

## STATE 接纳

1. 拒绝过期序号与不匹配 epoch，等待对应权威地形版本。
2. 比较该 tick 的本地角色、武器、弹丸、本地账户和历史地形；远端完整玩法不属于本地锚点。
3. 按 ACK 重建仍有效的命令，使用新代理复核已记录的几何查询与阶段依赖。
4. 更新确认边界并保留有效前缀；首个失效 tick 之后从有效检查点重放。
5. 历史缺失、锚点不同或检查点无效时恢复权威锚点。

比较对象必须处于同一时间。例如未来已经预测出爆炸，不能据此判定爆炸前的权威地形与历史不一致。NetBus 的接收屏障也不能替代事件覆盖检查，见[通道顺序](netplay.md)。

## 查询和地形依赖

角色阻挡、起身空间、弹丸点/线段接触及射手回溯状态按 tick 和阶段保存、复核。原先为空的查询也必须复核。静态地形运动查询可按完整参数复用；角色阻挡逐次计算，碰撞几何变化使相关缓存失效。

[NativeTerrain](../../native/simulation/terrain.cpp) 保存权威 HP、窗口基线和按 tick 分组的稀疏改前/改后值，角色历史只保存历史代号。相同权威确认不先撤销再重演预测爆炸。补丁后保留尚未被覆盖的预测差分；确有历史差异时限制检查点复用。恢复碰撞在下一步查询前提交，只有子格存亡变化才重建几何。地形预测历史保留 64 tick。

## 战斗确认

| 确认 | 一致性与失效范围 |
|---|---|
| EXPLOSION | 比较 tick、类型、位置；时间改变时覆盖旧、新时刻之间的影响 |
| HIT | 比较攻击、目标、tick、实际 HP、冲量与朝向；缺少足够记录时不能假定一致 |
| 光束 | 先比较时刻和几何；几何不同则按原阶段目标矩形复核实际接触 |
| 引信 | 比较锚点的完整运动和引信状态 |
| 弹丸结束 | 还须检查对应 HIT；结束 tick 相同不能证明命中相同 |
| 时间奖励 | 按服务端 serial 和阶段重算账户，只有倍率或许可等行为发生变化才触发模拟重放 |
| BULLET_REWIND | 拒绝重复、过期和已被更新 STATE 覆盖的锚点；真实变化使锚点下一 tick 起失效 |

一致的单个结果不取消其他依赖的失效。缺少实际执行记录时采用保守恢复。权威已覆盖的命中、收益和弹丸恢复不能再次施加，表现按稳定身份去重。

## 历史所有权

原生历史保存角色、弹丸、代理接触、游标和版本。弹丸使用每帧独占的有序数值数组，直接与协议字典比较、恢复到原生弹丸；不逐颗构造历史字典。背包等低频元数据在变化时生成，历史引用按只读约定复用。检查点不拥有节点，协议只包含可序列化数据。场景重置、epoch 切换和确认裁剪同步释放失效历史。
