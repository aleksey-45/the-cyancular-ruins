# UI 与交互系统

> 本文档属于 [`CLAUDE.md`](../../CLAUDE.md) 架构分域文档。
> 涵盖范围：全局调色板与 UI 工厂 (`UiFactory`) · 菜单视觉设计规范 · 字体与排版约束 · 战斗 HUD 界面层级 · 小地图雷达 · 统一联机大厅 (`mp_lobby`)。

## 一、 UI 控件工厂与色彩规范 (`ui/factory/ui_factory.gd`)

1. **单一调色板源 (`UiFactory`)**：
   - 全局界面颜色唯一定义于 `UiFactory` 中，业务脚本一律引用其语义常量，严禁在业务代码中硬编码 `Color(...)` 字面量。
   - **核心语义色彩**：
     - 背景基色：`C_BG`（页面底色）、`C_SURFACE`（面板表面）、`C_ROW`（列表行底色）、`C_FIELD`（输入框底色）。
     - 控件交互：`C_BTN_FILL_HI / C_BTN_FILL_DN`（按钮高亮与按下）、`C_BORDER / C_BORDER_DIM`（边框与暗边框）。
     - 功能高亮：`C_ACCENT`（核心强调色青色）、`C_DANGER`（危险与血量警告）、`C_WARN`（弹药见底黄色警告）、`C_GOLD`（重要行动按钮琥珀金）。
     - 文字色彩：`C_TEXT`（主文字白色）、`C_TEXT_DIM`（次级文字）、`C_TEXT_MUTE`（禁用弱化文字）。
   - **菜单专属设计样式**：
     - `menu_panel()`：双层嵌套面板（外深色边框 + 内亮线凿刻感），预设充足的内边距。
     - `menu_button()`：统一外发光与暗填充直角描边按钮，最小高度适配 32px 文本及上下边距。
     - `header_strip()`：界面顶部模块标题带。
2. **排版与字体约束**：
   - 英文与数字采用 DOS 位图字体 `assets/fonts/less_perfect_dos_vga.ttf`（8×16 像素）。
   - 中文字体统一采用 GNU Unifont 矢量字体 `assets/fonts/unifont-17.0.05.otf`（SIL OFL 1.1 授权）。
   - 全局关闭抗锯齿与子像素平滑，字号**必须维持 16 的整数倍**（16px、32px 等），杜绝非整数倍缩放导致的笔画粗细不均。

## 二、 战斗 HUD 界面架构

1. **半透明深色底板规范 (`UiFactory.C_PLATE`)**：
   - 地图开阔区域呈现浅灰蓝色调，HUD 元素必须统一步置半透明黑色底板（`C_PLATE = Color(0, 0, 0, 0.1)`），确保血条与残弹计数达到 3:1 以上的视觉对比度。
   - 氧气进度条在满氧状态下自动淡出隐藏，水下缺氧时平滑淡入。
2. **武器槽位显示 (`ui/hud/weapon_slots.gd`)**：
   - 位于屏幕左下方，展示 4×2 网格布局。
   - 呈现三态明度阶梯：未占用（贴近底板颜色）→ 已占用（中明度）→ 当前手持（高亮亮色）。
   - 左下角行首标记数字指示本地切枪快捷键编号。
3. **圆形小地图雷达 (`ui/hud/minimap.gd` + `ui/hud/minimap_circle.gdshader`)**：
   - 挂载于 `CanvasLayer`（Layer 131），仅在 PvP 模式中激活。
   - 以角色为中心显示半透明圆形雷达，范围为 50 个网格单元（`RANGE_CELLS = 50`）。
   - 纹理采样器开启回绕模式（`repeat_enable`），天然适应环面无缝回绕，无需平铺多重副本。
   - 点位标识：本地角色显示带白色描边的本方色彩；1v1 与大乱斗中对手按角色序号配色；3v3 中严格按阵营下发队伍颜色。

## 三、 统一多人联机大厅 (`scenes/mp_lobby.tscn`)

1. **单一大厅入口与模式筛选**：
   - 主菜单通过单点入口「多人模式」跳转至统一大厅。
   - 大厅内支持在「全部 / 1v1 / 3v3 / 大乱斗」标签页之间快速切换过滤。
   - 房间列表并发向服务端查询各模式对局信息，在前端统一汇聚打标展示。
2. **房间状态与断线回局交互**：
   - 房间卡片明确区分等待中与对局中状态；对局中的房间整体弱化置灰。
   - 具备回局凭据的玩家，对应对局中房间保持高亮可点，点击后直接发起快速重连。
3. **动态弹层与等待室形态**：
   - 创建房间弹层根据当前所选模式自动调整配置表单项（1v1 隐藏公开/私密选项，3v3 隐藏禁用武器列表）。
   - 等待室组件按模式自动切换形态：1v1 显示双方准备状态，大乱斗显示人数与房主开始控制，3v3 支持红蓝两队选边与人数对齐。

## 四、 主菜单背景视觉管线

- **真实世界背景烘焙**：主菜单背景通过 `TerrainAtlas.bake_map_image()` 直接烘焙当前对局地图的真实图集纹理，确保背景材质与实际游戏内完全一致。
- **动态 Shader 镜头**：通过 `menu_fisheye.gdshader` 实现逐像素鱼眼重投影与景深模糊，脚本驱动摄像机沿地图路径缓动漂移并在 0°~120° 角度区间摆动，形成生动的空间透视流动感。
- **压暗与暗角控制**：Shader 中 `dim` 语义表示黑色混合遮罩浓度（默认 0.50），配合边缘暗角（`vignette = 0.30`）确保前景菜单文字具备清晰的可读性。
