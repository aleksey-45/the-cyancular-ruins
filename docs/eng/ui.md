# UI 与交互系统

本文档说明全局 UI 样式工厂、调色板与排版规范、战斗 HUD 布局、小地图雷达以及统一多人联机大厅设计。

---

## 一、 UI 控件工厂与调色板规范 (`ui/factory/ui_factory.gd`)

### 1. 全局调色板 (`UiFactory`)
界面颜色统一在 `UiFactory` 中通过语义常量定义，避免在业务代码中随意硬编码颜色值：
- **背景与表面**：`C_BG`（页面底色）、`C_SURFACE`（面板底色）、`C_ROW`（列表行底色）、`C_FIELD`（输入框底色）。
- **按钮与边框**：`C_BTN_FILL_HI / C_BTN_FILL_DN`（按钮悬停与按下）、`C_BORDER / C_BORDER_DIM`（高亮边框与暗边框）。
- **状态高亮**：`C_ACCENT`（核心青色）、`C_DANGER`（危险与濒血红色）、`C_WARN`（弹药不足黄色警告）、`C_GOLD`（关键确认操作琥珀金）。
- **文本颜色**：`C_TEXT`（主文字白色）、`C_TEXT_DIM`（次级文字灰白）、`C_TEXT_MUTE`（禁用或弱化文字暗灰）。

### 2. 菜单控件构建器
- `menu_panel()`：生成带有外边框与内边衬垫的双层矩形面板。
- `menu_button()`：生成统一高度、边框发光与按下反馈的像素风格按钮。
- `header_strip()`：生成界面顶部的分类标题栏。

### 3. 字体与排版约束
- **英文与数字**：使用 DOS 风格位图字体 `assets/fonts/less_perfect_dos_vga.ttf`（8×16 像素）。
- **中文字体**：统一使用 GNU Unifont 矢量字体 `assets/fonts/unifont-17.0.05.otf`（SIL OFL 1.1 授权）。
- **像素对齐原则**：全局禁用抗锯齿与子像素平滑，字号必须为 16 的整数倍（如 16px、32px），防止字体缩放时出现像素模糊或笔画粗细不均。

## 二、 战斗 HUD 界面布局

### 1. 半透明底板 (`UiFactory.C_PLATE`)
- 地图开阔区域多为浅灰蓝色调，HUD 各元素统一使用半透明黑色底板（`C_PLATE = Color(0, 0, 0, 0.1)`），确保血条与弹药文字在浅色背景下依然具备足够的对比度。
- 满氧状态下氧气槽自动隐藏，潜水缺氧时淡入显示。

### 2. 武器槽位显示 (`ui/hud/weapon_slots.gd`)
- 位于屏幕左下角，以 4×2 网格布局展示。
- 槽位状态分为三档：未装备（近底板色）、已装备（中等亮度）、当前手持（高亮高光）。
- 左侧标有数字快捷键提示。

### 3. 圆形小地图雷达 (`ui/hud/minimap.gd` + `ui/hud/minimap_circle.gdshader`)
- 挂载于 CanvasLayer 131，仅在多人 PvP 模式中开启。
- 以玩家为中心显示半径 50 格（`RANGE_CELLS = 50`）的圆形雷达。
- 采样器开启回绕模式（`repeat_enable`），自适应环面世界的首尾连通特性。
- 玩家标记：本地玩家带白色描边；1v1 与大乱斗中对手按序号着色；3v3 团队赛中严格显示所属队伍颜色。

## 三、 统一多人联机大厅 (`scenes/mp_lobby.tscn`)

### 1. 单一大厅入口与标签过滤
- 主菜单通过「多人模式」单一按钮跳转至统一大厅。
- 大厅支持在「全部 / 1v1 / 3v3 / 大乱斗」标签页间切换过滤。
- 客户端并发查询各模式房间列表后统一汇聚展示。

### 2. 房间卡片与断线重连入口
- 房间卡片清晰标识“等待中”与“对局中”状态；对局中的房间置灰不可选。
- 持有该对局有效重连凭据的玩家，对应对局卡片显示高亮重连按钮，点击可直接重新连接回对局。

### 3. 创建弹窗与等待室
- 创建房间弹窗根据所选模式自适应显示配置项（如 1v1 隐藏私密选项，3v3 隐藏禁用武器列表）。
- 等待室根据模式切换形态：1v1 显示双方准备状态；大乱斗显示当前人数与房主开局控制；3v3 显示红蓝两队选边与人数平衡状态。

## 四、 主菜单背景渲染

- **真实地图烘焙**：主菜单背景通过 `TerrainAtlas.bake_map_image()` 直接烘焙关卡地图的完整材质图集，使背景细节与局内完全一致。
- **鱼眼与动态运镜**：挂载 `menu_fisheye.gdshader` 实现轻量鱼眼投影与景深模糊，摄像机在地图上方沿平滑曲线以 0°~120° 角度循环摆动。
- **暗角遮罩**：着色器通过 `dim = 0.30` 叠加压暗遮罩，配合边缘暗角（`vignette = 0.30`），保证前景菜单按钮文字清晰易读。
