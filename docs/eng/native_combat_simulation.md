# 武器、战斗与预测历史的原生迁移

2026-10-27，第二批。承接[场景内原生模拟](native_scene_simulation.md)。保留场景树、Godot 物理节点与生命周期，将高频状态和执行规则一同迁移；原生循环直接访问类型明确的成员，不回调脚本读取模拟属性。

## 当前边界

| 范围 | 当前实现 |
|---|---|
| 角色与武器 | `NativeActorBody.native_step_actor` 在一次原生调用中推进无敌时间、换弹、武器与运动；`ActorStep` 准备输入、时间倍率、地图上下文，并处理背包切换 |
| 武器状态 | `NativeWeaponBody : Node2D` 保存弹药、冷却、换弹、瞄准与开火缓冲，执行开火规则、后坐力及稳定弹丸初态生成；武器场景继续覆盖同名数值属性 |
| 弹丸记录 | `NativeProjectileEntry` 保存类型明确的生存期、tick 与确认字段；节点以弱 ID 引用，出生锚点和确认检查点仍保留兼容 Dictionary |
| 预测战斗 | `NativeCombatKernel` 执行弹丸推进、角色接触、命中、爆炸影响、确认结果、代理交互复核及独立远端弹丸追赶；光束接触和伤害在原生，路径构造仍在脚本 |
| 历史 | `NativePredictionHistory` 批量捕获角色、弹丸、远端接触、碰撞箱、游标和版本等记录；完整检查点仍为既有 Dictionary/Array 格式，没有改成完全打包的原生存储 |
| 管理和表现 | GDScript 保留场景装配、背包生命周期、网络接纳、输入与时间账户、重放外层循环、地形历史/提交适配、显示与一次性音画 |
| 服务端外围 | 原生角色和武器核已共用；弹丸场景创建、事件广播、网络编码、服务端战绩与伤害外围仍在脚本。预测战斗核迁移不等于服务端整个物理回调原生化 |

`WeaponBase` 继承 `NativeWeaponBody`。武器场景数值仍经 WeaponRegistry 加载，C++ 不按武器 ID 另建参数映射。稳定攻击 ID、射击序号、随机种子、枪口变换及视觉偏移剔除与原规则一致。

## 顺序、所有权与副作用

原生战斗段按既有攻击 ID 顺序推进。需要改变地形时返回明确的爆炸提交请求；脚本同步提交该 tick 的临时地形与碰撞后，再继续下一段。后续攻击因此能看到同 tick 已发生的地形变化，不能把提交简单推迟到重放结束。

原生核输出带攻击身份和 tick 的结果与通知，外层消费日志及表现。确认去重、静默重放、权威覆盖和历史有效性检查保持原有语义。模拟需要的瞄准节点变换仍立即更新；精灵、声音、预瞄线和 HUD 在表现阶段更新。

节点由场景管理，原生记录不接管其释放。内部弹丸注册表的值改为 `NativeProjectileEntry`；协议和保存历史仍导出普通数据，不能把原生对象引用发到网络或写入检查点。

## 验证与实战

- Windows Release 模块编译成功；全脚本加载 244/244。
- 全量逻辑/场景回归 67/70；三项已有失败为 `elite_drop_probe` 输出成功后退出崩溃、`preview_visibility_probe` 访问空预瞄节点、`settings_display_section_probe` 旧文案断言。
- 武器、弹药回滚、敌人接口、事件影响、爆炸、局部预测和历史复用相关检查通过；`authority_probe` 通过，`bullet_rewind_order_probe` 的 23 个同批/跨帧迟到与覆盖用例通过。
- `match_8_relay`：90.016 秒八人 Beta 大乱斗，本机 EasyTier UDP 中继，禁用 P2P；152 个路由样本均为 `relay(2)`，八人正常结算并回到原房间，最终位置误差均为 0。
- 正式战斗 43,200 个无头客户端主循环区间中，≥30 ms 为 0，最大 27.186 ms。峰值含一次权威应用、2 tick 重放和一次正常推进；物理节点回调 12.955 ms，回调覆盖外 12.829 ms。子阶段有嵌套，不能相加。

这场客户端均为无头模式；`process_frame` 间隔不等于实际屏幕呈现间隔，也不是完整 CPU 执行时间。它跨越上一轮尾部与等待、下一轮物理阶段。单场结果不证明所有实战卡顿已消失。

服务端最大间隔 32.152 ms，物理节点回调 18.107 ms，进一步调查见[服务端物理峰值](server_physics_peak_20261027.md)。新增分段计时后补测一场：服务端物理回调峰值 17.764 ms，客户端主循环峰值 28.004 ms，runner 无失败、最终误差均为 0。两场时序不同，补测只用于成本归因。

## 尚未完成的原生执行链

输入缓冲与命令审核、时间账户、背包切换、权威接纳准备、地形历史适配、代理轨迹选择，以及整轮恢复/重放/推进的外层循环仍在 GDScript。光束路径与服务端/单人伤害外围也仍有脚本规则。完整历史由原生批量生成，但保留 Godot 容器布局。

因此目前是场景内原生模拟核与批量边界，尚未达到“一整轮模拟完全不回调脚本”的完成判据。后续应针对剩余实测热点继续迁移；服务端事件扇出和日志编码也需要单独优化。
