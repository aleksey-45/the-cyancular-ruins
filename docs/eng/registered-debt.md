# 已知缺陷与验证边界

## 网络

固定种子与真实流程入口见 [联机系统](netplay.md)，测量见 [验证记录](network_validation.md)。隧道已覆盖本机直连与强制中继；跨运营商 NAT、远程中继和长期高负载需要对应部署环境验证。

大基线和全量 STATE 经 ENet 原生分片，双方 64 份解码基线缓存与 32 个播放样本独立；缺少基线恢复全量。目标 tick 未来窗口为 32，持续输入冗余四条，动作有效期 12 tick；预测历史 64 条，单次重放上限 32 tick。

丢包与积压用例能够恢复、完成对局并收敛，远端播放仍可能冻结。原生非可靠节流降到零、可靠地形等待和大基线等待均影响 STATE 到达；生产使用 ENet 默认参数。100 ms 播放缓冲覆盖短期波动，实测冻结时长单独报告。
