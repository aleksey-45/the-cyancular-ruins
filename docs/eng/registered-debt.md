# 实现边界

以下是当前设计的限制。具体缺陷需有适用于当前实现的触发条件和证据，不能从旧版本的耗时或测试失败直接推断。

| 范围 | 边界 |
|---|---|
| 远端交互 | 运动代理不知道尚未到达的远端输入和击退，可能与权威轨迹不同；实际影响通过状态及查询依赖检查处理 |
| 预测窗口 | 历史和领先范围有界；无法证明复用安全时恢复权威锚点，不能承诺所有情况下都无校正 |
| 传输预算 | 收包与派发预算在完整消息间检查，单条大消息或消费者仍可超过软预算 |
| 公网连接 | NAT、运营商和中继可用性影响实际路径；节点配置本身不保证连通质量 |
| 性能归因 | 默认统计提供聚合墙钟值，无法给出任意帧完整调用链或实际显示间隔；需要时进行专项采样 |
| 原生边界 | 场景创建、资源、网络编码和外围玩法仍有脚本及引擎成本；原生模拟不等于整个回调都在 C++ |

设计与处理方式见[联机系统](netplay.md)、[本地预测](local_prediction_design.md)和[性能观测](low_overhead_performance.md)。
