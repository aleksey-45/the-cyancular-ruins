# 已知问题与技术债务

本文档记录当前系统中已知的边界情况、偶发异常及待优化项。

---

## 一、 网络联机

网络系统实现与测试入口请参阅 [联机系统说明](netplay.md)，实测基准数据见 [GNS 验证记录](gns_validation.md)。

- **网络环境边界**：EasyTier 网络隧道已在单机直连与公网中继节点环境下完成验证。在复杂的对称型 NAT（Symmetric NAT）跨运营商网络直连环境下，连通性依赖公共中继节点的转发质量。
- **高丢包与极端积压表现**：在极端丢包与网络积压恢复后，客户端能够自动收敛至权威状态并顺利完成对局，但在极端断流期间远端实体可能会触发短暂停顿或画面冻结。系统当前配置的 100ms 播放缓冲可吸收短期的网络抖动。
- **预测接触与未知输入**：全部武器的已知攻击由 `CombatPrediction` 推进完整受击状态，命中按目标确认。原 91.869 px 硬阻挡现场涉及尚未收到的对手反向加速；相同已知输入的逐 tick 权威对照差 0.000122 px。该未知操作边界保持未关闭。末次八人中继场错误撤销死亡为 0，但仍有 5 次 ≥128 px，最大 189.761 px，集中于输入和接触信息延迟的加速段，尚未逐条关闭。不能统称为正常网络波动。详见[预测与 CPU 验证](prediction_cpu_validation.md)。
- **并发模拟性能**：角色采用缓存矩形边界与逻辑轴向阻挡，地形使用 Godot 查询。较低 RTT 的八人场没有客户端超预算处理；网络延迟增加后，28–32 tick 重放仍出现超过 16.667 ms 的 CPU 成本。实测也记录了约 68 ms 的本机帧间隔，来源尚未完全查明。八个无头实例的结果不代表八个可见窗口的 GPU 性能。详见[预测与 CPU 验证](prediction_cpu_validation.md)。

## 二、 配置表一致性维护

| 配置项 | 当前实现机制 | 验证与约束 |
|---|---|---|
| **HUD 底板颜色** | 由 `UiFactory.C_PLATE` 统一配置 | 场景内的对应属性通过 已移除的 ui_palette_single_source_smoke 进行单一配置源校验 |
| **菜单主题** | 由 `tools/gen_menu_theme.gd` 基于全局调色板自动生成 | 通过 已移除的 menu_theme_mirror_smoke 进行一致性校验 |
| **关卡编辑器敌人列表** | 由 `level_editor/sync-enemies.js` 从 `data/enemies.json` 生成 | 通过 `node sync-enemies.js --check` 校验前后端数据表是否一致 |

## 三、 精英掉落探针偶发异常

- **现象描述**：已移除的 elite_drop_probe 在执行击杀乌鸫、结晶生成与吸收判定（+300 颗粒）完全通过后，在退出场景释放时偶发出现引擎底层崩溃（访问冲突代码 3221225477）。
- **当前状态**：该用例在自动化回归中按失败统计。测试日志保存在 `.test_logs/` 目录下，后续需进一步排查节点退出树（`_exit_tree`）与引擎底层对象销毁的调用时序。
