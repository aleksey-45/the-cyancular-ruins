# 对战模式与结算

多人对战房间由 [RoomSession](../../server/room_session.gd) 统一管理，所有模式共享 [AuthorityWorld](../../server/authority_world.gd)、[MatchRules](../../server/match_rules.gd) 和客户端 [PvpMatchClient](../../scenes/pvp_match_client.gd) 逻辑，避免了各模式碎片化的重复实现。

## 一、 模式规则总览

| 模式 | 开局条件 | 胜负判定规则 | 玩家复活机制 |
|---|---|---|---|
| **1v1 回合死斗** | 两名玩家在线后，房主手动开局 | 单局先得 5 次击杀获胜，三局两胜 | 阵亡者 2 秒后复活；存活者重置回出生点 |
| **团队对抗** | 红蓝两队各 1–5 人、总计 2–10 人，全部在线，房主手动开局 | 单局队伍先达到 `TeamRules.kills_to_win(总人数)` 次击杀获胜，三局两胜 | 阵亡者 2 秒后仅在本方地图侧的出生点中，选离存活敌人最远且未被占用的点复活；全部点被其他存活角色占用时保持倒地，占用解除后的下一 tick 立即重试 |
| **多人大乱斗** | 2–8 名真人在线，房主手动开局 | 默认时长 300 秒，倒计时结束时击杀数最高者获胜；击杀数相同判为平局 | 阵亡者 2 秒后在随机安全地面点复活 |

- **回合流转**：新回合由 `WAITING` 开始，服务端先向各席位发送基线；所有在线席位完成场景与碰撞初始化并上报 READY 后，才进入 3 秒 `COUNTDOWN`。单局结束后停留 4 秒展示小结，随后按回合序号奇偶交换双方地图侧、重置地图与掉落物并重新同步基线。大乱斗模式对局时长由房间配置决定。武器生成、弹药消耗、地形破坏、数据统计及胜负均由服务端权威判定。
- **团队碰撞与伤害分层**：团队模式中，队伍 1 使用碰撞层 Layer 2，队伍 2 使用碰撞层 Layer 16；双方碰撞掩码包含地形与敌方角色层，同队玩家可自由穿行。普通子弹与激光穿透友军，但爆炸类范围伤害仍保留对友军和自身的伤害结算。
- **团队人数与补偿**：开局时固定阵容与人数统计，掉线不重算。单局击杀目标为 `clampi(总人数 + 3, 5, 13)`；少人方开局得分等于人数差，起始最大 HP 为 `50 + 5 × min(人数差, 4)`；人数差 ≥3 时，少人方对敌伤害为 `1.0 + 0.1 × min(人数差 − 2, 3)`，自伤、友伤与无归属伤害不加成。服务端与客户端预测共用 [TeamRules](../../core/sim/team_rules.gd)。
- **阵营出生点与换边**：`.cyrm` 注释中的 `# respawn 1 X Y` / `# respawn 2 X Y` 给出双方地图侧出生点。开局与每局换边时按角色编号升序分配所属地图侧的前 N 个合法点；服务端在 START 前检查每队全部配置点（至少 5 个）：16px 角色净空、脚下支撑、点不重合与静态空域连通；静态空域不证明跳跃/台阶可达，失败时返回地图路径、阵营、坐标和原因。
- **MVP**：团队赛只在分出胜负后从获胜队的玩家统计中评选；排序依次为 ACS、击杀、死亡，完全平分时按角色编号升序；平局或获胜队无有效候选时返回 `0`。
- **时间系统 Beta 模式**：对战支持开启服务端权威的时间回溯与加速机制，具体同步机制详见 [联机系统说明](netplay.md)。

房间人数、成员与开局请求由 `RoomSession` 负责，局内计分和回合推进由 `MatchRules` 负责。当前三种模式共用这些实现，模式差异直接写在所属行为的分支中，不另设通用模式规则表。等待室按钮只提供操作入口；服务端检查房主身份及各模式的在线人数和队伍条件。开局人数只统计在线席位，断线宽限期席位不计入。团队房间上限 10 人；新席位优先进入人数较少的一队（平手进 A 队），选边只接受队伍 1/2 且先排除当前角色再判断目标队容量。`WAITING` 期间席位到期离场会取消尚未开始的对局并返回房间。

## 二、 计分规则与结算流程

玩家倒地前在有效时间窗口内造成伤害的同队队友计为助攻。赛后评分由 [ScoreRules](../../core/sim/score_rules.gd) 统一计算：

```text
penalty = (team_damage + self_damage) / 5 + team_kills * 100
kscore = kills * 100 + assists * 50 + dealt / 5 - deaths * 50 - penalty
acs = kscore / rounds
```

结算界面通过 [结果数据适配器](../../ui/screens/match_result_payload.gd) 将服务端统计数据转换为 [结算面板](../../ui/screens/match_result.gd) 的展示内容。在线玩家确认返回后，服务端释放当前的对局物理世界，在原有网络连接上恢复房间大厅状态（保留房间号、席位及重连 token）。若房主主动退出或重连宽限期超时，房间将直接解散。
