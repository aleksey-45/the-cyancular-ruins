# KH 合并 L3 实施计划（换弹 / 禁用武器 / HUD）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 KH_v1_1_3 的**换弹玩法**、**武器槽位禁用闸门**、**滚轮切枪**与 **KH 版 HUD**（武器剪影/名称/残弹/换弹进度条）搬进 main；其余保持 main，**绝不接受 KH 在传输这些特性时顺带删掉的 main 既有成果**。

**Architecture:** 以 **main 为基底做加法**。KH 在这四个文件里同时删掉了 10 处 main 的东西（含 C2 的 `capture_state`/`restore_state`、`tick(delta)` 物理 tick 驱动、`input_source.frozen`）——那些**一律不采纳**。移植内容从 KH 源文件按方法名逐段搬，不整文件替换。

**Tech Stack:** Godot 4.7.1 标准版 · GDScript · 探针用 `extends SceneTree`（`-s`）或场景式（`.tscn`）
