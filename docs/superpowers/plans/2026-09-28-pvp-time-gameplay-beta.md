# PvP 时间玩法（Beta：错乱大乱斗 / 时空 3v3）实施计划

日期：2026-09-28
状态：已确认
范围：将单人时间玩法机制移植至联机模式（包含大乱斗与 3v3 两个 **Beta 变体**），单人模式与现有常规大乱斗/3v3 **保持不变**

---

## 0. 核心设计约束（实施前提）

| 问题 | 裁定规则 |
|---|---|
| 回溯能否复活 | **不能**。倒地/死亡后禁用时空回溯（联机死亡会触发计分事件，不支持跨死亡边界回滚） |
| 回溯时敌方画面效果 | 反色底片效果**仅作用于世界图层与自身**（将全屏后处理调整为作用于世界图层与本地玩家的着色器）；其他玩家保持原样 |
| 破坏瓦片的粒子奖励粒度 | **16px 子格**（与 B18 实现的子格破坏判定保持一致） |
| Beta 房间与常规模式关系 | **独立房间池**：Beta 界面仅展示并加入 Beta 房间，常规大乱斗/3v3 不受影响 |

## 1. 玩法规则

### 1.1 时间技能（联机语义）
| 技能 | 效果 | 消耗速率 |
|---|---|---|
| **时间加速** | **仅加速自身**（倍率 ×3.0：移动/开火/换弹/冲刺/自身子弹）；**不减速**其他实体 | 70 粒子/秒 |
| **时空回溯** | **仅回溯自身**（位置/速度/朝向/生命值/弹药与手持武器 + **自身发射的子弹**，包含引信状态）；回溯期间**自身处于无敌免伤状态**；其余玩家完全不受影响 | 150 粒子/秒 |

- 各玩家的时间技能控制彼此独立：所有玩家均在各自独立的历史轨迹上回溯，互不干涉。
- **回溯中的子弹保持伤害有效性**：倒流中的子弹穿过敌方仍能正常造成伤害；**回溯中的榴弹接触敌方角色时，立即触发触碰引信并引爆**，该爆炸作为实时物理事件重新广播至世界（走标准的服务端权威伤害结算与地形破坏管线）。
- 角色处于倒地或死亡状态时禁用时空回溯。

### 1.2 时间粒子经济系统（默认数值可在建房界面自定义）
| 配置项 | 默认值 |
|---|---|
| 账户初始粒子 | 1000 |
| 账户粒子上限 | 1800 |
| 回溯消耗速率 | 150 /秒 |
| 加速消耗速率 | 70 /秒 |
| 短期使用额度 | 250 |
| 短期额度恢复速率 | 50 /秒 |
| 击杀获取奖励 | 被击杀者**账户总额度的 50%**（被击杀者自身余额**不扣除**） |
| 破坏瓦片奖励 | 每摧毁一个 **16px 子格** +10 |
| 造成伤害奖励 | 每造成 **1 点**伤害 +4 |
| 透支额度上限 | **等于短期额度**（默认 250；账户总余额不为负，透支满额后锁定） |

**关键规则约定**：
- **PvP 模式启用透支机制，但上限等于短期额度**（默认 250；`loan_limit` 由构造参数传入，PvP 传入 `short_window`，单人模式仍传入 `TimeParams.LOAN_LIMIT = 100`）。
  · **账户总余额不为负**：余额永不透支至负数；仅短期使用额度支持透支。
  · 沿用单人模式的**透支满额强制锁定**机制：透支达到上限后，怀表指针红闪且时间技能按键锁定；恢复时以 50/s 速率**优先偿还透支额度，还清后再恢复短期额度**，完全还清后自动解除锁定。
  · 怀表红色长指针指示的额外圈数支持参数化：单人模式为 1/4 圈（100/400），PvP 默认配置为 **1 整圈**（250/250）。
- 伤害与击杀奖励仅针对**敌方实体**有效（自伤与友军伤害不计入奖励，复用伤害归因过滤管线）。
  · **自杀与自伤不产生时间粒子**：自爆、坠落伤害或环境伤害均不奖励任何粒子。
- 时间粒子获取特效**仅在自身屏幕播放**（其他玩家获取粒子时不播放特效）。
- 加速倍率固定为 3.0×（不纳入建房界面可调参数）。

## 2. 架构设计：服务端权威模型

联机模式采用**服务端权威模拟 + 客户端预测与回滚**（MatchHost/RoyaleHost/TeamHost + 状态快照）。具体设计：

- **时间粒子账户由服务端权威管理**（每个角色独立维护一份），客户端仅维护**镜像副本**（防作弊，确保数值来源单一权威）。
- **时空回溯由服务端执行驱动**：服务端为每个角色独立维护**历史状态环形缓冲区**（20Hz），收到该角色的回溯输入状态后，通过环形缓冲区中的历史数据驱动其实体、子弹与弹药状态；客户端仅负责播放本地特效。
- **伤害免伤由服务端权威判定**：当角色处于回溯状态时，所有命中该角色的伤害在裁决阶段直接丢弃。
- 环形缓冲区容量 = `min(粒子上限 / 回溯消耗速率, 15s)`（默认 1800/150 = 12s）；仅存储**自身**状态（位置、速度、朝向、生命值、弹药、手持武器）以及**自身发射的子弹**（复用 `BulletBase.rewind_state()`：位置、速度、伤害、击退、引信、射程）。

数据流设计：
```
客户端 → 服务端：输入数据包增加两个持续按住状态位（rewind / haste）    [PacketInputSource 扩展]
服务端 → 客户端：状态快照包中同步下发：
                 · 各角色时间粒子状态（余额、短期额度、上限）—— 供 HUD 渲染
                 · 各角色时间模式状态（none / rewind / haste）—— 供实体视效与头顶指示
                 · 回溯角色的轨迹采样点（每 3 帧记录一个坐标）—— 供时间切片残影渲染
```

## 3. 视觉与表现规范

### 3.1 本地第一人称视角（与单人模式保持一致）
- **怀表 HUD 与屏幕中心模式指示图标**：复用单人模式的 `ui/watch_hud.gd` 与 `ui/time_symbol_hud.gd`，挂载于 `pvp_hud` / `royale_hud` / `team_hud` 的对应位置（生命条下方）。
- **时间加速（本地玩家）**：视觉表现与单人模式一致（角色高亮 + 红蓝交替残影拖尾 + 屏幕中心 `▶▶` 紫色符号）。
- **时空回溯（本地玩家）**：反色底片 Shader 效果调整作用范围——仅作用于**世界图层（瓦片、水体、背景）与自身角色**；屏幕由中心向外平滑扩散过渡。**其余玩家实体保持正常渲染，不叠加底片效果**。

### 3.2 观察其他玩家视角（第三人称表现）
- **其他玩家执行时空回溯时**：
  1. 该玩家角色外观渲染为**反色底片风格**（挂载对应底片 Shader 材质）；
  2. 沿其**历史回退轨迹每 3 帧**留存一个**淡色时间切片残影**（残影呈现底片色且透明度较低），在 **1.0 秒内渐隐销毁**；
  3. 其回溯倒流中的子弹**正常对其他玩家造成伤害**；回溯中的榴弹接触其他玩家时立即引爆（参见 §1.1）。
- **其他玩家执行时间加速时**：亮度增强 + **红蓝重影**（通过两个偏移的叠加色彩贴图副本实现）+ **角色头顶像素字体 `▶▶ 3x`** 快进标识。

### 3.3 时间粒子收支反馈
与单人模式保持一致：获取粒子时触发结晶碎片飞向**自身的怀表 HUD** 并伴随表体微震；消耗粒子时无额外粒子特效。

Beta 模式房主可自定义调整（其余客户端通过服务端同步配置）：

| 参数项 | 默认值 | 服务端数值限制范围（防止非法上报） |

## 6. 分批交付计划

### B19 时间规则与账户参数化（纯逻辑，单人模式零回归）
- 新增 `core/config/time_rules.gd`：PvP 全量默认配置 + `from_dict/to_dict` 序列化 + `clamp_self()`（房间设置与服务端共用统一限制）。
- `core/sim/grain_account.gd` 逻辑参数化：初始值、上限、短期额度、恢复速率、**透支额度**支持由构造参数传入；**单人模式保持 `TimeParams` 原值**（包含 `LOAN_LIMIT=100`），行为严格保持向后兼容；PvP 模式传入 `loan_limit = short_window`。
- `ui/watch_hud.gd`：红色长指针指示的额外圈数由 `loan_limit / short_window` 动态计算（单人模式为 1/4 圈保持不变，PvP 模式默认为 1 整圈）。
- 自动化测试：`time_rules_smoke.gd`（默认值、序列化往返、参数范围限制）；`grain_account_smoke.gd` 扩充自定义参数测试组（包含 PvP 语义：`loan_limit = short_window`、余额不透支、透支上限锁定与还清解锁）。

### B20 Beta 入口与独立房间池及建房参数配置
- 主菜单新增 `Beta` 入口按钮与 `scenes/beta_menu.tscn` 界面（包含各模式卡片组件）。
- 独立房间池隔离：`LobbyRooms`、`server_main`、`NetBusExt` 新增 `beta_royale` 与 `beta_team` 独立注册表与端口范围，实现与常规模式完全隔离。
- 建房面板增加时间参数配置栏目（9 项配置），支持通过 `UiFactory` 控件调整并随 `player_options` 上报同步。
- 自动化测试：菜单跳转自动化测试（`-- --autotest-beta`）与房间隔离冒烟测试。

### B21 服务端权威时间粒子经济
- 服务端：为各玩家角色独立实例化 `GrainAccount`（结合 `TimeRules` 配置）；结算接口：
  · 击杀：角色倒地时触发，奖励击杀者相应比例的时间粒子；
  · 伤害：伤害判定命中时按点数奖励攻击方（仅限敌方伤害）；
  · 破坏瓦片：16px 子格破坏时按配置奖励子弹或爆炸的发射者；
  · 自动恢复：以预设速率由服务端 tick 定期恢复。
- 状态同步：服务端在快照包中广播各角色的时间粒子状态；客户端 `PvpSession` 维护镜像并在快照间隙进行平滑插值。
- 客户端 HUD：Beta 房间 HUD 挂载 `WatchHud`（位于生命条下方）。
- 自动化测试：`time_economy_smoke.gd`（数值结算冒烟测试）与端到端场景测试。

### B22 个人时间加速（倍率 ×3.0）
- 输入协议增加 `haste` 状态位；服务端对该角色的移动、开火、换弹与冲刺按 3.0 倍率缩放（作用于**速度域**），其发射的子弹速度同步提升相应倍率；其余实体不受影响。
- 表现层：自身视角角色高亮、红蓝交替残影与中心指示图标；其余玩家视角下该角色显示高亮重影与头顶 `▶▶ 3x` 快进标识。
- 自动化测试：`beta_haste_probe` 验证服务端位移与射速倍率以及客户端视效标识。

### B23 个人时空回溯（状态回溯、免伤与轨迹表现）
- 服务端：为各角色维护 20Hz 环形缓冲区；按住回溯键触发**自身历史状态回放**、扣除时间粒子、开启免伤状态并锁定常规输入；发射的子弹同步沿历史轨迹回放。
- 回溯倒流中的子弹穿透敌方时正常判定伤害；回溯中的榴弹接触敌方立即引爆。
- 客户端表现：自身视角世界图层与角色反色；其余玩家视角下显示反色外观并在轨迹上留存时间切片残影。
- 自动化测试：`beta_rewind_probe` 验证回溯轨迹还原、免伤有效性、子弹二次伤害与榴弹引爆判定。

### B24 综合回归测试与文档发布
- 回归测试：单人模式全量时间系统测试套件 + 联机模式测试套件（房间、大乱斗、3v3 及 Beta 模式）+ 全流程自动化测试。
- 技术文档：更新 `AGENTS.md`（PvP 时间玩法机制、权限架构与测试用例说明）。
- 发布构建：打包验证可执行程序。

## 7. 风险与设计边界

| 风险点 | 说明与对策 |
|---|---|
| **回溯状态带宽开销** | 仅同步与回溯自身状态，且轨迹采样点仅在回溯期间按降频下发，整体网络带宽处于可控范围内 |
| **客户端预测与回溯冲突** | 角色进入时空回溯时，客户端暂停本地物理预测（锁定本地输入并完全由服务端下发的历史状态驱动），消除预测冲突 |
| **免伤机制与伤害归因** | 回溯免伤在服务端判定阶段直接丢弃伤害事件，避免对伤害统计与助攻记账造成污染 |
| **数值平衡性** | 3.0× 加速与免伤回溯效果强劲，所有核心数值均在房间设置中开放调节，便于实战测试调优 |
| **明确不包含的范围** | ① 队友与敌方实体不受发动者时间技能影响；② 倒地与死亡状态下禁止时空回溯；③ 账户总余额永不透支至负数 |

## 8. 核心规则确认项

1. PvP 模式**启用透支机制，且透支上限等于短期额度**（默认 250）；账户总余额不为负；透支达到上限后锁定、还清后解除锁定的规则与单人模式保持一致。
2. 造成伤害与击杀奖励**仅对敌方实体有效**；自杀、自伤与环境伤害一律不产生时间粒子。
3. 时间粒子获取特效**仅在自身屏幕播放**。
4. 加速倍率固定为 **3.0×**。
5. 回溯期间**锁定输入**（无法主动移动或开火），与单人模式保持一致。
6. Beta 房间采用**独立房间池**，与常规大乱斗/3v3 严格双向隔离。
