## 1. 玩法规则（本计划按用户原文固化）

### 1.1 时间技能（联机语义）
| 技能 | 效果 | 消耗 |
|---|---|---|
| **加速** | **只加快自己**（×3：移动/开火/换弹/冲刺/自己的子弹）；**不**放慢任何人 | 70 颗粒/秒 |
| **回溯** | **只回溯自己**（位置/速度/姿态/HP/弹量与手持武器 + **自己的子弹**，含引信状态）；回溯期间**自身免伤**；其他人完全不受影响 | 150 颗粒/秒 |

- 非房主玩家的"时间权柄"彼此独立：所有人都在自己的时间线上回溯，互相不干涉。
- **回溯的子弹对外仍是活的**：倒回中的子弹照常伤害他人；**回溯的榴弹碰到你 → 当场起触碰引信并爆炸**，该爆炸按"历史事件"重新写入世界（走正常的服务器权威爆炸/拆砖/结算链路）。
- 倒地/死亡 → 回溯禁用（不能自救复活）。

### 1.2 颗粒经济（全部默认值可在建房页自定义）
| 项 | 默认 |
|---|---|
| 账户初始值 | 1000 |
| 账户上限 | 1800 |
| 回溯燃烧速率 | 150 /秒 |
| 加速燃烧速率 | 70 /秒 |
| 短时额度 | 250 |
| 短时额度回复速率 | 50 /秒 |
| 击杀获取 | 被击杀者**账户总额度的一半**（被击杀者**不减少**） |
| 破坏获取 | 每摧毁一个 **16px 子格** +10 |
| 伤害获取 | 每造成 **1 点**伤害 +4 |
| 贷款上限 | **= 短时额度**（默认 250；账户本身不透支，贷满锁定） |

**用户已确认的补充裁定**：
- **PvP 启用贷款，但上限 = 短时额度**（默认 250；`loan_limit` 由构造参数传入，PvP 传 `short_window`，单机仍传 `TimeParams.LOAN_LIMIT = 100`）。
  · **账户本身不透支**：余额永不为负；可透支的只有"短时窗"这一档。
  · 沿用单机的"**贷满强制锁定**"语义：贷满 → 怀表表针红闪 + 两键空转；回复速率 50/s **先还贷、后回窗**，还清即解锁。
  · 怀表红长针的"额外圈数"要**参数化**：单机 = 1/4 圈（100/400），PvP 默认 = **1 整圈**（250/250）。
- 伤害/击杀获取只算**对敌方**（自己与队友不计，复用上游已有的自伤/队友伤害归因通道）。
  · **自杀/自伤绝不产颗粒**：自己炸死自己、摔死、环境致死都不给任何颗粒（防止用自伤刷额度）。
- 颗粒获取特效**只对自己播**（他人获得颗粒不显示特效）。
- 加速倍率固定 ×3（不进建房页可调项）。

## 2. 架构：为什么必须服务器权威

联机是**服务器权威 + 客户端预测/回滚**（MatchHost/RoyaleHost/TeamHost + 快照）。因此：

- **颗粒账户住在服务器**（每个 role 一份），客户端只做**显示镜像**（防作弊；数值来源唯一）。
- **回溯由服务器执行**：服务器为每个 role 维护一条**自身状态环形缓冲**（20Hz），收到该 role 的"按住回溯"输入位后，用环缓里的历史驱动它的实体、子弹与弹量；客户端只做视效。
- **免伤由服务器裁决**：某 role 处于回溯态时，所有指向它的伤害在裁决处直接丢弃。
- 环缓深度 = `min(上限/回溯燃烧速率, 15s)`（默认 1800/150 = 12s）；只存**自己**的状态（位置/速度/姿态/HP/弹量/手持武器）+ **自己的子弹**（`BulletBase.rewind_state()` 已有：位置/速度/伤害/击退/引信/射程）。

数据流（新增部分，改动最小化）：
```
客户端 → 服务器：输入包增加两个"按住"位（rewind / haste）           [PacketInputSource 扩展]
服务器 → 客户端：快照/回合包里增加
                 · 每 role 的颗粒状态（余额/短时/上限）—— 显示用
                 · 每 role 的时间态（none/rewind/haste）—— 他人视效与头顶标记用
                 · 回溯者的轨迹采样（每 3 帧一个点）—— 轨迹残像用
```

## 3. 视效规格

### 3.1 自己（与单机一致）
- **怀表 HUD + 屏幕中心符号 HUD**：全盘照搬单机的 `ui/watch_hud.gd` 与 `ui/time_symbol_hud.gd`，挂在 `pvp_hud` / `royale_hud` / `team_hud` 的**同一位置**（血条下方）。
- **加速（自己）**：与单机一致（提亮 + 红蓝残影拖尾 + 中心 `▶▶` 紫色符号）。
- **回溯（自己）**：底片效果**改作用域**——只打在**世界图层（砖/水/背景）+ 自己的角色**上；屏幕由内而外的推进感保留（着色器内用 `SCREEN_UV` 算覆盖度，与单机同款公式）。**其他玩家（副本）不被底片覆盖**。

### 3.2 他人视角（看到别人在做什么）
- **别人回溯时**：
  1. 那个人自己渲染成**底片色**（对他的副本套同一支底片着色器）；
  2. 沿他的**回退轨迹每 3 帧**留一个**淡淡的时间切片残像**（残像也是底片色，透明度低），**1 秒内渐隐消失**；
  3. 他的回溯子弹**照常伤害你**；其回溯的榴弹碰到你 → 触碰引信当场起爆（见 §1.1）。
- **别人加速时**：亮度突然提高 + **红蓝重影**（用两张偏移的加色副本实现，不走全屏后期）+ **头顶像素字体 `▶▶ 3x`**（快进符号，非中文）。

### 3.3 颗粒收支特效
照搬单机：获得颗粒 → 结晶飞向**自己的怀表** + 表体颤抖；消耗 → 无额外特效（与单机一致）。

## 6. 分批施工（每批独立提交 + 检查点分支）

> 约定沿用本线：每批一个 `KH_v0.5.0_Bx` 检查点；每批自带探针；批次结束导出 exe。

### B19 时间规则与账户参数化（纯逻辑，单机零回归）
- 新增 `core/config/time_rules.gd`：PvP 全量默认值 + `from_dict/to_dict` + `clamp()`（建房页与服务器共用一份钳制）。
- `core/sim/grain_account.gd` 参数化：初始/上限/短时窗/回复/**贷款额**由构造参数传入；**单机走 `TimeParams` 原值**（含 `LOAN_LIMIT=100`），行为逐位不变；PvP 传 `loan_limit = short_window`。
- `ui/watch_hud.gd`：红长针的"额外圈数"由 `loan_limit / short_window` 推出（单机 1/4 圈不变，PvP 默认 1 整圈）。
- 探针：`time_rules_smoke.gd`（默认值/序列化往返/钳制矩阵）；`grain_account_smoke.gd` 增补"自定义参数"组（含 PvP 语义：`loan_limit = short_window`、余额不透支、贷满锁定→还清解锁、怀表额外圈数换算）。

### B20 Beta 入口 + 独立房间池 + 建房页参数栏（不下场，只把通道打通）
- 主菜单 `Beta` 按钮 + `scenes/beta_menu.tscn`（卡片：画框/模式名/简介/版本）+ 两个卡（图标程序化生成）。
- 独立房间池：`LobbyRooms` / `server_main` / `NetBusExt` 新增 `beta_royale` / `beta_team` 两条（各自的注册表与 worker 端口段，RPC 名镜像现有 `royale_*` / `team_*`）。
- 建房面板加"时间参数栏"（9 项，`UiFactory` 滑条/输入行），随 `player_options` 上报；服务器钳制后回灌。
- 探针：菜单流转 autotest（`-- --autotest-beta`：主菜单 → Beta 页 → 两张卡都在 → 进 Beta 房页）；房间冒烟（Beta 建房/加入与普通房互不可见）。

### B21 服务器权威颗粒经济（先只做账户与收支，不做技能）
- 服务器：每 role 一个 `GrainAccount`（B19 的参数化版 + `TimeRules`）；结算入口：
  · 击杀：`MatchState`/`RoyaleHost` 的倒地边沿 → 奖励击杀者"被击杀者余额 × 比例"；
  · 伤害：命中裁决处按点数奖励攻击方（仅敌方，复用自伤/队友伤害归因过滤）；
  · 拆砖：子格摧毁处按 `block_gain` 奖励弹/爆炸的 owner（`shooter`）；
  · 回复：50/s 恒定（服务器 tick）。
- 下发：快照/回合包带每 role 的颗粒状态；客户端 `PvpSession` 存镜像 + **仅在包间隙做本地预测插值**（显示用，不参与裁决）。
- 客户端 UI：Beta 房的 HUD 挂 `WatchHud`（血条下方）。
- 探针：`time_economy_smoke.gd`（-s：结算公式矩阵）+ 场景探针（两个 bot：A 打死 B → A 余额 = 初始 + B 余额×50%、B 余额不变；A 拆一格砖 → +30×子格数；B 打掉 A 的 1 点血 → A 得 4）。
- **本批结束即可玩**：Beta 房里有颗粒账户与收支，但还没有加速/回溯。

### B22 加速（自己 ×3）
- 输入包加 `haste` 位；服务器：该 role 移动/开火/换弹/冲刺 ×3（作用在**速度域**，与单机 B12/B16 同一套教训），其发射的子弹速度 ×3；其他人不受影响。
- 客户端表现：自身提亮 + 红蓝残影 + 中心 `▶▶`；**他人视角**：该副本提亮 + 红蓝重影 + 头顶 `▶▶ 3x` 像素字（随其世界坐标定位）。
- 探针：`beta_haste_probe`（服务器侧：A 加速时 A 的位移/射速比 ≈3、B 的位移不变；客户端侧：他人头顶标记出现且 3x 文案正确）。

### B23 回溯（自身状态/武器/子弹 + 免伤 + 他人视效）
- 服务器：每 role 环缓（20Hz，深度见 §2）；按住回溯 → **倒放自己**（3×→1× ramp，与单机一致）、扣 150/s、自身免伤、输入锁定；自己的子弹一并倒放（`rewind_state/apply_rewind_state` 直接复用，**含引信/射程**）。
- 回溯弹仍然致命（对他人）；回溯榴弹触碰他人 → 触碰引信起爆 + 正常权威爆炸链路。
- 客户端视效：底片只打世界图层 + 自己（§3.1）；他人视角：底片色自身 + 每 3 帧轨迹残像（1 秒渐隐）；轨迹点由服务器随包下发。
- 探针：`beta_rewind_probe`（服务器侧：A 回溯期间位置/HP/弹量按历史回退、B 的伤害被丢弃、B 自身状态完全不动；回溯弹伤到 B 照常结算；榴弹触碰 B 起爆）、`beta_rewind_fx_probe`（残像数量/1 秒消失/底片材质只挂在世界层与自己）。

### B24 全量回归 + 文档 + 导出
- 回归：单机全部时间探针（rewind/haste/elite_drop/watch_hud/tile_rewind/subcell/map_*）+ 联机冒烟（room/match/team/royale + Beta 两条）+ `autotest-sp`。
- 文档：AGENTS.md（PvP 时间玩法小节：规则、权威归属、探针清单、检查点）+ `CR_Plan.txt` 登记。
- 导出 exe + 管线检查（`~/.zcode/v2/checkpoints` 哨兵 + 无新产物）。

## 7. 风险与已知边界

| 风险 | 说明与对策 |
|---|---|
| **回溯的带宽** | 只回放"自己的"状态，且轨迹点每 3 帧一个、仅回溯时下发 → 量级与既有快照同阶；若紧张，可只对**近处玩家**下发轨迹点 |
| **回滚与回溯叠加** | 客户端本地预测/回滚（C2）与"服务器倒放"会互相干扰：回溯期间该客户端**暂停本地预测**（输入锁定 + 服务器状态直推），避免预测把倒放拉回去 |
| **免伤与归因** | 回溯免伤在服务器裁决处丢弃伤害 → 击杀/助攻/惩罚记账都不应被污染（复用上游 `自伤标记通道` 的思路：丢弃而不是记 0 伤害） |
| **平衡** | ×3 加速 + 免伤回溯 + "击杀得对方一半余额"可能滚雪球；本批先按原文实装，数值全在建房页可调，实测再调 |
| **不做的事** | ①队友/敌人不受任何时间影响；②不做跨死亡复活；③账户本身不透支（贷款只在短时窗这一档，见 §1.2）；④四层渲染（前景/后景/背景）与本次无关，仍是独立待办（需"前景层顺序"决策） |

## 8. 需要用户确认的补充裁定（默认已按上表写进计划）

1. PvP **启用贷款，上限 = 短时额度**（默认 250）；账户余额不透支；贷满锁定、还清解锁的语义沿用单机。
2. 伤害/击杀获取**只算敌方**（自己与队友不计）；**自杀/自伤/环境致死一律不产颗粒**。
3. 颗粒获取特效**只对自己播**。
4. 加速倍率**固定 ×3**（不进建房页）。
5. 回溯**输入锁定**（倒放期间不能移动/开枪），与单机一致。
6. Beta 房**独立房间池**（普通大乱斗/3v3 的列表与规则零污染）。
