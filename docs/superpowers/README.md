> ## 读之前必须知道的三件事
>
> 1. **这里的路径引用大面积失效，且这是设计如此**：2026-10-13 实测 `docs/superpowers/**` 有
>    **2,890 处**指向已不存在文件的引用（占 8,204 条引用的 35%）。原因不是写错了 —— 是
>    2026-10-09 的测试面削减删了 **345 个**文件、加上 `tests/` 与 `server/` 的目录重组 ⇒
>    "当时的计划"提到的文件**今天大多不在原位**。**逐条订正它们等于篡改历史**，所以不做。
> 2. **`tools/check_naming.py` 的规则 C 刻意不覆盖本目录**（连同 `docs/archive/`）。纳入它会把
>    数千条**正确的历史记录**判红 —— 那是"守卫逼人删信息"。代价照实写在 `check_naming.py` 的
>    `DOC_FILES` 注释里：**这些文件里的路径没有机械守卫，要查只能手工扫**。
> 3. **别把这里的结论当现行口径**：要判断"今天是什么样"，读 [`docs/eng/`](../eng) 或源码；
>    要判断"当时为什么这么决定"，才读这里。
>
> ## 想查某一批做了什么
>
> 1. `git log --oneline -- docs/superpowers/specs/<那份 spec>` —— 提交记录里带着当时的判词；
> 2. 本机运行账本在 `.superpowers/sdd/`（**gitignore，不入库**，但它是恢复地图：每批的
>    `progress.md` + `task-N-report.md` + 评审包）。
