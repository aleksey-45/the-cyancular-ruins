# 1.游戏概述
## 1.1概述

- 一局半个小时左右的肉鸽游戏。玩家一共要打从L1到L4的四张地图，每张地图各有两个boss，打完所有8个boss即为游戏通关。
- 正上方会显示游戏的时间T=。随着时间增加地图会逐渐崩坏，玩家需要在限定时间之内，且在自身血量不被清空的情况下通关这张地图，否则将被视为''被杀死''或''迷失''，游戏失败。
- 玩家UI左上角有血量条和时间条两个条。血量顾名思义；时间条相当于技能条，通过打怪积攒，用于存储时间，可以被清空。
- 玩家消耗时间条，产生两大类效果：时间倒退和改变流速。时间倒退即让玩家，部分怪物和整个世界倒流回从前；改变流速即让玩家相对于世界行动的更快或更慢（类似子弹时间，相当于延长或缩短了地图崩坏的限时）。这些效果有助于玩家通关或有助于开发者设计独特的关卡和boss
- 玩家初始时武器随机，在地图中清理怪物（小怪不掉落时间，也会受时间倒退影响反向移动或复活；精英怪掉落时间，不受时间倒退影响，但会受改变流速影响）；开宝箱；与商店交易（宝箱和商店有特殊时间场，在范围内时间停止流动）；然后进入boss房打掉两个boss即可进入下一张地图
- 在完成一局游戏后，角色（机器人）在设定上要''生产下一个机器人''，然后玩家将使用上一局生产的机器人开始下一局的游戏。这样每一局的初始机器人都有差别，即局外的养成系统。

## 1.2与其它游戏差异点
- 采用灰色系，主要用灰蓝和灰绿作为基本色调。文学背景缝合四个四重奏和环形废墟，世界观具有现代主义色彩
- 循环地图：上就是下，左就是右
- **核心**：大量的时间系玩法，怪物和机制。如通过倒退纠正失误；与过去自己合作（影子接力）；时间武器；瞬移怪等等。
# 2.核心玩法和世界观设定
## 2.1局内循环
进入地图 → 战斗 → 打小怪没有掉落，打精英怪掉落时间→ 使用时间倒退或改变流速技能战斗→在时间暂停的商店升级 → 构建 Build → 打两个Boss房 → 被杀死，迷失或（往下跳逐渐加速）通关 → 结算，剧情，进入下一张地图


- 玩家操作：移动、瞄准、射击、投掷，冲刺、时间技能、交互
- 胜利条件、失败条件：比如初始时T=0，T=300时世界崩坏玩家迷失，则被怪打死或T=300视为失败；在T=300之内打完两个boss（和所有精英怪）视为单张地图胜利。失败后将倒回该张地图开始时（相当于一张图存一次档）。
- 中间穿插开宝箱和一些基于时间机制的小解谜（此时时间也暂停减少玩家压力）
- 单局节奏：前 3 分钟给什么，中期压力怎么来，Boss 怎么检验 Build


## 2.2局外循环和养成系统

打完全部四张地图→触发剧情→结算获得（局外）资源 → 解锁新武器/天赋 → 用新武器/天赋生产下一局的初始机器人→ 用这个新机器人再进一局

## 2.3世界观设定
- 这个世界的时间构成了大的轮回，也没有时间箭头，过去就是未来，未来就是过去。所以玩家操控时间''倒退''的能力本质是另一种时间的''前进''--对机器人来说这只是对这个世界时间特性的简单运用，并非什么不得了的能力。
- 在一局结束后，机器人（对应环形废墟魔法师）被要求生产出新的机器人（对应孩子）。玩家在第一次游玩时也终于意识到自己的机器人也是由上一代的机器人生产出来的（对应结构嵌套）。在生产（局外养成）完后，玩家会看到新的机器人以跟自己从前一模一样的路径走向了第一张地图（对应时间和命运轮回观念）。
- 由于机器人是一层一层生产出来的，所以设定上它是无法真正被打死或迷失的（对应孩子不怕火）。每次游戏失败玩家点击''重生''，会看到时间溯源的画面，回到地图开始时，即机器人只是又回到了过去，而不是死了。它没法死去，它只能在时间中不停的的前后移动，然后接受命运的轮回生产出下一代机器人。
