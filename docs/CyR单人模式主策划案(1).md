# 1.游戏概述
## 1.1概述

### 1.1.1性质：
一局两个小时左右的肉鸽游戏。玩家一共要打从L1到L4的四张地图，每张地图各有两个boss，打完所有8个boss即为游戏通关。玩家在游戏中可以改变所处的时间和时代，来完成战斗，物品收集，路线选择等一系列操作。

### 1.1.2内外循环：
局内循环：
进入地图 → 战斗 → 打小怪没有掉落，打精英怪掉落时间颗粒→（ 使用时间颗粒倒退或改变流速技能战斗）→（使用时间颗粒切换时代）→在商店升级以及恢复状态 → 构建 Build → 打两个Boss房 → 被杀死或（往下跳逐渐加速）通关 → 结算，剧情，进入下一张地图

注意游戏并不会要求玩家严格按照上面的顺序和流程走完地图。


局外循环和养成系统：
打完全部四张地图→触发剧情→结算获得（局外）资源 → 解锁新武器/天赋 → 用新武器/天赋生产下一局的初始机器人→ 用这个新机器人再进一局

## 1.2与其它游戏差异点
- 采用灰色系，主要用灰蓝和灰绿作为基本色调。文学背景缝合四个四重奏和环形废墟，世界观具有现代主义色彩
- 空间循环：环形地图，上就是下，左就是右
- **核心**：大量的时间系玩法，怪物和机制。如通过回退和加速纠正失误；回退造成二次伤害；时间武器；瞬移怪；改变时代来选择路径等等。
# 2.核心玩法和世界观设定
## 2.1时间相关详解
时间颗粒是游戏中的唯一一种资源，既用于释放技能又用于购买，资源管理是游戏中一大要点。

### 2.1.1
- 游戏的时间标识分为时间和时代两个部分（如：时代III午后）。时代分I到V五个阶段；时间分`黎明`、`早晨`、`正午`、`午后`、`黄昏`与`寂灭`六个阶段。玩家每张地图都出生于时代III的黎明。
- 玩家UI左上角有血量条和时间颗粒两个条。血量顾名思义；时间颗粒相当于技能条和资源条，通过打怪积攒，用于存储时间，可以被清空。
- 时间颗粒的来源：精英怪和boss掉落；从静物（相当于宝箱）中抽取时间颗粒（比如石碑样的损坏的时代改变器）
- 玩家消耗时间颗粒，产生三大类效果：临时回溯，时间加速和改变时代。
### 2.1.2
- 临时回溯即让玩家，小怪（精英怪和Boss无影响）和整个世界倒流回从前；时间加速即让玩家相对于世界行动的更快（显示为玩家人，武器，子弹原速；地图，怪物，怪物的子弹变慢）。这两种效果相当于技能，改变时间但不改变时代，玩家随时都可以使用。
- 改变时代需要在地图特殊的位置（时代改变器）通过消耗时间颗粒进行。玩家可以进入同一张地图的不同时代（实际上会通过画五张大致相同但部分路径和小怪分布不同的地图来达到这种效果，但五张图共享同样的精英怪和boss数据），一般地时代数字越小地图越新，数字越大地图越破碎和古老。这种效果改变时代但不改变时间。
### 2.1.3
- 时间会从第一个阶段慢慢滑向第六个阶段，期间使用回溯和加速可以部分改变时间的进程（会有限制使得玩家不能一次改变太多）。如果在到达寂灭后仍未完成通关同样视为游戏失败，但六个阶段的总时间较长，不会导致玩家游玩过于紧张（类似搜打撤游戏中的限时）
- 一天中的不同时间**对于游戏玩法没有本质影响**：只是加入了总的游戏限时，以及在光影和环境上会有变化。
- 不同时代**会对游戏玩法产生影响**：一些道路只在某些时代才会开启，导致地图结构有所变化（类似一个五层的迷宫）；不同时代商店售卖的东西有差异；某个特定时代可能有类似隐藏房间有特殊奖励；同时由于小怪会换掉，重新清怪需要时间，需要玩家权衡。

 ## 2.2核心玩法
- 玩家开局一把基础武器（手枪），在地图中清理怪物（小怪不掉落时间，也会受所有时间系技能和效果的影响，发生反向移动甚至复活；精英怪和boss掉落时间，不受时间回溯影响，但会受时间加速影响）；开宝箱；移动到各个时代与不同的商店交易，探索有差异的地图；最后进入boss房打掉两个boss即可进入下一张地图
- 胜利条件：打掉两个boss。失败条件：被怪打死或者拖的时间太长导致寂灭。失败后将倒回该张地图开始时（相当于一张图存一次档）。
- 玩家可以肉鸽的东西：自身的数值(血量，护盾），技能（消耗更少颗粒），饰品（tag），buff和debuff；道具（手雷，烟雾，或者类似MC喷溅药水）；武器的种类，基础数值，配件，buff。
- 商店的功能：用时间颗粒购买东西；**回血/维修**；锻造。地图中心点商店功能最齐全，外围会有承担商店部分功能的建筑。
- 在完成一局游戏后，角色（机器人）在设定上要''生产下一个机器人''，然后玩家将使用上一局生产的机器人开始下一局的游戏。这样每一局的初始机器人都有差别，即局外的养成系统。

## 2.3世界观设定
- 这个世界的时间线类似于螺纹（有两个“维度”），每一天（黎明→正午→寂灭→黎明）都循环一次，在每一次循环中有细微的变动。所以加速和回溯技能相当于沿着螺纹方向走；改变时代相当于沿着垂直螺纹的方向走。
- 在一局（四张地图）结束后，机器人（对应环形废墟魔法师）被要求生产出新的机器人（对应孩子）。玩家在第一次游玩时也终于意识到自己的机器人也是由上一代的机器人生产出来的（对应结构嵌套）。在生产（局外养成）完后，玩家会看到新的机器人以跟自己从前一模一样的路径走向了第一张地图（对应时间和命运轮回观念）。
- 由于机器人是一层一层生产出来的，所以设定上它是无法真正被打死或迷失的（对应孩子不怕火）。每次游戏失败玩家点击''重生''，会看到时间溯源的画面，回到地图开始时，即机器人只是又回到了过去，而不是死了。它没法死去，它只能在时间中不停的的前后移动，然后接受命运的轮回生产出下一代机器人。
- 以上三点是世界观在三个意义上的时间轮回：时代变换，死亡重生，和设定上的大轮回。
