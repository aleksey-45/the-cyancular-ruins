# 武器与装备

`WeaponRegistry` 定义手枪、步枪、M82A1、S686、榴弹发射器、激光枪、复合弓和 M249。`GunBody` 按定义处理按下、连发、松手与蓄力扳机，并推进瞄准、装填、冷却和后坐力。`WeaponBase` 从武器表读取图集区域和表现参数，地面掉落从同一条目读取碰撞盒。 [武器表](../core/sim/weapon_registry.gd) · [GunBody](../core/sim/gun_body.gd)

- 复合弓按住 0.8 秒达到满蓄，松手发箭。初速从 500 至 1500 px/s，伤害从 4 至 35。箭受重力与水阻，预瞄使用同样的出射参数。
- M249 按住 0.3 秒后开始连射，弹匣容量为 100 发。松手或换枪会清除按住时长。蓄力与扳机延迟共用装备的按住时长字段。
- 榴弹发射器按射手最多保留 3 枚在途榴弹，换枪后仍由世界推进。激光枪使用反射光束。 [战斗结算](simulation.md)

背包容量为 8 格，最多持有 4 把武器。轻、中、重装备占 2、3、4 格。拾取在 64 像素环面半径内选择最近的可用掉落，同距取较小实例 ID。长按丢弃键 0.6 秒触发丢弃，丢出者有 0.5 秒的重新拾取间隔。剩余弹药由背包装备实例保存，手持武器直接读取并更新该槽位，丢弃时残弹随装备转移。单人和 Beta 回溯保留拾取与丢弃结果，恢复仍持有的同一实例的弹药和历史手持武器的状态。 [背包](../core/sim/weapon_inventory.gd) · [掉落物查询](../core/sim/ground_weapon_field.gd)

开局至少启用一种武器。单人使用第一种可用武器，多人从可用列表为各玩家独立随机发放。地图另生成每种至多两件地面掉落。快照分别保存背包、当前装备实例和枪械状态块。枪械状态块保存冷却、装填与按住时长等计时。榴弹达到在途上限时拒绝出手，弹药与冷却保持原值。 [装备装配](../scenes/player/weapon_component.gd)

新增装备时分配未使用的类型 ID，并在武器表填写图集区域、掉落碰撞盒、触发方式和攻击参数。攻击分为弹丸、光束和近战。近战使用 `range` 和 `hit_radius` 判定前方范围，遵守墙体遮挡和队伍关系。只有配置 `mag` 的装备才消耗弹药并可装填。 [攻击结算](../core/sim/shot_rules.gd)
