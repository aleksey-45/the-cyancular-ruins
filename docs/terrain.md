# 地形

`Terrain` 保存地图的 16 像素子格及其本局耐久度、碰撞形状和地形版本。每个子格的初始耐久度取自自身材质。墙体阻挡移动，梯子和铁链支持攀爬，水体用于检测浸水。铁链端部有提供站立支撑的碰撞形状。[地形数据](../core/sim/terrain.gd) · [材质表](../data/tile_defs.json)

## 碰撞与破坏

相邻的实心子格合并为矩形碰撞形状，并通过 `PhysicsServer2D` 添加到当前物理空间。不可破坏墙体、铁链端部的平台以及各个可破坏分块使用各自的静态物理体。每个可破坏分块最多覆盖 48×48 个子格。同尺寸的矩形共用形状 RID，可破坏分块根据子格的占用情况复用已计算的形状布局。

地图边缘的地形按地图宽高平移到另一侧，供跨越边缘的碰撞检测使用。绘制时也将地形平移到另一侧，并按摄像机视野决定绘制范围。`TileMapLayer` 显示墙体和水体，地形碰撞来自 `Terrain` 创建的静态物理体。[碰撞查询](../core/sim/collision_world.gd) · [地形视图](../core/present/terrain_view.gd)

普通弹丸击中可破坏子格时，命中位置所在的 2×2 子格分块内，每个可被子弹破坏的子格都扣除本发伤害。榴弹按相同的 32×32 像素分块计算衰减伤害。地图宽高为奇数时，边缘分块只包含实际存在的子格。激光按命中的 64 像素瓦片对其中可被爆炸破坏的子格分别扣血。

子格从实心变为空或恢复时，对应碰撞分块和渲染位置会标记为待更新。同一批次中的重复修改合并处理。战斗帧末更新的碰撞用于下一帧的移动和弹丸运动。重开关卡或开始新回合时恢复地图的初始地形。

视线检测沿最短路径查找遮挡，射线穿过地图边缘时从另一侧继续检测。光束也按这种方式检测，命中后沿反射方向继续检测剩余距离。绘制时将各段光束连成一条折线。[地形射线](../core/sim/terrain.gd) · [光束命中](../core/sim/shot_rules.gd)

## 回溯与网络同步

地形每次提交耐久变化时，在一条线性日志里记录受影响子格的旧耐久。世界检查点只保存日志位置。恢复时从日志尾部逐批取出差分并撤销，下一次提交从恢复的位置继续。只有实心占用变化的分块更新碰撞。

服务器从日志汇总子格的最终耐久，经可靠有序通道发布结果版本和差分，然后释放已发布的记录。客户端排队接收差分。采用权威状态时，先撤销上一个权威版本之后的预测修改，再依次应用补丁到所需版本。更晚的补丁继续排队。基线保存相对原始地图的差分。

单人世界回溯撤销到历史样本记录的位置。历史窗口移过旧样本时释放它之前的地形日志。表现合并两次呈现之间实心占用的变化。 [Terrain](../core/sim/terrain.gd) · [联机系统](netplay.md)
