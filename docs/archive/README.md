## 封存纪律

1. 搬进来的文件**不再订正** —— 它们是历史快照。发现里面某条信息今天仍然有效，做法是
   **把它摘进 `docs/eng/` 对应域文档**并在那里维护，**不要回来改这里**。
2. 搬进来的文件**不得被现行文档当作权威引用**。现行文档要指向它们时，必须写明"已封存 / 只作查证"。
3. 新增封存对象时，在本表补一行：**它是什么 + 为什么封存**（缺任一条就别搬）。
