# 敌人

单人关卡按地图中 `# enemy TYPE X Y` 的顺序创建敌人。类型表指定资源路径和编辑器显示信息，每种敌人的资源保存 AI 脚本、凸碰撞形状、接触矩形、生命值和动画。三种 AI 都跟踪本局玩家，`EnemyBase` 负责移动、浸水、击退和死亡。[类型表](../data/enemies.json) · [资源定义](../core/config/enemy_type.gd) · [敌人模拟](../scenes/enemies/enemy_base.gd)

接触攻击在结算时用敌人的缩放、偏移和矩形尺寸查询玩家碰撞层。玩家的站姿、蹲姿及边界镜像都参与当帧判定。[接触判定](../scenes/enemies/enemy_base.gd)

| 类型 | 行为 |
|---|---|
| `jump_bird` | 接近时从休眠中苏醒，跳向玩家。进入攻击范围后蓄力扑击，再后跳并继续追击 |
| `fly_bird` | 起飞后绕到玩家斜上方，预估玩家位置并投弹。生命值低于 25% 时改为冲撞，命中或超时后自毁 |
| `black_bird` | 乌鸫苏醒后巡逻，在玩家另一侧寻找传送点。传送后下落并突进，最后后跳。击败后获得 300 个时间颗粒 |

飞鸟使用 A* 寻路，地图两侧的瓦片视为相邻。搜索路径时，用飞鸟的包围盒排除与地形、水体或附近角色重叠的位置。飞鸟起飞和降落时切换碰撞形状，并沿最短路线飞向各个路径点。[飞行 AI](../scenes/enemies/enemy_fly_bird.gd)

普通敌人按出生顺序参与回溯。死亡后尸体在短时间内仍可移动，计时结束后停止更新并关闭碰撞。回到尸体尚在的时刻会恢复剩余时间，回到受击前会恢复生命值。乌鸫在回溯期间继续行动。[世界回溯](../core/sim/rewind_history.gd) · [敌人模拟](../scenes/enemies/enemy_base.gd)
