# 敌人

单人关卡按 CYRM 地图中 `enemy` 点位的 ID 顺序生成敌人。类型表按 ID 查找敌人资源，每种资源定义 AI 脚本、凸碰撞形状、接触攻击矩形、生命值和动画。`EnemyBase` 提供共用的移动、浸水、击退和死亡逻辑。[类型表](../core/config/enemy_type.gd) · [跳鸟资源](../scenes/enemies/enemy_jump_bird.tres) · [敌人模拟](../scenes/enemies/enemy_base.gd)

接触攻击将敌人的攻击矩形变换到世界坐标，再查询是否与玩家碰撞形状重叠。判定使用玩家当帧的站立或蹲伏形状，也包括平移到地图另一侧的碰撞形状。[接触判定](../scenes/enemies/enemy_base.gd)

| 类型 | 行为 |
|---|---|
| `jump_bird` | 接近时从休眠中苏醒，跳向玩家。进入攻击范围后蓄力扑击，再后跳并继续追击 |
| `fly_bird` | 起飞后绕到玩家斜上方，预估玩家位置并投弹。生命值低于 25% 时改为冲撞，命中或超时后自毁 |
| `black_bird` | 乌鸫苏醒后巡逻，在玩家另一侧寻找传送点。传送后下落并突进，最后后跳。击败后获得 300 个时间颗粒 |

飞鸟在子格上用 A* 寻路，地图边缘两侧的子格视为相邻。搜索时用飞鸟的包围盒排除与地形、水体或附近角色重叠的位置。起飞和降落时切换碰撞形状，飞行时沿最短路线飞向各路径点。[飞行 AI](../scenes/enemies/enemy_fly_bird.gd)

单人世界回溯会恢复普通敌人的历史状态。敌人死亡后，尸体短时间内仍可移动，计时结束后停止更新并关闭碰撞。回溯到尸体尚在的时刻会恢复尸体的剩余时间，回到受击前会恢复当时的生命值。精英敌人乌鸫在回溯期间继续行动。[世界回溯](../core/sim/world_time.gd) · [敌人模拟](../scenes/enemies/enemy_base.gd)
