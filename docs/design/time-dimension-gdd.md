# 《The Cyancular Ruins》时间维度玩法 策划案 v0.3

> 状态：v0.3（单钟定稿版） · 载体：现有 Godot 工程演进 · 范围：首版仅单机，联机预留
> 本文档是时间维度玩法的单一事实来源；所有数值均为**初版可调参数**，集中在 §9 参数总表。

---

## 0. 设计支柱（一切争议以此裁决）

1. **钟即世界**：时间坐标不是 UI 数字，它直接决定地图形态、事件触发、怪物强度。
2. **时间即代价**：力量、物资、通行，全部用同一块资源支付——每次消费都能"看见世界变糟一点"。
3. **夺回即推进**：击杀 = 夺回被窃的时间 = 世界的微恢复；玩家的每一次战斗都在推动世界修复。
4. **压力与希望的钟摆**：世界钟自然走向毁灭（压力），玩家用夺回的时间把它拨向灾前（希望）。输在钟走到尽头，赢在把钟拨过灾前。

## 1. 时间轴与世界模型

### 1.1 时间轴（单向轴 + 双向可动钟）

```
T_pre(灾前·毁灭度0%) ◄──── T_ruin(开局·毁灭度50%) ────► T_final(最终时刻·毁灭度100%)
        ▲ 回拨=世界恢复(胜利方向)         自然衰减 ► 世界崩坏(失败方向)
```

- 开局位于 **T_ruin**：大灾难已经发生、但"最终时刻"尚未到来。
- 世界钟 W = **距最终时刻的剩余分钟数**（基准局 W₀ = 60 分钟，见 §9）。
- **毁灭度 D = (120 − W) / 120**，映射到四个世界阶段（§1.3）。
- **失败**：W 归零（走到 T_final，全图终末化，强制结算）。
- **胜利**：击败最终 Boss → 获得巨额时间块 → 把 W 回拨越过 **T_pre**（W ≥ 120，毁灭度 0%），触发真结局「回到灾前」。

### 1.2 单钟模型（v0.2 决议：v1 唯一方案）

一块表，**一根针**：世界针 W 既是地图状态坐标，也是玩家的全部时间资源。

- **击杀怪物** → W 回拨 v（世界恢复一点，你的钟也变多了——资源与状态是同一个东西）；
- **消费（交易/合成/封存解封）** → W 向毁灭推进（**花时间 = 亲手提前灾变**，每次买卖都是时间决策）；
- 自然衰减 → W 持续走向 T_final。

> 单钟的戏剧性：不存在"私房时间"，你钱包里的每一分钟就是世界的寿命。
> 双针 + 联动系数 K 为**后备方案**（若测试期发现资源管理深度不足再启用），当前所有数值与系统均按单钟编写。

### 1.3 世界阶段（毁灭度四档）

| 毁灭度 D | 阶段名 | 世界表现 | 敌人 |
|---|---|---|---|
| 0–25% | 灾前余晖 | 完好建筑、明亮色板、无额外灾害 | 基础表 |
| 25–50% | 侵蚀 | 局部断瓦、火点、色板泛灰 | 基础表+精英出现 |
| 50–75% | 崩坏 | 大面积坍塌、坍塌事件频率上升 | 强化表、成群刷新 |
| 75–100% | 终末 | 全图裂化、终末色板、屏幕边缘暗角常驻 | 精英+终末怪 |

阶段由 W 阈值触发（§9），每档是一组**表现参数包**（色板/刷怪表/事件权重），内容可增量添加。

## 2. 核心循环

```
探索/战斗 ──击杀──► 世界钟 W 回拨(世界恢复+资源入袋,同一件事)
   ▲                                        │
   │                              消费 W(交易/合成/封存解封)
   │                              —— 每花一分钟,灾变近一分钟
   │                                        │
   └──── W 自然衰减(世界崩坏,事件触发,难度爬升) ◄────────┘
```

压力来源：自然衰减 + 衰减随毁灭度加速（§9）。
希望来源：击杀回收 + 灌注 + Boss 巨额时间块。

---

## 3. 时间流速场

- 每张地图/区域可定义**流速系数 F**（默认 1.0）：
  - 时间涨潮区 F = 2.0（站在里面世界钟双倍速流逝——高风险区，回报也丰厚）；
  - 时滞区 F = 0.5（时缓区——安全但收益也慢）；
  - 事件可临时改写 F（如"时间风暴" 3.0，持续 30 秒，逼玩家做路线决策）。
- 流速影响：世界针衰减速度、以及**个人针的击杀回收量**（涨潮区杀怪双倍回收）。
- **明确约定：实体位置不随时间流速/回拨变化**（玩家与怪物的空间坐标独立于时间轴——这是可玩性让步，写死为设计不变量）。

## 4. 系统规格

### 4.1 时间账本（核心抽象）

所有时间收支走统一账本，便于单钟/双钟切换与未来联机：

| 操作 | 世界针 W(单钟) | 备注 |
|---|---|---|
| 击杀回收 | **回拨 −v** | v = 该怪时间价值;既是资源入袋也是世界恢复 |
| 自然流逝 | 前进 +F·Δt | 只烧世界 |
| NPC 交易 | **前进 +y** | 花时间=灾变临近;价目表 §4.6 |
| 封存 | 前进 +z | 时间铸成块入物品栏(§4.7) |
| 解封(注入/回溯区) | 回拨 −z | 就地回拨世界 |
| 死亡惩罚 | 前进 +5min(世界骤进) | 可调 §9 |
| Boss 巨额块 | 回拨 −大量 | 通关钥匙 |

> 灌注（个人针→世界针）在单钟下**不复存在**——击杀即灌注，消费即抽取。

### 4.2 时间事件系统（地图的"第三维度"数据）

**事件 = (触发阈值 W_t, 方向, 动作, 区域, 提示)**

- 触发：世界钟**正向跨越** W_t 时执行（从安全侧越向危险侧才触发；回拨跨越不触发，避免玩家用回拨"闪避"已编排的戏剧事件后又被二次轰炸——但"修复类"事件可标记为反向可触发，如坍塌的路在回拨后重开）。
- 动作原型（首批 8 个，覆盖绝大多数关卡需求）：

| 原型 | 效果 | 实现 |
|---|---|---|
| 坍塌 | 指定区域瓦片变为实心 | 状态瓦片层切换 + 分块重建（复用现有 chunk 系统） |
| 崩开 | 实心变空气（炸开的墙） | 同上 |
| 怪潮 | 区域按表刷怪 | 复用 EnemySpawner |
| 强化 | 怪物表切强化档 | 阶段参数包 |
| 时间风暴 | 区域流速 F 临时改写 | 流速场 §3 |
| 补给窗 | 商人/物资限时出现 | NPC/掉落 |
| 地貌变化 | 换瓦片皮肤（火烧/腐蚀） | 表现层 |
| 剧情播报 | 表针特写 + 音效 + 字幕 | UI |

- **事件预告**：阈值前 60 秒 HUD 表盘警告（ T−60″ 桥梁坍塌 ），配合音效滴答加速——把压迫感做出来，也给玩家公平的路线决策窗。

### 4.3 地图时空格式（.cyrm v4）

- **空间层与时间层分离**，解决"随机地图 + 时间线"的生成难题：
  - 空间层：现有 .cyrm 逻辑**原样保留**，随机生成的地图照旧随机；
  - 时间层：**事件调度表**（§4.2 的事件列表），可手写、可按种子从"事件原型模板库"程序化生成。
- **格式方案**：`.cyrm` 头部加 `# cyrm-v4` 与 `# timeline:` 段（事件行）；无 timeline 段的 v3 地图 = 自动按种子生成默认时间层 → **全部旧图/导入图即刻兼容时间玩法**。
- 地图导入工具（已有）拖入 v4/v3 均可；选图 UI 不变。

### 4.4 击杀回收表（初版数值见 §9）

| 敌人 | 时间价值 v |
|---|---|
| 小型鸟 | 0.2 min |
| 飞鸟/跳鸟 | 0.35 min |
| 黑影（刺客） | 1.0 min |
| 精英（阶段怪） | 2.0 min |
| 区域 Boss | 15.0 min |
| 最终 Boss | 60.0 min（足以回拨越过灾前） |

### 4.5 交易系统（v1 = NPC 时间商人）

- **时间商人**（新 NPC）：固定点位/事件"补给窗"出现；价目表以分钟计价（医疗包 3′、弹药箱 2′、封存块 10′、传说武器 25′…）；
- 交易 = 世界针 W **向前支付**（花钱即让灾变临近——单钟下不存在"安全的钱"）；
- 预留：玩家间交易（联机期）——封存块天然是可转让载体。

### 4.6 封存时间块

- **封存**：把个人针的时间铸成面额块（5′/10′/25′），入物品栏（走现有道具卡/道具系统管线——封存块就是一张道具卡）；
- **死亡豁免**：封存量不受死亡惩罚；
- **使用**：① 注入世界钟（就地回拨）；② 支付交易；③（进阶道具变体）掷出后生成"时间回溯区"，区域内已触发事件反向重置（坍塌重开）——作为稀有道具卡；
- 与现有道具系统完全兼容：时间块=新道具 kind，击退炮等同款管线。

### 4.7 表 HUD（一块表，两根针）

- 常驻表盘（中央上方）：**唯一指针 W**（T-xx.xx 倒数,10ms 粒度显示百分秒）；
- 阈值前 60s：表盘警示（抖动+滴答加速+事件预告字幕）；
- 毁灭度阶段切换：全屏钟鸣 + 色板渐变（复用 post_process）；
- 拟真细节：击杀时指针**倒跳一小格**的动画；消费时指针**向前窜一格**并短促红闪——收支即世界的生死,可视化是单钟体验的核心。

### 4.8 失败与结算

- **死亡（HP=0）**：原地结算损失（§4.1），重生（沿用现有重生物件）；
- **终末（W=0）**：全图终末化演出 → 强制结算画面（本局回收总量/修复进度/存活时长）→ 回主菜单；
- **胜利**：W 回拨 ≥ 灾前 → 真结局演出「灾前的一天」（安静的日常场景，与全片崩坏形成情感对比）。

### 4.9 最终 Boss：灾厄守时者

- 出现条件：毁灭度首次 ≥ 75% 后的固定事件窗（或累计回收达标后触发，二选一，测试期定）；
- 击败掉落「巨针」时间块（+60′），并解锁"灌注无上限"；
- 设计意图：Boss 战本身是资源争夺——它的攻击会**偷走个人针时间**（打中扣表），强制玩家在"血量"与"时间"双条血线间做权衡。

## 6. 联机扩展预留（二期，仅方向）

- **共享世界针 + 私人表**：W 全房一致（服务器权威，灌注需全房投票或房主决定）；P 私有；
- 死亡惩罚、交易走服务器；时间事件由服务器跨越阈值后广播；
- 本地预测需把 W 纳入 capture_state（或干脆 W 只由服务器驱动、客户端插值显示——推荐后者，避免新增分歧源）。

## 7. 首个示范关：教学与体验锚点

- 一张手作小图（含 v4 时间层），强制教学三件事：
  1. 开场 2 分钟：第一次自然事件（桥塌）——教会"世界会变"；
  2. 击杀首批怪：世界针倒跳——教会"战斗在修复世界"；
  3. 商人出现：花时间换物资——教会"时间是代价"。
- 结尾：灌注回拨使"坍塌的路重开"，走通即完成教学闭环。

## 12. v0.2 决议记录(2026-09-16,制作人拍板)

1. **单钟模型(定案)**:v1 只做一根世界针 W;**K 参数废除**,全文按单钟改写(本版已完成)。双针为后备方案存档。
   - 击杀 → W 回拨;**消费(交易/合成)→ W 向毁灭推进**——花时间=亲手提前灾变,买卖即时间决策。
2. **时间粒度 10ms**:内部浮点秒;事件行支持小数秒(`# tl: 14.300`);HUD 显示百分秒(T-14.30)。
3. **子弹时间(决策时停)**:TimeWorld.scale;任何决策 UI(交易/合成/地图)打开 → scale=0,思考不烧钟。
   可选 0.05 慢放档位作风格化。**M1 起必须存在**,防菜单焦虑。
4. **时空地图 = 事件溯源模型**(制作人方案,替代 v0.1 §4.2 的单向调度器):
   - 时间线 = append-only 事件日志;事件 = {t_ms, 正向操作, 逆向操作, origin: scheduled|player};
   - **玩家操作入史**:拆墙(逆=按 pristine 恢复)/开门/拾取;**击杀不入史**(实体位置不回拨决议的推论——
     击杀只动时钟数字,回拨撤"世界的伤"不撤"战果");
   - 回拨 = LIFO 倒放日志(t > 目标时刻者逐个执行逆操作);scheduled 事件回拨后**重新武装**
     (再次跨越可再触发),player 事件不重发;
   - 逆操作完备性 = 铁律:每个入史 kind 必须带正确逆操作并过探针,否则产生幽灵状态。
