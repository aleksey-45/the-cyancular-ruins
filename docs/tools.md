# 运行与工具

## 从源码运行

项目使用 Godot 4.7.1 标准版。原生扩展由 Python 脚本调用 Git、CMake 和 Ninja 构建，CI 使用 Python 3.12。Windows 使用配置了 x64 MSVC 的开发者终端，macOS 使用 Xcode 命令行工具。网络传输与进程管理扩展共用一个 CMake 工程。[构建配置](../native/CMakeLists.txt)

在仓库根目录运行以下命令，安装构建工具、编译原生扩展、导入资源并启动游戏。

```sh
python -m pip install cmake==3.31.6 ninja==1.11.1.4
python tools/build_native.py
godot --headless --editor --path . --import
godot --path .
```

`godot` 可替换为可执行文件的完整路径。也可以用 Godot 编辑器打开项目，按 F5 运行主场景。[项目配置](../project.godot)

专用服务器以无头模式运行，默认监听 UDP 7777，启动成功后输出 `SERVER READY`。可用 `--port` 指定监听端口。

```sh
godot --headless --path . res://server/server_main.tscn -- --port 7777
```

发布包中的服务器入口见 [构建与发布](../RELEASE.md#发布包中的专用服务器)。

## 数值资源

世界重力和水体参数定义在 `WorldConfig` 资源中。玩家、敌人和时间参数分别保存在 `core/config/` 下的自定义资源中。[世界参数](../core/config/world_config.tres)

## 自动加载节点

Godot 根据 [project.godot](../project.godot) 的 `[autoload]` 配置，在加载主场景前添加以下节点。

| 节点 | 职责 |
|---|---|
| [PerfMonitor](../core/config/perf_monitor.gd) | 根据命令行选项启用性能采样、发布统计和写入报告 |
| [NetBus](../core/net/net_bus.gd) | 通过 GameNetworkingSockets 收发消息，分发输入、状态和事件 |
| [NetSession](../core/net/net_session.gd) | 管理联机连接、断线重连和游戏启动的后台进程 |
| [Settings](../core/config/settings.gd) | 读写并应用显示、音量与按键设置 |

## 地图编辑器

编辑器的工具栏、图层、状态栏和确认窗口共用游戏主题。[公共主题](ui.md#主题与设置)

从桌面主菜单进入「地图编辑器」。选择「文件 → 打开地图」或按 Ctrl/Cmd+O 可打开系统文件选择窗口，默认目录为 `user://maps`，也可以浏览其他目录中的 `.cyrm` 文件。「另存为」使用同一个系统窗口。单人和联机选图界面会列出默认目录中的地图。发行包的 `maps/` 目录附带 `demo.cyrm` 和 `newfactory.cyrm` 两张示例地图。文件名旁的标记表示有未保存的修改。编辑器每 10 秒将未保存的修改写入 `user://map-editor.draft`，下次进入时恢复草稿。[地图编辑器场景](../scenes/map_editor.tscn)

在左栏选择材质，右栏显示当前工具的参数。各图层可分别切换可见和锁定状态。「视图」菜单提供网格、环面预览、分区标线和压暗其他层。「编辑」菜单可调整地图尺寸或打开注记。滚轮以光标为中心缩放画布，按住中键或空格加左键可平移。前三层使用材质和色调。背景 1 至 4 支持绘制 RGBA 颜色，编辑时对齐网格，试玩时从近到远以主层滚动速度的 80%、60%、40%、20% 移动。

画笔和点位以 16 像素子格定位。拖动画笔后松开鼠标完成一笔，按 Esc 取消当前操作。选框内拖动可移动选中内容，按住 Shift 可重画选框。渐变在选区内绘制。按 Ctrl/Cmd+Z 撤销，按 Ctrl/Cmd+Shift+Z 重做。

使用画笔或「点位」工具时，可以拖动已有点位，松开鼠标确认，或按 Esc 取消。也可选中一点，点「移至…」后单击目标子格，期间仍可平移或缩放画布。右栏「点位类型」提供玩家出生点（单人或第二出生点）、联机复活点和敌人出生点。未选中点位时，选择类型会进入放置模式。「放置点位（连续）」可连续放置同类点位，取消勾选后恢复选择和拖动。

按住 Alt 可用画笔在点位所在子格落笔。右侧点位列表可选取重叠的点位，双击一行可将画布定位到该点。选中敌人出生点或复活点后，可用下拉框更改敌人类型，或将复活点分配给侧 1 或侧 2。更改立即生效，可撤销。

顶栏「光照预览」从正午开始，可按 15 分钟的间隔查看一天中的光照，关闭预览后恢复原色。预览时刻只影响显示。按 F5 试玩当前地图，沿用当前预览时刻和未保存的地图修改。已选中点位时在该处出生，否则使用单人关卡的默认出生位置。按 Esc 返回编辑器。使用「保存」或「另存为」可将地图写入文件。[静态地图操作](../core/sim/cyrm_map.gd) · [CYRM 地图格式](world.md) · [自动化测试](tests.md)
