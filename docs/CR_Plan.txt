┌─ v1.1.3 ──────────────────────────────────────────────────────
│ 分支:KH_v1_1_3    状态:已发布    主题:体验与稳定修补
└───────────────────────────────────────────────────────────────
  ◆ 一句话
    联机不再干等、进图不再蓝屏、子弹判得中、IP 看得见、UI 与工具不再抽风。

  ◆ 更新内容
    ① 联机稳定
       · 幽灵房间:点了没反应的房 → 超时自动回大厅;大厅不再滞留已开局/失效房
       · 入房后配对被取消 / 房主掉线 → 不再干等(补齐两个边缘态)
       · 1v1 进图蓝屏:补回 match_start「延迟出 poll 栈」(分支整合时丢过一次)
       · 子弹"看着重合却不判中" → 命中判定改「扫掠线段 + 身体圆」双判定
    ② 大乱斗
       · 远端激光光束:大乱斗客户端补上 beam_fired 订阅(此前只有 1v1 能看到对手激光)
       · 修掉本机 IP 标签压住提示文字造成的严重 UI 重叠
    ③ 本地一键开服
       · 大厅页「启动/重启本机服务器」:杀旧实例 → 拉起同目录服务端 → 自动连 127.0.0.1 刷新
       · 重启期间吞掉"服务器断开/连接失败"预期噪音,不再覆盖提示
       · 本机 IP 变页面常驻标签(进页即显),按钮按下与成功提示都带 IP
       · 服务端是无控制台 GUI exe → IP 落盘 exe 旁 local_ip.txt(公网 IP 到手后补写)
       · 端口轮询/杀进程改隐形执行:不再每秒弹黑窗(此前像服务器反复开关)
    ④ 工具链 / 兼容
       · 卡编辑器"agent 施工一小时没动静"三处修复:静默拉起失败 / 停止失效 / 完成标记丢失
       · 现役 6 武器做成对照卡(手枪/步枪/重狙/霰弹/榴弹/激光),数值 = 实装 tscn 导出
       · 项目内中文文件名改英文(build_exe.bat / launch_card_editor.bat / local_ip.txt),win/mac 通用
       · 实验:移植 C2 客户端预测 rollback(开关 LOCAL_PREDICTION_ENABLED,默认 OFF)
       · 试过"榴弹直击钉住原地引爆",手感不佳已回滚(保持反弹 + 引信)
  ◆ 备注
    · 换弹仍只限单机(PvP/大乱斗无弹夹系统,对局中按 R 不换弹)
    · 公网 IP 会变:每次开服看 local_ip.txt;局域网 IP 基本不变

┌─ v1.1.2 ──────────────────────────────────────────────────────
│ 分支:KH_v1_1_2    状态:已发布    主题:玩法大版本
└───────────────────────────────────────────────────────────────
  ◆ 一句话
    大乱斗真正能打完一局、打起来更爽;武器与手感明显扩充。

  ◆ 更新内容
    ① 武器
       · 新增第 6 槽激光枪:即时光束,开火瞬间算反射折线(最多 5 次反射),
         路径上敌人/玩家一次性结算,可磨树叶/树干;蓝色双层光束 + 枪口光球
       · 榴弹两修:① PvP 命中却不爆(引信被普通结算吞掉) ② 多人同炸卡崩 → 每人同屏最多 3 发
       · 黑鸟调强(跟上游手感):游走更快、瞬移判定更频、冲锋更快更狠、后跳更远且保持面朝玩家
    ② 手感
       · 下蹲改逐帧推导:空中松开 S 不再落地卡蹲;新增蹲走
       · 冲刺大改:可被跳/撞墙打断、空中重力 ×0.35(能跨沟)、收尾平滑、
         枪口不跟身体翻;速度 1500→1900、时长 0.6→0.4 秒
    ③ 生存与反馈
       · 单机倒地按 R = 原地重启(满血回出生点、清子弹敌人重刷),不再重建世界(避蓝屏)
       · 击杀中央播报 + 像素骷髅头 + 连杀计数(6 秒内累加,自己被击杀清零)
       · 激光补齐打击反馈:命中 X 标记 + 击杀归因
    ④ 大乱斗玩法
       · 出生/复活点改"开阔可走区"(头顶 2 格净空 + 左右空 + 同层连通 ≥20 格)
         → 不再出生在走不出去的小房间
       · 建房页可调一局限时(1~15 分钟);建房页可直接改角色颜色
       · 新增 K 键自杀脱困(卡死自救,2 秒复活,不给人记杀);排行榜加阵亡数
    ⑤ 稳定与工具
       · 主菜单→关卡改"先建新世界再拆旧菜单",规避建图同帧段错误(蓝屏)
       · 大乱斗点进蓝屏(大厅脚本解析失败 + 开局转场景 poll 栈)修复
       · 打包器/卡编辑器"双击闪退"根治(cmd 批处理 CRLF + GBK + console 版 Godot)
       · 打包脚本改为"客户端 + 服务端成对导出"
       · 服务端启动自动报本机 IP(局域网优先 + 公网尽力)
       · 纪律:版本名分支(KH_vX_Y_Z)永久保留,清理只删非版本名实验分支
