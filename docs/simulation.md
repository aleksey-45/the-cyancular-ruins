# 模拟与战斗

每场对局拥有独立的 `Terrain` 和 `World2D`。模拟层更新玩家、敌人、弹丸与地面武器，`ServerBody` 将它们的变换同步到 `PhysicsServer2D`。`GunBody` 管理手持武器的弹药、瞄准、射击间隔和装填。客户端视口使用该对局的 `World2D`，服务器可独立推进模拟。[物理体](../core/sim/server_body.gd) · [玩家](../scenes/player/player.gd) · [武器](../core/sim/gun_body.gd)

## 世界与会话

单人关卡、编辑器试玩和专用服务器都以 `MatchHost` 运行一个权威世界。本地席位直接提交本帧输入，远端席位按目标帧从各自的缓冲取出输入。两者使用同一套席位号和步进入口。远端客户端以 `PredictedMatch` 运行同一个模拟，并按服务器快照校正。[权威主机](../core/net/match_host.gd) · [客户端预测](../core/net/predicted_match.gd)

`WorldSpec.solo` 固定一个席位，按地图生成敌人，允许重试，装配世界时间。`WorldSpec.arena` 装配计分、回合与复活规则，Beta 对战另装配个人时间。时间能力负责推进、历史重置、账户和检查点。关卡与回合各自决定出生和结束条件，玩家离场时仍沿用开局规则。[开局预设](../core/sim/world_spec.gd) · [对战规则](../core/sim/match_rules.gd) · [时间接口](../core/sim/match_time.gd)

| 接口 | 行为 |
|---|---|
| `MatchWorld.new(spec)` | 创建并返回对局实例。 |
| `world.advance(inputs, commands)` | 按固定步长推进一次。`commands` 用于开始倒计时、玩家离场、联机主动倒地和单人重开。时间技能通过 `inputs` 触发。 |
| `world.sample(only_role)` | 采集当前帧的表现数据。角色 ID 用于筛选玩家及其攻击。传入 0 或省略时，采集整个世界，包含地面武器。 |
| `world.capture()` | 生成包含动态状态和地形版本的检查点。 |
| `world.restore(checkpoint)` | 恢复检查点中的帧末状态、地形版本及待结算爆炸等计时状态。 |
| `MatchHost.new(spec, local_role)` | 创建权威世界。指定本地席位，其余席位使用网络输入。专用服务器省略本地席位。 |
| `host.fixed_step(direct)` | 合并本帧直接提交的输入与各远端席位已到期的输入，推进一次权威世界。专用服务器直接调用 `host.fixed_step()`。 |
| `session.reconcile(ping_ms)` | 采用可用的服务器权威快照，必要时恢复模拟并重放未确认的输入。返回采用的快照，并按需附上位置校正数据。 |
| `session.predict(input)` | 提交本步新输入，推进预测，返回待发送的输入包及表现所需的前后两帧。 |

关卡每步采样一次，显示端保留相邻两帧供插值。服务器按发送节奏捕获世界检查点，客户端可据此恢复预测模拟。[世界接口](../core/sim/match_world.gd) · [显示采样](../core/present/match_sampler.gd)

## 固定步长模拟

本地输入适配器采集移动、瞄准、武器和技能操作。每个模拟步先处理对局指令和时间技能，再更新地面武器和角色。角色移动完成后，战斗模块按射击 ID 处理攻击请求，随后更新敌人和在途弹丸。最后结算到期的爆炸并提交地形改动，联机对局据此处理击杀归属、时间颗粒奖励、计分和复活。[输入](../core/net/local_input_source.gd) · [战斗](../core/sim/combat_simulator.gd) · [对局](../core/sim/match_world.gd)

| 操作 | 恢复范围 |
|---|---|
| 预测回滚 | 从服务器权威快照恢复模拟状态和帧号，按原目标帧重放仍有效的未确认输入。 |
| Beta 个人回溯 | 恢复该角色的状态、仍持有的武器状态，以及该角色发射且仍在场的弹丸运动状态。保留当前武器归属、已结算直击和其他角色。 |
| 单人世界回溯 | 恢复玩家、普通敌人、攻击状态、地形和战斗时钟。精英继续行动，地面武器暂停更新。玩家保留当前氧气、武器归属和射击序号。 |

时间技能以 20 Hz 记录历史，按技能范围保存相关角色和实体的状态，并复用未变化的记录。结束回溯后，从所选历史状态继续记录。单人回溯期间，战斗时钟倒退，模拟帧号继续递增。[历史存储](../core/sim/time_history.gd) · [个人回溯](../core/sim/personal_time.gd) · [世界回溯](../core/sim/world_time.gd)

## 物理查询

`CollisionWorld` 复用 Godot 的物理查询参数。角色调用 `PhysicsServer2D.body_test_motion()` 依次检测 X、Y 轴的位移，弹丸沿移动路径做扫掠检测。光束按宽度查询与路径重叠的形状，敌人的接触攻击只检测当前帧的矩形重叠。命中结果带有角色的实例 ID，可据此取得模拟对象。爆炸按爆心到角色的跨边界最短距离判定范围，再用射线检测地形遮挡。[CollisionWorld](../core/sim/collision_world.gd)

出生点校验使用玩家站立时的矩形碰撞范围。玩家蹲伏或倒地时使用较矮的矩形，靠近地图边缘时在同一物理体上添加平移后的碰撞形状，让地图另一侧也能检测到该玩家。

| 碰撞层 | 位值 | 对象 |
|---|---:|---|
| 1 | 1 | 地形 |
| 2 | 2 | A 队及未分队玩家 |
| 3 | 4 | 敌人 |
| 5 | 16 | B 队 |

默认情况下，玩家的移动由地形阻挡，敌人的移动由地形和其他敌人阻挡。玩家和敌人可以穿过彼此，敌人的矩形接触判定对两队玩家结算伤害。开启「玩家碰撞」后，1v1 和大乱斗的玩家之间会互相阻挡，团队赛仅在敌对角色之间启用碰撞。

## 伤害结算

攻击请求包含武器类型、射击序号、发射位置和方向、蓄力程度及弹丸速度倍率。弹丸散布用角色 ID 和射击序号生成可复现的随机种子。`ShotRules` 处理弹丸、光束及近战攻击，`CombatSimulator` 根据敌我关系、受击无敌时间和浸水状态结算伤害与击退。普通弹丸和光束命中敌方角色，范围爆炸也能伤害自己和队友。每次光束攻击对同一角色或 64×64 像素地形分块只结算一次。[攻击规则](../core/sim/shot_rules.gd) · [命中配置](../core/sim/combat_profiles.gd)

榴弹首次碰撞时启动引信，射程耗尽也会引爆。每枚榴弹最多造成一次直击。引爆时记录爆心，3 个模拟帧后结算范围伤害、击退和地形破坏。多个爆炸按结算帧和弹丸 ID 依次处理。普通接触攻击和飞鸟投弹受玩家的受击无敌时间限制，枪弹、光束和榴弹爆炸在这段时间内仍可命中。[战斗模拟](../core/sim/combat_simulator.gd) · [地形](terrain.md)

预测回滚或单人世界回溯恢复攻击状态时，引爆前的记录保存弹丸和引信，引爆后至结算前的记录保存爆心及预定的结算帧号。随战斗时钟恢复这些状态后，爆炸仍在原定帧结算。[检查点](../core/sim/match_world.gd)
