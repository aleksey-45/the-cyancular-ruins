# 模拟与战斗

每场对局持有自己的 `Terrain` 和 `World2D`。玩家、敌人、弹丸与地面武器都是普通模拟对象，`ServerBody` 将它们的位置写入 `PhysicsServer2D`。`Player` 保存角色状态，`GunBody` 管理当前武器的弹药、瞄准、冷却和装填。客户端视口使用同一个世界绘制关卡，服务器可以直接推进模拟。[物理体](../core/sim/server_body.gd) · [玩家](../scenes/player/player.gd) · [武器](../core/sim/gun_body.gd)

## 每帧更新

`LocalInputSource` 把按键、瞄准方向、长按丢弃和滚轮切换合成输入记录。`ActorStep` 使用同一种输入记录更新单人角色、服务器角色和客户端预测。每次更新分别生成开火或溺水等结算请求，以及落地和换弹等画面与音效事件。重放预测时跳过一次性画面与音效。[本地输入](../core/net/local_input_source.gd) · [角色更新](../core/sim/actor_step.gd)

本地对局、服务器和客户端预测都以 60 Hz 调用 `CombatSimulator.step()`。每帧先移动地面武器，再按角色 ID 处理输入与移动。所有角色就位后按射击 ID 执行攻击，更新敌人，并推进包括刚发射弹丸在内的所有在途弹丸。最后结算到期爆炸并更新地形碰撞。服务器随后推进回合，客户端重放时使用服务器确认的射击和终止帧。[战斗步进](../core/sim/combat_simulator.gd) · [本地对局](../scenes/solo_level.gd) · [服务器](../server/authority_world.gd)

世界回溯与个人回溯都用 `RewindHistory` 以 20 Hz 记录 `CombatSnapshot`。同一物理帧需要采样的玩家引用同一份检查点，每个玩家可以独立倒退、松开并从所选时刻继续。个人范围恢复使用者和仍在场的自有弹丸的运动状态。世界范围还恢复战斗帧号、弹丸的存在与结算状态、普通敌人和地形。网络预测使用同一种战斗检查点，并在 `PredictionFrame` 中额外保存时间账户和当帧射击。[时间历史](../core/sim/rewind_history.gd) · [战斗检查点](../core/sim/combat_snapshot.gd) · [预测回滚](../core/net/prediction_rollback.gd)

## 物理查询

`CollisionWorld` 复用 Godot 物理查询参数。角色依次沿 X、Y 轴调用 `PhysicsServer2D.body_test_motion()`，弹丸沿当前位移做扫掠检测。光束用形状查询找目标，敌人的接触攻击查询当帧的矩形重叠。物理体关联角色的实例 ID，命中可直接取得模拟对象。爆炸按对局名单计算环形距离，再用射线检查遮挡。出生点校验和玩家物理体共用站姿矩形。蹲伏和倒地切换到较矮的矩形。玩家靠近地图边缘时，会把当前碰撞形状复制到地图另一侧。原位置和复制后的形状都属于同一个物理体。[CollisionWorld](../core/sim/collision_world.gd)

| 碰撞层 | 位值 | 对象 |
|---|---:|---|
| 1 | 1 | 地形 |
| 2 | 2 | A 队及未分队玩家 |
| 3 | 4 | 敌人 |
| 4 | 16 | B 队 |

玩家默认只与地形碰撞；敌人只与地形、其他敌人碰撞。玩家与敌人**不物理互挡**（接触伤害由矩形查询结算），只有开启「玩家碰撞」时，敌对队伍的玩家才互相阻挡。地面武器是数据对象，没有物理层。

## 伤害结算

攻击请求包含武器类型、射击序号、发射位置和方向、蓄力程度及弹丸速度倍率。散射用角色 ID 和射击序号生成随机种子。`ShotRules` 处理弹丸、光束及近战攻击，`CombatSimulator` 根据目标关系、受击无敌时间和水体状态应用伤害及击退。普通弹丸和光束命中敌方角色，范围爆炸也能伤害自身和队友。每次光束攻击对同一实体或瓦片只结算一次。[攻击规则](../core/sim/shot_rules.gd) · [命中配置](../core/sim/combat_profiles.gd)

榴弹首次碰撞时启动引信，射程耗尽也会引爆。每枚榴弹最多造成一次直击。引爆帧发出爆炸事件，之后第 3 个模拟帧统一结算范围伤害、击退和地形破坏。多个爆炸按结算帧、弹丸 ID 排序。近身接触和鸟类炸弹遵守玩家的受击无敌时间，枪弹、光束和榴弹爆炸可以连续命中。[战斗模拟](../core/sim/combat_simulator.gd) · [地形](terrain.md)

回到引爆前，检查点恢复弹丸及引信。回到引爆与结算之间，检查点恢复爆心和原定的结算帧号，连同模拟时钟一起倒回。网络校正随后重放输入，世界回溯在松开技能后从所选状态继续。[战斗检查点](../core/sim/combat_snapshot.gd)
