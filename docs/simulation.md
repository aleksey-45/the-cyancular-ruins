# 模拟与战斗

每场对局持有自己的 `Terrain` 和 `World2D`。玩家、敌人、弹丸与地面武器都是普通模拟对象，`ServerBody` 将它们的位置写入 `PhysicsServer2D`。`Player` 保存角色状态，`GunBody` 管理当前武器的弹药、瞄准、冷却和装填。客户端视口使用同一个世界绘制关卡，服务器可以直接推进模拟。[物理体](../core/sim/server_body.gd) · [玩家](../scenes/player/player.gd) · [武器](../core/sim/gun_body.gd)

## 世界与会话

单人、编辑试玩、服务器和远程预测都建同一个 MatchWorld。WorldSpec 提供地图、席位、玩法参数和种子。单人装配世界时间规则，Beta 装配个人时间规则。同进程和网络接入都由 MatchSession 推进。

| 接口 | 行为 |
|---|---|
| MatchWorld.create(spec) | 建立独立世界和初始帧。 |
| world.advance(inputs, commands) | 提交一个固定步，返回借用帧视图。commands 用于开局、离场、重开和死亡倒带。 |
| world.capture() | 按需采集完整的动态状态和地形版本。 |
| world.restore(checkpoint) | 撤销到线性日志保留的地形版本，恢复帧末状态和计时任务，返回该帧视图。远程会话在调用前应用权威地形补丁。 |
| MatchSession.open_local / open_remote | 装配本机权威或远程会话。 |
| session.fixed_step(seat_intents) | 处理输入及提交帧，提供表现采样端点。 |

帧视图在下一次推进或恢复前有效。会话只保留展示所需的端点，传输和校正使用完整检查点。 [世界接口](../core/sim/match_world.gd) · [会话接口](../core/net/match_session.gd)

## 每帧更新

本地输入适配器采集移动、瞄准、武器和技能意图。世界先执行本步的控制意图与时间规则，再更新地面武器和角色。攻击按稳定 ID 结算，敌人与弹丸推进，到期爆炸与地形一起提交。已结算伤害直接交由世界处理归因、颗粒、计分与复活。画面提示从采样状态的变化推导。 [输入](../core/net/local_input_source.gd) · [战斗](../core/sim/combat_simulator.gd) · [表现](../core/present/match_presenter.gd)

| 操作 | 恢复范围 |
|---|---|
| 网络回滚 | 恢复完整检查点和提交号，按原目标帧重放后续输入。 |
| Beta 个人回溯 | 恢复该角色、仍拥有武器的历史数据和仍在场自有弹丸的运动。保留当前武器归属、已结算直击和其他角色。 |
| 单人世界回溯 | 恢复普通敌人、弹体存续、地形和战斗时钟。精英继续行动，地面武器暂停。保留当前氧气、武器归属和射击序号。 |

玩法历史以 20 Hz 记录，按作用范围保存需要的角色和实体字段并共享未变化的记录。技能选中历史点后沿该分支续接。单人回溯可以倒退战斗时间，每次提交的帧号持续前进。 [历史存储](../core/sim/time_history.gd) · [个人回溯](../core/sim/personal_time.gd) · [世界回溯](../core/sim/world_time.gd)

## 物理查询

`CollisionWorld` 复用 Godot 物理查询参数。角色依次沿 X、Y 轴调用 `PhysicsServer2D.body_test_motion()`，弹丸沿当前位移做扫掠检测。光束用形状查询找目标，敌人的接触攻击查询当帧的矩形重叠。物理体关联角色的实例 ID，命中可直接取得模拟对象。爆炸按对局名单计算环形距离，再用射线检查遮挡。出生点校验和玩家物理体共用站姿矩形。蹲伏和倒地切换到较矮的矩形。玩家靠近地图边缘时，会把当前碰撞形状复制到地图另一侧。原位置和复制后的形状都属于同一个物理体。[CollisionWorld](../core/sim/collision_world.gd)

| 碰撞层 | 位值 | 对象 |
|---|---:|---|
| 1 | 1 | 地形 |
| 2 | 2 | A 队及未分队玩家 |
| 3 | 4 | 敌人 |
| 5 | 16 | B 队 |

默认情况下，玩家的移动由地形阻挡，敌人的移动由地形和其他敌人阻挡。玩家和敌人可以穿过彼此，敌人的矩形接触判定对两队玩家结算伤害。打开房间选项「玩家碰撞」后，敌对双方的玩家也会互相阻挡。地面武器由装备系统处理拾取。

## 伤害结算

攻击请求包含武器类型、射击序号、发射位置和方向、蓄力程度及弹丸速度倍率。散射用角色 ID 和射击序号生成随机种子。`ShotRules` 处理弹丸、光束及近战攻击，`CombatSimulator` 根据目标关系、受击无敌时间和水体状态应用伤害及击退。普通弹丸和光束命中敌方角色，范围爆炸也能伤害自身和队友。每次光束攻击对同一实体或瓦片只结算一次。[攻击规则](../core/sim/shot_rules.gd) · [命中配置](../core/sim/combat_profiles.gd)

榴弹首次碰撞时启动引信，射程耗尽也会引爆。每枚榴弹最多造成一次直击。引爆帧把爆心和到期帧放入待结算集合，之后第 3 个模拟帧统一结算范围伤害、击退和地形破坏。多个爆炸按结算帧、弹丸 ID 排序。近身接触和鸟类炸弹遵守玩家的受击无敌时间，枪弹、光束和榴弹爆炸可以连续命中。[战斗模拟](../core/sim/combat_simulator.gd) · [地形](terrain.md)

回到引爆前，检查点恢复弹丸及引信。回到引爆与结算之间，检查点恢复爆心和原定的结算帧号，连同模拟时钟一起倒回。网络校正随后重放输入，世界回溯在松开技能后从所选状态继续。[检查点](../core/sim/match_world.gd)
