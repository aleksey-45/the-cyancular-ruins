# 模拟与战斗

每场对局持有自己的 `Terrain` 和 `World2D`。玩家、敌人、弹丸与地面武器都是普通模拟对象，`ServerBody` 将它们的位置写入 `PhysicsServer2D`。`Player` 保存角色状态，`GunBody` 管理当前武器的弹药、瞄准、冷却和装填。客户端视口使用同一个世界绘制关卡，服务器可以直接推进模拟。[物理体](../core/sim/server_body.gd) · [玩家](../scenes/player/player.gd) · [武器](../core/sim/gun_body.gd)

## 世界与会话

单人模式、地图编辑器试玩、服务器和客户端预测均通过 `MatchWorld` 创建各自的对局实例。`WorldSpec` 指定地图、席位、玩法参数和随机种子。单人模式启用世界时间规则，Beta 对战启用个人时间规则。`MatchSession` 负责推进模拟。

| 接口 | 行为 |
|---|---|
| `MatchWorld.create(spec)` | 创建并返回对局实例。 |
| `world.advance(inputs, commands)` | 按固定步长推进一次。`commands` 用于开局、离场、重开和倒地后的模拟回溯。 |
| `world.sample(role)` | 采集当前帧所需的表现数据。省略角色或传入 0 时采集整个世界。 |
| `world.capture()` | 按需保存完整的动态状态和地形版本。 |
| `world.restore(checkpoint)` | 将地形恢复到检查点记录的本地版本，并恢复帧末状态和计时任务。 |
| `MatchSession.open_local()` / `open_remote()` | 分别创建本地会话或连接已有对局的联机会话。 |
| `session.fixed_step(seat_intents)` | 推进单人或服务端模拟。有观察角色时返回供表现层采样的前后两帧。 |
| `session.reconcile(ping_ms)` | 处理可用的权威快照，返回快照和位置校正数据。需要回滚时恢复权威状态并重放未确认的输入。 |
| `session.predict(input)` | 提交本步新输入，推进预测并返回表现所需的前后两帧。 |

会话决定何时采样。联机回滚后重放输入，为最终显示保留前后两帧的表现数据。传输和恢复使用检查点。 [世界接口](../core/sim/match_world.gd) · [会话接口](../core/net/match_session.gd)

## 每帧更新

本地输入适配器采集移动、瞄准、武器和技能操作。每步先处理对局指令和时间规则，再更新地面武器和角色。战斗模块按射击 ID 顺序分派弹丸、光束和近战，命中后共用伤害结算。随后更新敌人和在途弹丸，帧末结算到期的爆炸并更新地形碰撞。对局模拟根据伤害结果处理击杀归属、时间颗粒奖励、计分和复活。攻击状态由战斗模块统一采样和恢复。 [输入](../core/net/local_input_source.gd) · [战斗](../core/sim/combat_simulator.gd) · [表现](../core/present/match_presenter.gd)

| 操作 | 恢复范围 |
|---|---|
| 网络回滚 | 从权威快照恢复模拟状态和模拟帧号，按原目标帧重放仍有效的未确认输入。 |
| Beta 个人回溯 | 恢复该角色的状态、仍持有的武器状态，以及该角色发射且仍在场的弹丸运动状态。保留当前武器归属、已结算直击和其他角色。 |
| 单人世界回溯 | 恢复普通敌人、弹丸的存在与运动状态、地形和战斗时钟。精英继续行动，地面武器暂停。保留当前氧气、武器归属和射击序号。 |

时间技能以 20 Hz 记录历史，按技能范围保存相关角色和实体的状态，并复用未变化的记录。结束回溯后，从所选历史状态继续记录。单人回溯可以倒退战斗时间，模拟帧号仍持续递增。 [历史存储](../core/sim/time_history.gd) · [个人回溯](../core/sim/personal_time.gd) · [世界回溯](../core/sim/world_time.gd)

## 物理查询

`CollisionWorld` 复用 Godot 物理查询参数。角色依次沿 X、Y 轴调用 `PhysicsServer2D.body_test_motion()`，弹丸沿当前位移做扫掠检测。光束用形状查询找目标，敌人的接触攻击查询当帧的矩形重叠。物理体关联角色的实例 ID，命中可直接取得模拟对象。爆炸按对局名单计算环形距离，再用射线检查遮挡。出生点校验和玩家物理体共用站姿矩形。蹲伏和倒地切换到较矮的矩形。玩家靠近地图边缘时，会把当前碰撞形状复制到地图另一侧。原位置和复制后的形状都属于同一个物理体。[CollisionWorld](../core/sim/collision_world.gd)

| 碰撞层 | 位值 | 对象 |
|---|---:|---|
| 1 | 1 | 地形 |
| 2 | 2 | A 队及未分队玩家 |
| 3 | 4 | 敌人 |
| 5 | 16 | B 队 |

默认情况下，玩家的移动由地形阻挡，敌人的移动由地形和其他敌人阻挡。玩家和敌人可以穿过彼此，敌人的矩形接触判定对两队玩家结算伤害。打开房间选项「玩家碰撞」后，敌对双方的玩家也会互相阻挡。地面武器由装备系统处理拾取。

## 伤害结算

攻击请求包含武器类型、射击序号、发射位置和方向、蓄力程度及弹丸速度倍率。散射用角色 ID 和射击序号生成随机种子。`ShotRules` 处理弹丸、光束及近战攻击，`CombatSimulator` 根据目标关系、受击无敌时间和水体状态应用伤害及击退。普通弹丸和光束命中敌方角色，范围爆炸也能伤害自身和队友。每次光束攻击对同一实体或瓦片只结算一次。[攻击规则](../core/sim/shot_rules.gd) · [命中配置](../core/sim/combat_profiles.gd)

榴弹首次碰撞时启动引信，射程耗尽也会引爆。每枚榴弹最多造成一次直击。引爆时记录爆心和结算帧，在引爆 3 个模拟帧后结算范围伤害、击退和地形破坏。多个爆炸按结算帧、弹丸 ID 排序。近身接触和鸟类炸弹遵守玩家的受击无敌时间，枪弹、光束和榴弹爆炸可以连续命中。[战斗模拟](../core/sim/combat_simulator.gd) · [地形](terrain.md)

回到引爆前，检查点恢复弹丸及引信。回到引爆与结算之间，检查点恢复爆心和原定的结算帧号，连同模拟时钟一起倒回。网络回滚随后重放未确认的输入，世界回溯在松开技能后从所选状态继续。[检查点](../core/sim/match_world.gd)
