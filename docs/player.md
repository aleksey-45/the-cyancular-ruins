# 玩家

## 操作

| 默认操作 | 动作 |
|---|---|
| A、D | 水平移动 |
| W、空格 | 跳跃、攀爬、主动上浮 |
| S | 蹲伏、空中下冲、向下攀爬 |
| X | 冲刺 |
| 鼠标左键 | 按装备规则瞄准或出手 |
| R | 装填。单人倒地时重开关卡 |
| F、长按 Q | 拾取、丢弃武器 |
| 1–4、滚轮 | 切换装备。滚轮可以在设置中关闭 |
| Shift、鼠标右键 | 时空回溯、时间加速。适用于单人和 Beta 对战 |

## 移动与姿态

站立、移动、跳跃和冲刺使用站立矩形。蹲伏降低矩形顶边，脚底和宽度保持一致。起身要经过净空查询，倒地使用旋转后的站立形状并继续受重力与击退影响。正常移动包含土狼时间、跳跃缓冲和松键截断。空中冲刺的重力倍率为 0.35。 [运动参数](../core/config/player_params.gd)

角色着地且横移被地形侧面挡住时，从侧边内侧、脚底上方 64 像素处向下找首个地形顶面。探测起点在墙内时，沿用普通碰撞结果。找到顶面后检查一次上抬、横移和落脚，落脚有效且横移更远时提交位姿。梯子和铁链按脚底或角色中心识别，向上输入可抓取，移动速度取材质配置。 [ActorBody](../core/sim/actor_body.gd)

## 单人时间

单人关卡持有自己的颗粒账户和 `TimeField`，在固定物理步进中结算回溯或加速。加速时玩家和精英以 2 倍行动，普通敌人、敌弹与地面物件以 0.5 倍行动。角色与敌人的步进按各自时间倍率推进。 [单人时间参数](../core/config/time_params.gd) · [TimeField](../core/sim/time_field.gd)

`WorldRewind` 记录玩家、普通敌人和弹丸，地形历史按同一时间轴恢复。玩家生命值取历史快照并限制在当前最大 HP 内，氧气沿用进入该次恢复时的值。回溯可重建历史弹丸，松开后从恢复位置续写历史。单人倒地按 R 会恢复地形、敌人、掉落物与玩家初始装备，并把角色以满 HP 和氧气放回开局点。 [WorldRewind](../core/sim/world_rewind.gd) · [单人关卡](../scenes/level_0.gd)
