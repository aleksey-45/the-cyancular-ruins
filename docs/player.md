# 玩家

## 默认操作

| 输入 | 动作 |
|---|---|
| A、D | 水平移动 |
| 空格 | 跳跃、向上攀爬或上浮 |
| S | 蹲伏、在空中下冲、向下攀爬或下潜 |
| 双击 A 或 D | 向相应方向横冲，跟随左移和右移键位 |
| 移动鼠标 | 瞄准 |
| 鼠标左键 | 按武器规则开火、连射或蓄力 |
| R | 换弹。单人倒地后重开 |
| F、长按 Q | 拾取、丢弃武器 |
| 1–4、鼠标滚轮 | 切换武器。滚轮切换可在设置中关闭 |
| Shift、鼠标右键 | 时间回溯、时间加速。适用于单人和 Beta 对战 |

## 移动与碰撞

玩家的站立碰撞形状为矩形。蹲伏时只降低矩形顶部，起身前检查头顶是否有足够空间。倒地时沿用蹲伏形状，角色和武器贴图会旋转。角色仍受重力和击退影响。

离开地面后默认还有 0.1 秒可以起跳（土狼时间）。落地前的跳跃输入最多缓冲 0.12 秒，着地后触发。上升途中松开跳跃键可降低上升速度，控制跳跃高度。

在 0.25 秒内双击同一方向的移动键可向该方向横冲。横冲速度受武器的水平移动减速影响，在空中横冲时重力为平时的 0.35 倍。下冲将向下速度提高到至少 2,000 像素/秒。攀爬判定读取角色脚底和中心所在的子格，梯子和铁链的攀爬速度可分别配置。[玩家参数](../core/config/player_config.gd) · [玩家数值](../core/config/player_config.tres) · [角色移动](../scenes/player/player.gd)

角色沿输入方向撞到地形侧面时，向下投射射线查找台阶顶面，再用角色的碰撞形状检测能否向上移动。角色着地时最多探测 4 个子格高的台阶。横移后能比原来走得更远且能落脚时，2 个子格及以下的台阶可直接迈上，更高的台阶会触发自动跳跃。角色在空中撞到台阶时，若脚底比台阶顶面低至多 1 个子格，且上移路径畅通，就将角色抬至顶面并清除下落速度。[台阶检测](../scenes/player/player.gd)

## 单人时间技能

`WorldTime` 按物理帧更新时间颗粒、技能消耗和时间倍率。同时按住两个时间技能时优先加速。加速期间玩家、玩家发射的弹丸和精英敌人按 2 倍时间更新。普通敌人、敌方弹丸和地面武器以 0.5 倍时间为基准更新，普通敌人的速度还受时间颗粒透支影响。击败乌鸫后，时间结晶飞向怀表，300 个时间颗粒在 36 个模拟帧后到账。[时间参数](../core/config/time_config.tres) · [WorldTime](../core/sim/world_time.gd)

单人模式以 20 Hz 记录玩家、普通敌人、攻击状态和地形版本。回溯可恢复玩家的生命值、仍在飞行的弹丸及其引信，也可恢复已引爆、尚待结算的爆炸。精英敌人继续行动。玩家保留当前氧气、已完成的武器拾取与丢弃、已分配的射击序号。松开回溯键后，从所选状态继续战斗。[回溯历史](../core/sim/time_history.gd) · [世界时间规则](../core/sim/world_time.gd) · [Beta 时间技能](modes.md#beta-时间技能)

从主菜单进入的单人对局会在玩家倒地或退出时保存供片头重绘的场景状态。下一局的片头从上一局最后一幕倒放至出生画面，越早的片段播放越快，片头最多 3 秒。按 Esc 或空格可跳过。倒地后仍可按 Shift 回溯自救，或按 R 重开。重开会恢复地形、敌人和初始装备，重新分布地面武器，并让玩家以满生命值和氧气回到出生点。[单人片头](render.md#单人片头)
