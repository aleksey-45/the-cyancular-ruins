# 玩家

## 默认操作

| 输入 | 动作 |
|---|---|
| A、D | 水平移动 |
| 空格 | 跳跃、向上攀爬或上浮 |
| S | 蹲伏、在空中下冲、向下攀爬或下潜 |
| 双击 A 或 D | 向相应方向横冲，跟随左移和右移键位 |
| 鼠标左键 | 根据武器规则瞄准、射击或蓄力 |
| R | 装填。单人倒地时倒带并重开关卡 |
| F、长按 Q | 拾取、丢弃武器 |
| 1–4、鼠标滚轮 | 切换武器。滚轮切换可在设置中关闭 |
| Shift、鼠标右键 | 时间回溯、时间加速。适用于单人和 Beta 对战 |

## 移动与碰撞

站立、移动、跳跃和冲刺使用站立碰撞形状。蹲伏降低矩形顶部，保留原来的底部和宽度。起身前用站立碰撞形状检查头顶空间。倒地使用蹲伏的碰撞形状，并旋转角色和武器贴图。倒地后仍受重力和击退影响。

离开地面后的短暂时间内仍可起跳。在落地前短按跳跃键会缓存这次输入，落地后触发。上升时松开跳跃键会降低向上速度。横冲需要在 0.25 秒内按两次同一方向的移动键，并受当前生效的武器水平移速惩罚影响。空中横冲将重力乘以 0.35。下冲将向下速度提高到至少 2,000 像素/秒。游戏检查角色脚底和中心所在的瓦片，判断能否攀爬。梯子和铁链可以有不同的攀爬速度。[玩家参数](../core/config/player_config.gd) · [玩家数值](../core/config/player_config.tres) · [角色移动](../scenes/player/player.gd)

着地横移遇到墙面时，角色从脚底上方约 64 像素处向下发射射线，寻找台阶的顶面，再检测抬高位置、向前移动和落地时是否受阻。台阶路径畅通且比直接横移走得更远时，32 像素及以内的台阶可直接迈上，48 / 64 像素的台阶触发自动跳跃并保留横向速度。空中贴到 16 像素以内的台沿且头顶有空间时，角色向上修正位置。其余情况按普通水平碰撞处理。[台阶检测](../core/sim/actor_body.gd)

## 单人时间技能

`TimeField` 按物理帧更新时间颗粒、技能消耗和时间倍率。同时按住两个时间技能时优先加速。加速期间玩家、玩家发射的弹丸和精英敌人按 2 倍时间更新。普通敌人、敌方弹丸和掉落物按 0.5 倍更新。击败乌鸫获得的 300 个时间颗粒在 36 个物理帧后到账，结晶在此期间飞向怀表。[时间参数](../core/config/time_params.gd) · [TimeField](../core/sim/time_field.gd)

`RewindHistory` 以 20 Hz 保存世界记录。每份战斗检查点包含角色、弹丸、普通敌人的行动状态与计时器，恢复时同时恢复该帧的地形。回溯可恢复角色生命值、飞行中的弹丸及其引信，也可恢复已经引爆、仍在等待结算的榴弹。精英敌人继续行动。玩家保留当前氧气、已完成的武器拾取与丢弃、已分配的射击序号。松开回溯键后，从所选状态继续战斗。[回溯历史](../core/sim/rewind_history.gd) · [战斗检查点](../core/sim/combat_snapshot.gd) · [Beta 时间技能](modes.md#beta-时间技能)

单人倒地后按 R，用同一份历史和回溯速度倒放死亡前最近 4 秒内的场景。按 R、空格、Esc 或鼠标左键可跳过，记录不足半秒时直接重开。重开会重置地形、敌人、掉落物和初始装备，并以满生命值和氧气回到出生点。
