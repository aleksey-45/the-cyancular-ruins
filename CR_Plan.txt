================================================================
The Cyancular Ruins 更新总览：v1.1.1 → v1.1.3
================================================================

【一句话记忆】
  v1.1.1 是"起跑线"快照；
  v1.1.2 是"玩法大版本"——让大乱斗能打完一局、打起来更爽；
  v1.1.3 是"体验与稳定修补"——修联机干等、进图蓝屏、判不中、界面/工具毛病。

【版本地图】
  KH_v1_1_1（0232a0d）  基线：之前所有成果的快照
  KH_v1_1_2（5043a50）  内容向：武器、手感、反馈、大乱斗玩法、开服工具
  KH_v1_1_3（当前主线）  体验向：联机稳定、UI、工具链、兼容性

----------------------------------------------------------------
V1.1.2：玩法大版本（"加了什么好玩的"）
----------------------------------------------------------------

[武器]
  · 新增第 6 槽激光枪：即时光束，开火瞬间算反射折线（最多 5 次反射），
    路径上的敌人/玩家一次性结算，可磨树叶/树干；蓝色双层光束 + 枪口光球。
  · 榴弹两处修复：
      1) PvP 里命中敌人却"没爆炸伤害"——引信被命中结算吞掉，改为跳过普通补刀；
      2) 多人一起轰导致卡崩——限制每人同屏在飞榴弹最多 3 发（弹满开火点空枪，不耗弹）。
  · 黑鸟调强（跟上游手感）：游走更快、瞬移判定更频、冲锋更快更狠、后跳更远，
    且后跳时保持面朝玩家（不再背对玩家倒退）。

[手感：下蹲 & 冲刺]
  · 下蹲改成"逐帧推导"：空中松开 S 不再落地卡蹲；并支持蹲走（小步移动）。
  · 冲刺大改：可被跳跃/撞墙打断、空中冲刺重力 ×0.35（能跨沟）、收尾不再硬减速，
    枪口在冲刺时不跟着身体翻（仍朝鼠标）；速度 1500→1900、时长 0.6→0.4 秒。

[生存]
  · 单机倒地按 R = 原地重启：满血满氧回出生点、清子弹/敌人并按难度重刷；
    不再"重建整个世界"（那会偶发蓝屏/段错误）。

[打击反馈]
  · 击杀时屏幕中央：金色「击杀 XXX」+ 像素骷髅头 + 连杀计数
    （6 秒内连续击杀累加，自己被击杀立即清零）。
  · 激光枪补齐反馈：命中出 X 标记、击杀能正确归因（单机播报、大乱斗计分）。

[大乱斗玩法]
  · 出生/复活点改为"开阔可走区"：头顶 2 格净空 + 左右邻格空 + 同层连通区 ≥20 格
    → 再也不会出生在走不出去的小房间、夹层里。
  · 建房页可自定一局限时（1~15 分钟，默认 5）。
  · 建房页能直接改自己角色颜色（以前必须绕回 1v1 多人页）。
  · 新增 K 键"自杀脱困"：卡在墙里/夹缝时自救，走正常 2 秒复活，不给人记击杀。
  · 排行榜增加"阵亡数"列。

[开服 / 联机体验]
  · 服务端启动自动算出并打印本机 IP（局域网 IPv4 优先 + 公网 IP 尽力拉取）
    → 不用再手动 ipconfig。

[稳定]
  · 主菜单 → 关卡：改成"先建好新世界再拆旧菜单"的分阶段接管，规避建图同帧段错误（蓝屏）。
  · 大乱斗"点进去蓝屏"：大厅脚本解析失败 + 开局转场景延迟出 poll 栈，已修。

[工具与纪律]
  · 卡编辑器 / 打包器"双击闪退"根治：cmd 批处理必须 CRLF、中文用 GBK 编码，
    并改用 console 版 Godot（GUI 版不阻塞，errorlevel 不可靠）。
  · 打包脚本改为"客户端 + 服务端成对导出"。
  · 纪律：版本名分支（KH_vX_Y_Z）永久保留，清理只删非版本名的实验分支。

----------------------------------------------------------------
V1.1.3：体验与稳定修补（"修了什么难受的"）
----------------------------------------------------------------

[联机稳定]
  · 幽灵房间：点了没反应的房 → 超时自动回大厅；大厅不再滞留已开局/失效房间。
  · 入房后配对被取消 / 房主掉线 → 不再干等，补齐两个边缘态。
  · 1v1 进图蓝屏：补回 match_start"延迟出 poll 栈"（分支整合时丢过一次）。
  · 子弹"看着重合却不判中"：命中判定改为"扫掠线段 + 身体圆"双判定。

[大乱斗]
  · 远端激光光束：大乱斗客户端补上 beam_fired 订阅（以前只有 1v1 能看到对手的激光）。
  · 修掉本机 IP 标签压住提示文字造成的严重 UI 重叠。

[本地一键开服]
  · 大厅页新增「启动/重启本机服务器」：杀旧实例 → 拉起同目录服务端 → 自动连 127.0.0.1 刷新列表。
  · 重启期间吞掉"服务器断开/连接失败"这类预期噪音，不再吓人也不再覆盖提示。
  · 本机 IP 变成页面常驻标签（进页即显示），按钮按下与成功提示都带 IP。
  · 服务端是无控制台的 GUI exe：IP 改为落盘 exe 旁的 local_ip.txt（公网 IP 到手后补写）。
  · 端口轮询/杀进程改为隐形执行：不再每秒弹一个黑窗（之前看着像服务器在反复开关）。

[工具链 / 兼容]
  · 卡编辑器"agent 施工一小时没动静"三处修复：静默拉起失败、停止按钮失效、完成标记丢失。
  · 现役 6 把武器做成对照卡（手枪/步枪/重狙/霰弹/榴弹/激光），
    数值 = 实装 tscn 导出，可直接在卡编辑器里查看/修改后走提示词施工。
  · 项目内中文文件名改英文（build_exe.bat / launch_card_editor.bat / local_ip.txt），win/mac 通用。
  · 实验：移植原作者 C2 客户端预测 rollback（开关 LOCAL_PREDICTION_ENABLED，默认 OFF，
    当前仍是"服务器渲染"路线）；计划细节见 docs/c2-client-prediction-port-plan.md。
  · 试过"榴弹直击敌人钉住原地引爆"，因手感不佳已回滚（保持反弹+引信引爆）。

已知限制 / 下一步
----------------------------------------------------------------
  · 换弹仍只限单机：PvP / 大乱斗没有弹夹系统，对局中按 R 不换弹。
    要实装需三件套：R 边沿进输入包 + 服务端权威弹夹 + 弹量随快照镜像。
  · 大乱斗上公网三条路：
      ① 请原作者在云服部署"含 NetBusExt 大乱斗协议"的服务端构建（需服主配合）
      ② 自己租一台轻量云当服主（放行 UDP 7777 + 7800~7910）
      ③ Tailscale / ZeroTier 虚拟局域网（零成本，最推荐先试）
  · 公网 IP 是动态的：每次开服看 local_ip.txt；局域网 IP 基本不变。
  · C2 客户端预测默认关闭，属实验开关——开之前先读 docs/c2-client-prediction-port-plan.md。
  · 文档里的旧中文文件名（打包exe.bat / 启动卡编辑器.bat / 本机IP.txt）已改名，
    对应新名见上面 V1.1.3 的"工具链 / 兼容"。
