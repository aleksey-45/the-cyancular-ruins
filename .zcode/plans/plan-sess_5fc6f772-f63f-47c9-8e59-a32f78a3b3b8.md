## 目标(已按你的要求修正:所有文件名一律英文,macOS/Windows 双端合法)
新开 `editor_log` 分支,交付独立于游戏代码的"日志记录器 + 监看器":本分支之后每一次发起的游戏进程都有留档,进程结束自动生成小白可读的中文报告(时间精确到秒、退出原因、错误清单)。文件名全英文;报告**内容**为中文(文件内容 UTF-8,双端无碍)。

## 交付物(全部新文件,零游戏代码改动)

### A. 记录器
- `tools/gamelog/capture_session.ps1`:核心引擎(UTF-8 BOM 存中文)
  - 建 `gamelogs/<yyyyMMdd_HHmmss>_<game|server>/` 会话目录,重定向捕获 stdout.log / stderr.log;
  - 进程结束写 **report.txt**(中文,顶部自带"怎么读这份报告"):
    - 启动/结束时间、时长(精确到秒);
    - 退出结论三态:✅正常退出(码0)/ ⚠异常退出(非零)/ ❌崩溃(Windows 异常码翻译成人话,如 0xC0000005=内存访问冲突即段错误闪退);
    - 崩溃时查 Windows 事件日志取"故障模块名";
    - 问题清单:自动抽取 SCRIPT ERROR / Parse Error / ERROR: / 资源加载失败 / Vulkan 等行,按类别给中文解释;
- 入口(内容纯 ASCII+CRLF,双击用;支持把 exe 拖到 bat 上启动指定版本):
  - `start_game_logged.bat`(无可用 exe 时自动回退用 Godot 跑工程)
  - `start_server_logged.bat`

### B. 监看器(Godot 小程序)
- `DevTools/gamelog/log_viewer.tscn + .gd`:左侧按时间倒序列出全部会话(时间/类型/时长/结论,绿=正常 黄=异常 红=崩溃),右侧只读显示选中会话的 report.txt;按钮:刷新 / 打开会话文件夹;
- `DevTools/launch_log_viewer.bat` 双击启动。

### C. 收尾
- `gamelogs/` 加入 .gitignore;AGENTS.md 登记一段使用说明;
- 不动 project.godot、不动 Scenes/Globals/server 任何代码、不改动现有 bat。
